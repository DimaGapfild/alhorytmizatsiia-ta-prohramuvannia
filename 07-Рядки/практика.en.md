# Practice Tasks for Chapter 7

**Task type:** processing a string entered from the keyboard.
Use indexing, slices, string methods, and a loop over the string.

---

### Task 7.1
A string is given. Print its length, its first and last characters,
and the string in reverse order.
```
"program" → 7, 'p', 'm', "margorp"
```

### Task 7.2
A string is given. Count the number of vowels, consonants,
and other characters (Latin letters).
```
"algorithm and program" → vowels 6, consonants 13, other 2
```

### Task 7.3
A string is given. Check whether it is a palindrome
(ignoring case, spaces, and punctuation).
```
"A man, a plan, a canal: Panama" → yes
"program" → no
```

### Task 7.4
A string of words separated by spaces is given. Print the number of words
and the longest word.
```
"I study algorithmization" → 3 words, longest "algorithmization"
```

### Task 7.5
A string is given. Print it with the extra spaces removed
(at the beginning, at the end, and doubled ones inside).
```
"  two   words  " → "two words"
```

### Task 7.6
A string and a character are given. Count how many times the character occurs
and print the indices of all its occurrences.
```
"abracadabra", "a" → 5 times, indices 0 3 5 7 10
```

### Task 7.7
A string is given. Replace all digits with the `#` sign and print how many
replacements were made.
```
"tel. 380-67-123" → "tel. ###-##-###", replacements 8
```

### Task 7.8
A string of words is given. Print each word capitalized,
as well as the abbreviation made of the first letters.
```
"united nations organization" → "United Nations Organization", UNO
```

### Task 7.9
A string in Latin letters and an integer k are given. Encrypt the string with the Caesar
cipher with shift k (preserve case, leave other characters unchanged).
```
"Hello, World!", 3 → "Khoor, Zruog!"
```

### Task 7.10
A string is given. Print which character occurs most often
and how many times (do not count spaces).
```
"abracadabra" → 'a', 5 times
```
