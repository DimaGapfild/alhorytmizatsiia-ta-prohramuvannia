# Практичні завдання до розділу 7

**Тип завдань:** обробка рядка, введеного з клавіатури.
Використовувати індексацію, зрізи, методи рядків і цикл перебору.

---

### Задача 7.1
Дано рядок. Вивести його довжину, перший і останній символи
та рядок у зворотному порядку.
```
"програма" → 8, 'п', 'а', "амаргорп"
```

### Задача 7.2
Дано рядок. Підрахувати кількість голосних, приголосних
і решти символів (українські літери).
```
"алгоритм і програма" → голосних 7, приголосних 10, інших 2
```

### Задача 7.3
Дано рядок. Перевірити, чи він є паліндромом
(ігноруючи регістр, пробіли та знаки).
```
"А роза упала на лапу Азора" → так
"програма" → ні
```

### Задача 7.4
Дано рядок зі слів, розділених пробілами. Вивести кількість слів
і найдовше слово.
```
"я вивчаю алгоритмізацію" → 3 слова, найдовше "алгоритмізацію"
```

### Задача 7.5
Дано рядок. Вивести його з видаленими зайвими пробілами
(на початку, в кінці та подвійними всередині).
```
"  два   слова  " → "два слова"
```

### Задача 7.6
Дано рядок і символ. Підрахувати, скільки разів символ зустрічається,
і вивести індекси всіх його входжень.
```
"абракадабра", "а" → 5 разів, індекси 0 3 5 7 10
```

### Задача 7.7
Дано рядок. Замінити всі цифри на знак `#` і вивести, скільки
замін виконано.
```
"тел. 380-67-123" → "тел. ###-##-###", замін 8
```

### Задача 7.8
Дано рядок зі слів. Вивести кожне слово з великої літери,
а також абревіатуру з перших літер.
```
"організація об'єднаних націй" → "Організація Об'єднаних Націй", ООН
```

### Задача 7.9
Дано рядок латиницею і ціле k. Зашифрувати рядок шифром Цезаря
зі зсувом k (регістр зберігати, інші символи не змінювати).
```
"Hello, World!", 3 → "Khoor, Zruog!"
```

### Задача 7.10
Дано рядок. Вивести, який символ зустрічається найчастіше
і скільки разів (пробіли не враховувати).
```
"абракадабра" → 'а', 5 разів
```
