# Розділ 7. Рядки

## 7.1 Рядок як тип даних

`str` — **незмінна** (immutable) послідовність символів Unicode.

**Python**

```python
s = "Привіт"
s = 'Привіт'           # однакові
s = """кілька
рядків"""              # з переходами
```

**C++**

```cpp
string s = "Hello";            // рядок у подвійних лапках
// 'Hello' в одинарних лапках — помилка: 'H' — це один символ типу char
string t = R"(several
lines)";                       // «сирий» багаторядковий літерал
```

**JavaScript**

```javascript
let s = "Hello";
s = 'Hello';                   // однакові
s = `several
lines`;                        // шаблонний рядок, з переходами
```

Незмінність означає: `s[0] = "п"` → `TypeError`.
Будь-яка «зміна» створює **новий** рядок.

**Три мови.** Приклади C++ і JavaScript у цьому розділі подано латиницею (як в англомовній версії), щоб не відволікатися на кодування: у C++ `std::string` зберігає **байти**, і кожна українська літера в UTF-8 займає 2 байти, тому `length()` і індекси для кирилиці працюють з байтами, а не з літерами.

Незмінність — особливість Python і JavaScript (`s[0] = "x"` у JavaScript мовчки нічого не робить, а в суворому режимі кидає `TypeError`). `std::string` у C++ — **змінний** тип: `s[0] = 'x'` дозволено.

### Екранування
| Запис | Символ |
|-------|--------|
| `\n` | новий рядок |
| `\t` | табуляція |
| `\\` | обернена похила |
| `\"` `\'` | лапки |
| `r"C:\new"` | «сирий» рядок, без екранування |

Екранування в C++ і JavaScript те саме (`\n`, `\t`, `\\`, `\"`, `\'`). «Сирий» рядок: `R"(C:\new)"` у C++, `String.raw\`C:\new\`` у JavaScript.

## 7.2 Довжина, індексація, зрізи

**Python**

```python
s = "програма"
len(s)        # 8
s[0]          # 'п'   — перший
s[-1]         # 'а'   — останній
s[2]          # 'о'
```

**C++**

```cpp
string s = "program";
s.length();            // 7     (також s.size())
s[0];                  // 'p'   — перший
s.back();              // 'm'   — останній (s[s.size() - 1])
s[2];                  // 'o'
```

**JavaScript**

```javascript
const s = "program";
s.length;              // 7
s[0];                  // 'p'   — перший
s.at(-1);              // 'm'   — останній (s[s.length - 1])
s[2];                  // 'o'
```

У C++ індекс `-1` **не означає** «останній»: `s[-1]` — це звернення за межі рядка (невизначена поведінка). У JavaScript для від'ємних індексів є метод `at`.

### Зрізи `s[start:stop:step]`

**Python**

```python
s[0:4]        # 'прог'   (stop не включається)
s[:4]         # 'прог'
s[4:]         # 'рама'
s[-4:]        # 'рама'
s[::2]        # 'прга'   (кожен другий)
s[::-1]       # 'амаргорп'  — реверс рядка
s[1:-1]       # без першого й останнього
```

**C++**

```cpp
s.substr(0, 4);                          // "prog"  (substr(позиція, довжина))
s.substr(4);                             // "ram"
s.substr(s.size() - 4);                  // "gram"
s.substr(1, s.size() - 2);               // без першого й останнього
string rev(s.rbegin(), s.rend());        // "margorp" — реверс
string every2;
for (size_t i = 0; i < s.size(); i += 2) every2 += s[i];   // "porm"
```

**JavaScript**

```javascript
s.slice(0, 4);                           // 'prog'  (кінець не включається)
s.slice(4);                              // 'ram'
s.slice(-4);                             // 'gram'
s.slice(1, -1);                          // без першого й останнього
[...s].reverse().join("");               // 'margorp' — реверс
[...s].filter((_, i) => i % 2 === 0).join("");   // 'porm'
```

`substr` у C++ кидає виняток `out_of_range`, якщо позиція більша за довжину, — на відміну від зрізів Python, що завжди «м'які». `slice` у JavaScript, як і зріз Python, ніколи не кидає виняток.

Зріз **ніколи не викликає IndexError** — зайві межі обрізаються.

## 7.3 Операції над рядками

**Python**

```python
"аб" + "вг"        # 'абвг'   конкатенація
"ха" * 3           # 'хахаха' повторення
"а" in "кава"      # True     входження
"кава".index("в")  # 2        індекс (ValueError, якщо немає)
"кава".find("z")   # -1       індекс або -1
"кава".count("а")  # 2
```

**C++**

```cpp
string a = "ab", b = "cd", w = "banana";
a + b;                                   // "abcd"    конкатенація
string(3, 'x');                          // "xxx"     повторення символу
w.find('a') != string::npos;             // true      входження
w.find('n');                             // 2         індекс
w.find('z');                             // string::npos — «не знайдено», а не -1
count(w.begin(), w.end(), 'a');          // 3         (<algorithm>)
```

**JavaScript**

```javascript
"ab" + "cd";                             // 'abcd'    конкатенація
"ha".repeat(3);                          // 'hahaha'  повторення
"banana".includes("a");                  // true      входження
"banana".indexOf("n");                   // 2         індекс
"banana".indexOf("z");                   // -1        «не знайдено»
"banana".split("a").length - 1;          // 3         кількість входжень
```

## 7.4 Основні методи

### Регістр

**Python**

```python
"Текст".upper()        # 'ТЕКСТ'
"Текст".lower()        # 'текст'
"текст тут".title()    # 'Текст Тут'
"текст".capitalize()   # 'Текст'
"ТеКсТ".swapcase()     # 'тEkSt'
```

**C++**

```cpp
string t = "Text";
transform(t.begin(), t.end(), t.begin(), ::toupper);   // "TEXT"
transform(t.begin(), t.end(), t.begin(), ::tolower);   // "text"
string c = "text";
c[0] = toupper(c[0]);                                  // "Text"  (capitalize)
```

**JavaScript**

```javascript
"Text".toUpperCase();                                  // 'TEXT'
"Text".toLowerCase();                                  // 'text'
"some text".replace(/\b\p{L}/gu, ch => ch.toUpperCase());   // 'Some Text'  (title)
"text".charAt(0).toUpperCase() + "text".slice(1);      // 'Text'  (capitalize)
```

У C++ `toupper`/`tolower` працюють з одним символом і лише з латиницею (ASCII); готових `title()` та `swapcase()` немає — їх пишуть циклом.

### Перевірки (повертають bool)

**Python**

```python
"123".isdigit()    "abc".isalpha()    "a1".isalnum()
"  ".isspace()     "Abc".istitle()    "ABC".isupper()
"abc".startswith("a")    "abc".endswith("c")
```

**C++**

```cpp
string d = "123", w = "abc", sp = "  ";
all_of(d.begin(), d.end(), ::isdigit);     // true   — isdigit()
all_of(w.begin(), w.end(), ::isalpha);     // true   — isalpha()
all_of(w.begin(), w.end(), ::isalnum);     // true   — isalnum()
all_of(sp.begin(), sp.end(), ::isspace);   // true   — isspace()
all_of(w.begin(), w.end(), ::isupper);     // false  — isupper()
w.starts_with("a");                        // true   (C++20)
w.ends_with("c");                          // true   (C++20)
```

**JavaScript**

```javascript
/^\d+$/.test("123");                       // true   — isdigit()
/^\p{L}+$/u.test("abc");                   // true   — isalpha()
/^[\p{L}\d]+$/u.test("a1");                // true   — isalnum()
/^\s+$/.test("  ");                        // true   — isspace()
"ABC" === "ABC".toUpperCase();             // true   — isupper() (приблизно)
"abc".startsWith("a");                     // true
"abc".endsWith("c");                       // true
```

Готових методів-перевірок у C++ і JavaScript немає: використовують `<cctype>`/`<algorithm>` (C++) і регулярні вирази (JavaScript). `all_of` для порожнього рядка дає `true`, тоді як `"".isdigit()` у Python — `False`.

### Обрізання та заміна

**Python**

```python
"  текст  ".strip()        # 'текст'
"  текст  ".lstrip()       # 'текст  '
"xxтекстxx".strip("x")     # 'текст'
"кава".replace("а", "о")   # 'ково'
"а-б-в".replace("-", "", 1)  # 'аб-в'  (лише перше)
```

**C++**

```cpp
string t = "  text  ";
t.erase(0, t.find_first_not_of(' '));      // lstrip: "text  "
t.erase(t.find_last_not_of(' ') + 1);      // rstrip: "text"
string k = "banana";
replace(k.begin(), k.end(), 'a', 'o');     // "bonono" — усі входження символу
string h = "a-b-c";
h.erase(h.find('-'), 1);                   // "ab-c" — лише перше входження
```

**JavaScript**

```javascript
"  text  ".trim();                         // 'text'
"  text  ".trimStart();                    // 'text  '
"xxtextxx".replace(/^x+|x+$/g, "");        // 'text'
"banana".replaceAll("a", "o");             // 'bonono'
"a-b-c".replace("-", "");                  // 'ab-c' — рядок заміняє лише перше входження
```

Стандартної функції `strip` у C++ немає — використовують `find_first_not_of`/`find_last_not_of`.

### Розбиття та склеювання

**Python**

```python
"1 2 3".split()            # ['1', '2', '3']
"a,b,c".split(",")         # ['a', 'b', 'c']
"a\nb".splitlines()        # ['a', 'b']
" ".join(["a", "b", "c"])  # 'a b c'
```

**C++**

```cpp
vector<string> parts;
string tok;

istringstream iss("1 2 3");
while (iss >> tok) parts.push_back(tok);         // split() за пробілами: {"1","2","3"}

istringstream csv("a,b,c");
while (getline(csv, tok, ',')) parts.push_back(tok);   // split(","): {"a","b","c"}

string joined;
for (size_t i = 0; i < parts.size(); ++i) {      // join(" ")
    if (i > 0) joined += " ";
    joined += parts[i];
}
```

**JavaScript**

```javascript
"1 2 3".split(/\s+/);                      // ['1', '2', '3']
"a,b,c".split(",");                        // ['a', 'b', 'c']
"a\nb".split("\n");                        // ['a', 'b']   (аналог splitlines)
["a", "b", "c"].join(" ");                 // 'a b c'      (метод масиву!)
```

У C++ немає готових `split` і `join` — їх складають із `istringstream`/`getline` та циклу. У JavaScript `join` — метод **масиву**, а не рядка-роздільника.

`join` працює лише зі списком **рядків** — числа треба перетворити:

**Python**

```python
" ".join(str(x) for x in [1, 2, 3])    # '1 2 3'
```

**C++**

```cpp
vector<int> v = {1, 2, 3};
string out;
for (size_t i = 0; i < v.size(); ++i) {
    if (i > 0) out += " ";
    out += to_string(v[i]);                // число → рядок
}
```

**JavaScript**

```javascript
[1, 2, 3].map(String).join(" ");           // '1 2 3'
[1, 2, 3].join(" ");                       // '1 2 3' — join сам перетворює числа
```

### Вирівнювання

**Python**

```python
"5".zfill(3)        # '005'
"ab".ljust(5, ".")  # 'ab...'
"ab".rjust(5, ".")  # '...ab'
"ab".center(6, "-") # '--ab--'
```

**C++**

```cpp
string t = "5", u = "ab";
string(3 - t.size(), '0') + t;             // "005"   zfill (t коротший за 3)
u + string(5 - u.size(), '.');             // "ab..."   ljust
string(5 - u.size(), '.') + u;             // "...ab"   rjust
```

**JavaScript**

```javascript
"5".padStart(3, "0");                      // '005'
"ab".padEnd(5, ".");                       // 'ab...'
"ab".padStart(5, ".");                     // '...ab'
// center у JavaScript немає — складають вручну
```

## 7.6 Код символу

**Python**

```python
ord("A")       # 65
chr(65)        # 'A'
ord("а")       # 1072  (українська/російська 'а' — не латинська!)
```

**C++**

```cpp
int('A');                // 65
char(65);                  // 'A'
(int)U'а';                 // 1072  (кирилична 'а' типу char32_t — не латинська!)
```

**JavaScript**

```javascript
"A".charCodeAt(0);         // 65
String.fromCharCode(65);   // 'A'
"а".codePointAt(0);        // 1072  (кирилична 'а' — не латинська!)
```

У C++ `char` — це й символ, і мале ціле число, тому `'a' + 1` дорівнює 98, а `char('a' + 1)` — `'b'`.

Шифр Цезаря для латиниці:

**Python**

```python
def caesar(ch, k):
    if "a" <= ch <= "z":
        return chr((ord(ch) - ord("a") + k) % 26 + ord("a"))
    return ch
```

**C++**

```cpp
char caesar(char ch, int k) {
    if ('a' <= ch && ch <= 'z') {
        return ((ch - 'a' + k) % 26 + 26) % 26 + 'a';   // + 26 — для від'ємного k
    }
    return ch;
}
```

**JavaScript**

```javascript
function caesar(ch, k) {
  if ("a" <= ch && ch <= "z") {
    const shifted = (ch.charCodeAt(0) - 97 + k) % 26;
    return String.fromCharCode(((shifted + 26) % 26) + 97);   // + 26 — для від'ємного k
  }
  return ch;
}
```

У C++ і JavaScript `%` від'ємного числа дає від'ємний результат, тому для від'ємного зсуву додають 26 — у Python `%` завжди невід'ємний.

## 7.7 Типові алгоритми

### Паліндром

**Python**

```python
t = "".join(c.lower() for c in s if c.isalnum())
print(t == t[::-1])
```

**C++**

```cpp
string t;
for (char c : s) {
    if (isalnum((unsigned char)c)) t += tolower((unsigned char)c);
}
string r(t.rbegin(), t.rend());
cout << boolalpha << (t == r) << endl;
```

**JavaScript**

```javascript
const t = [...s].filter(c => /[\p{L}\d]/u.test(c)).map(c => c.toLowerCase()).join("");
console.log(t === [...t].reverse().join(""));
```

### Підрахунок голосних

**Python**

```python
vowels = "аеєиіїоуюя"
k = sum(1 for c in s.lower() if c in vowels)
```

**C++**

```cpp
string vowels = "aeiou";
int k = 0;
for (char c : s) {
    if (vowels.find(tolower((unsigned char)c)) != string::npos) k++;
}
```

**JavaScript**

```javascript
const vowels = "aeiou";
const k = [...s.toLowerCase()].filter(c => vowels.includes(c)).length;
```

### Найдовше слово

**Python**

```python
words = s.split()
longest = max(words, key=len)
```

**C++**

```cpp
istringstream iss(s);
string w, longest;

```

**JavaScript**

```javascript
const words = s.split(/\s+/).filter(Boolean);
const longest = words.reduce((a, b) => (b.length > a.length ? b : a), "");
```

## 7.8 Чому конкатенація в циклі — погано

**Python**

```python
# погано: O(n²), щоразу створюється новий рядок
res = ""
for ch in s:
    res += ch

# добре: O(n)
res = "".join(parts)
```

**C++**

```cpp
// у C++ += для std::string — амортизовано O(1), бо рядок змінний
string res;
for (char ch : s) {
    res += ch;
}

// те саме, коли збираємо готові частини
ostringstream os;
for (const string &p : parts) os << p;
string res2 = os.str();
```

**JavaScript**

```javascript
// сучасні рушії оптимізують +=, але надійніше — join
let res = "";
for (const ch of s) {
  res += ch;
}

const res2 = parts.join("");
```

Повільною конкатенація у циклі є саме в Python (і подібних мовах із незмінними рядками); у C++ `s += ch` працює за амортизований O(1), а `s = s + ch` — створює копію щоразу.
