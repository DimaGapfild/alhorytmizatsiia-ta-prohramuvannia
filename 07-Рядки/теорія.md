# Розділ 7. Рядки

## 7.1 Рядок як тип даних

`str` — **незмінна** (immutable) послідовність символів Unicode.

```python
s = "Привіт"
s = 'Привіт'           # однакові
s = """кілька
рядків"""              # з переходами
```

Незмінність означає: `s[0] = "п"` → `TypeError`.
Будь-яка «зміна» створює **новий** рядок.

### Екранування
| Запис | Символ |
|-------|--------|
| `\n` | новий рядок |
| `\t` | табуляція |
| `\\` | обернена похила |
| `\"` `\'` | лапки |
| `r"C:\new"` | «сирий» рядок, без екранування |

## 7.2 Довжина, індексація, зрізи

```python
s = "програма"
len(s)        # 8
s[0]          # 'п'   — перший
s[-1]         # 'а'   — останній
s[2]          # 'о'
```

### Зрізи `s[start:stop:step]`
```python
s[0:4]        # 'прог'   (stop не включається)
s[:4]         # 'прог'
s[4:]         # 'рама'
s[-4:]        # 'рама'
s[::2]        # 'прга'   (кожен другий)
s[::-1]       # 'амаргорп'  — реверс рядка
s[1:-1]       # без першого й останнього
```

Зріз **ніколи не викликає IndexError** — зайві межі обрізаються.

## 7.3 Операції над рядками

```python
"аб" + "вг"        # 'абвг'   конкатенація
"ха" * 3           # 'хахаха' повторення
"а" in "кава"      # True     входження
"кава".index("в")  # 2        індекс (ValueError, якщо немає)
"кава".find("z")   # -1       індекс або -1
"кава".count("а")  # 2
```

## 7.4 Основні методи

### Регістр
```python
"Текст".upper()        # 'ТЕКСТ'
"Текст".lower()        # 'текст'
"текст тут".title()    # 'Текст Тут'
"текст".capitalize()   # 'Текст'
"ТеКсТ".swapcase()     # 'тEkSt'
```

### Перевірки (повертають bool)
```python
"123".isdigit()    "abc".isalpha()    "a1".isalnum()
"  ".isspace()     "Abc".istitle()    "ABC".isupper()
"abc".startswith("a")    "abc".endswith("c")
```

### Обрізання та заміна
```python
"  текст  ".strip()        # 'текст'
"  текст  ".lstrip()       # 'текст  '
"xxтекстxx".strip("x")     # 'текст'
"кава".replace("а", "о")   # 'ково'
"а-б-в".replace("-", "", 1)  # 'аб-в'  (лише перше)
```

### Розбиття та склеювання
```python
"1 2 3".split()            # ['1', '2', '3']
"a,b,c".split(",")         # ['a', 'b', 'c']
"a\nb".splitlines()        # ['a', 'b']
" ".join(["a", "b", "c"])  # 'a b c'
```

`join` працює лише зі списком **рядків** — числа треба перетворити:
```python
" ".join(str(x) for x in [1, 2, 3])    # '1 2 3'
```

### Вирівнювання
```python
"5".zfill(3)        # '005'
"ab".ljust(5, ".")  # 'ab...'
"ab".rjust(5, ".")  # '...ab'
"ab".center(6, "-") # '--ab--'
```

## 7.6 Код символу

```python
ord("A")       # 65
chr(65)        # 'A'
ord("а")       # 1072  (українська/російська 'а' — не латинська!)
```

Шифр Цезаря для латиниці:
```python
def caesar(ch, k):
    if "a" <= ch <= "z":
        return chr((ord(ch) - ord("a") + k) % 26 + ord("a"))
    return ch
```

## 7.7 Типові алгоритми

### Паліндром
```python
t = "".join(c.lower() for c in s if c.isalnum())
print(t == t[::-1])
```

### Підрахунок голосних
```python
vowels = "аеєиіїоуюя"
k = sum(1 for c in s.lower() if c in vowels)
```

### Найдовше слово
```python
words = s.split()
longest = max(words, key=len)
```

### Кількість слів
```python
print(len(s.split()))
```

### Видалити зайві пробіли
```python
print(" ".join(s.split()))
```

## 7.8 Чому конкатенація в циклі — погано

```python
# погано: O(n²), щоразу створюється новий рядок
res = ""
for ch in s:
    res += ch

# добре: O(n)
res = "".join(parts)
```
