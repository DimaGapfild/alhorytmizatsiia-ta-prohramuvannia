# Практичні завдання до розділу 4

**Тип завдань:** лінійний алгоритм із цілочисловою арифметикою
(`//`, `%`) — без умов і циклів.

Вимоги: прочитати дані з клавіатури, вивести результат у вказаному форматі.

---

### Задача 4.1
Дано чотирицифрове число. Вивести його цифри у зворотному порядку
як одне число.
```
Ввід:  1234    →    Вивід: 4321
```

### Задача 4.2
Дано п'ятицифрове число. Вивести суму та добуток його цифр.
```
Ввід:  12345   →    Вивід: сума = 15, добуток = 120
```

### Задача 4.3
Дано кількість хвилин. Вивести, скільки це повних діб, годин і хвилин.
```
Ввід:  1500    →    Вивід: 1 діб 1 год 0 хв
```

### Задача 4.4
Дано трицифрове число. Поміняти місцями першу й останню цифри.
```
Ввід:  473     →    Вивід: 374
```

### Задача 4.5
Дано кількість днів. Вивести, скільки це повних тижнів і днів.
```
Ввід:  25      →    Вивід: 3 тиж 4 дн
```

### Задача 4.6
Дано суму в копійках. Вивести її як «X грн Y коп»
(копійки — двома цифрами).
```
Ввід:  1205    →    Вивід: 12 грн 05 коп
```

### Задача 4.7
Дано чотирицифрове число. Виконати циклічний зсув цифр уліво
(перша цифра стає останньою).
```
Ввід:  1234    →    Вивід: 2341
```

### Задача 4.8
Дано кількість сантиметрів. Вивести, скільки це метрів
і сантиметрів, а також скільки це повних дюймів (1 дюйм = 2.54 см).
```
Ввід:  375     →    Вивід: 3 м 75 см, 147 дюймів
```

### Задача 4.9
Дано двоцифрове число. Вивести число, що складається з тих самих
цифр, записаних у зворотному порядку, і суму обох чисел.
```
Ввід:  38      →    Вивід: 83, сума = 121
```

### Задача 4.10
Дано шестицифрове число — дату у форматі `ДДММРР`.
Вивести її як `ДД.ММ.20РР`.
```
Ввід:  150326  →    Вивід: 15.03.2026
```
