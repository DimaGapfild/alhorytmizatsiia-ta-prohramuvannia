# Розділ 4. Лінійні алгоритми

## 4.1 Визначення

**Лінійний алгоритм** (структура «слідування») — алгоритм, у якому
всі дії виконуються послідовно, кожна рівно один раз, без розгалужень
і повторень.

Схема: `дія1 → дія2 → … → дія n`

Типова будова:
```
ВВЕСТИ вхідні дані
обчислити проміжні значення
обчислити результат
ВИВЕСТИ результат
```

## 4.2 Оператор присвоєння

**Python**

```python
змінна = вираз
```

**C++**

```cpp
x = a + b * 2;               // ім'я = вираз;
```

**JavaScript**

```javascript
x = a + b * 2;               // ім'я = вираз;
```

У C++ і JavaScript присвоєння саме є виразом (його значення — присвоєне), тому можливі записи на кшталт `x = y = 0`. У Python присвоєння — інструкція.

Порядок виконання: **спочатку обчислюється вираз справа**, потім
результат зв'язується з іменем зліва.

**Python**

```python
x = 5
x = x + 3      # обчислили 5+3=8, потім x → 8
```

**C++**

```cpp
int x = 5;
x = x + 3;                   // обчислили 5+3=8, потім x = 8
```

**JavaScript**

```javascript
let x = 5;
x = x + 3;                   // обчислили 5+3=8, потім x = 8
```

### Обмін значень двох змінних

Класичний спосіб (через третю змінну) — працює в будь-якій мові:

**Python**

```python
tmp = a
a = b
b = tmp
```

**C++**

```cpp
int tmp = a;
a = b;
b = tmp;
```

**JavaScript**

```javascript
let tmp = a;
a = b;
b = tmp;
```

Спосіб Python (кортежне присвоєння):

**Python**

```python
a, b = b, a
```

**C++**

```cpp
swap(a, b);                  // std::swap, заголовок <utility>
```

**JavaScript**

```javascript
[a, b] = [b, a];             // деструктуризація масиву
```

У JavaScript перед рядком, що починається з `[`, попередній рядок має закінчуватися `;`, інакше парсер склеїть їх в один вираз.

Без третьої змінної через арифметику (навчальний приклад):

**Python**

```python
a = a + b
b = a - b
a = a - b
```

**C++**

```cpp
a = a + b;
b = a - b;
a = a - b;
```

**JavaScript**

```javascript
a = a + b;
b = a - b;
a = a - b;
```

У C++ для `int` цей спосіб може дати переповнення при великих `a + b`.

### Множинне присвоєння

**Python**

```python
x = y = z = 0        # усі три на один об'єкт
a, b, c = 1, 2, 3    # розпакування кортежу
```

**C++**

```cpp
int x, y, z;
x = y = z = 0;                         // виконується справа наліво
tie(a, b, c) = make_tuple(1, 2, 3);    // розпакування кортежу (C++11)
auto [p, q] = make_pair(1, 2);         // структуровані прив'язки (C++17)
```

**JavaScript**

```javascript
let x, y, z;
x = y = z = 0;                         // числа копіюються
const [a, b, c] = [1, 2, 3];           // деструктуризація масиву
```

## 4.3 Цілочислова арифметика — головний інструмент розділу

Операції `//` і `%` дозволяють «розбирати» числа на частини
без перетворення в рядок.

| Задача | Вираз |
|--------|-------|
| остання цифра числа n | `n % 10` |
| число без останньої цифри | `n // 10` |
| друга цифра з кінця | `n // 10 % 10` |
| перша цифра трицифрового | `n // 100` |
| остання k цифр | `n % 10**k` |
| годин у s секундах | `s // 3600` |
| хвилин (без годин) | `s % 3600 // 60` |
| копійок у сумі в копійках | `c % 100` |

У C++ і JavaScript ті самі вирази записуються так: `n % 10`; `n / 10` (C++, для `int`) або `Math.floor(n / 10)` (JavaScript); `n / 100`; `n / 10 % 10`. Для невід'ємних чисел `%` працює однаково в усіх трьох мовах.

### Приклад: перевернути трицифрове число

**Python**

```python
n = 473
res = n % 10 * 100 + n // 10 % 10 * 10 + n // 100
print(res)        # 374
```

**C++**

```cpp
int n = 473;
int res = n % 10 * 100 + n / 10 % 10 * 10 + n / 100;
cout << res << endl;         // 374
```

**JavaScript**

```javascript
const n = 473;
const res = (n % 10) * 100 + (Math.floor(n / 10) % 10) * 10 + Math.floor(n / 100);
console.log(res);            // 374
```

### Приклад: циклічний зсув цифр уліво

**Python**

```python
n = 1234
res = n % 1000 * 10 + n // 1000
print(res)        # 2341
```

**C++**

```cpp
int n = 1234;
int res = n % 1000 * 10 + n / 1000;
cout << res << endl;         // 2341
```

**JavaScript**

```javascript
const n = 1234;
const res = (n % 1000) * 10 + Math.floor(n / 1000);
console.log(res);            // 2341
```

## 4.4 Округлення

| Функція | 3.5 | 2.5 | −3.7 | Примітка |
|---------|-----|-----|------|----------|
| `int()` | 3 | 2 | −3 | відкидає дробову частину |
| `round()` | 4 | **2** | −4 | «банківське» округлення до парного |
| `math.floor()` | 3 | 2 | −4 | вниз |
| `math.ceil()` | 4 | 3 | −3 | вгору |

Увага: `round(2.5)` дає `2`, а не `3`. Для «шкільного» округлення
використовують `math.floor(x + 0.5)`.

Ті самі дії у C++ та JavaScript:

| Дія | Python | C++ | JavaScript |
|-----|--------|-----|------------|
| відкинути дробову частину | `int(x)` | `(int)x`, `trunc(x)` | `Math.trunc(x)` |
| вниз | `math.floor(x)` | `floor(x)` | `Math.floor(x)` |
| вгору | `math.ceil(x)` | `ceil(x)` | `Math.ceil(x)` |
| до найближчого цілого | `round(x)` | `round(x)` | `Math.round(x)` |

«Половинки» три мови округлюють по-різному. Для x = 2.5: Python дає 2 (до парного), C++ — 3 (від нуля), JavaScript — 3 (вгору). Для x = −2.5: Python дає −2, C++ — −3, JavaScript — −2 (вгору).

## 4.5 Форматований вивід результатів

**Python**

```python
print(f"{x:.3f}")      # 3 знаки після коми
print(f"{x:8.2f}")     # ширина 8, вирівнювання вправо
print(f"{x:<8.2f}|")   # вирівнювання вліво
print(f"{n:04d}")      # 0007
print(f"{n:,}")        # 1,234,567
print(f"{x:e}")        # 1.234560e+03
```

**C++**

```cpp
printf("%.3f\n", x);         // 3 знаки після коми
printf("%8.2f\n", x);        // ширина 8, вирівнювання вправо
printf("%-8.2f|\n", x);      // вирівнювання вліво
printf("%04d\n", n);         // 0007
printf("%e\n", x);           // 3.141590e+00
// роздільник тисяч (1,234,567) вимагає locale або ручного коду
```

**JavaScript**

```javascript
x.toFixed(3);                       // 3 знаки після коми
x.toFixed(2).padStart(8);           // ширина 8, вирівнювання вправо
x.toFixed(2).padEnd(8) + "|";       // вирівнювання вліво
String(n).padStart(4, "0");         // 0007
(1234567).toLocaleString("en-US");  // 1,234,567
x.toExponential(6);                 // 3.141590e+0 (показник без нуля)
```

Те саме потоками C++: `cout << fixed << setprecision(3) << x`, `setw(8)`, `left`, `setfill('0')` (заголовок `<iomanip>`). `printf` (з `<cstdio>`) коротший, але не перевіряє типи.

## 4.6 Повний приклад

**Задача.** Дано суму в копійках. Вивести її як «X грн Y коп».

**Python**

```python
total = int(input("Сума в копійках: "))
hryvnia = total // 100
kopiyka = total % 100
print(f"{hryvnia} грн {kopiyka:02d} коп")
```

**C++**

```cpp
long long total;
cout << "Сума в копійках: ";
cin >> total;
long long hryvnia = total / 100;
long long kopiyka = total % 100;
cout << hryvnia << " грн " << setfill('0') << setw(2) << kopiyka << " коп" << endl;
```

**JavaScript**

```javascript
const lines = require("fs").readFileSync(0, "utf8").split("\n");   // ввід (див. 3.6)
const total = Number(lines[0]);
const hryvnia = Math.floor(total / 100);
const kopiyka = total % 100;
console.log(`${hryvnia} грн ${String(kopiyka).padStart(2, "0")} коп`);
```

Тести: `1234` → `12 грн 34 коп`; `5` → `0 грн 05 коп`; `100` → `1 грн 00 коп`.

## 4.7 Типові помилки

| Помилка | Приклад | Правильно |
|---------|---------|-----------|
| ділення замість цілочислового | `s / 3600` → `1.034…` | `s // 3600` |
| втрата порядку операцій | `a + b / 2` | `(a + b) / 2` |
| використання змінної до присвоєння | `print(s); s = 1` | спочатку присвоїти |
| переплутані `//` і `%` | `n // 10` як остання цифра | `n % 10` |
| C++: ціле ділення замість дійсного | `(a + b) / 2` для `int` | `(a + b) / 2.0` |
| C++: `1 / 2 * x` | `1 / 2` дорівнює `0` | `1.0 / 2 * x` |
| C++: переповнення `int` | результат більший за ≈ 2,1·10⁹ | `long long` |
| JS: `n / 10` як «число без останньої цифри» | дає дробове число | `Math.floor(n / 10)` |
