# Chapter 4. Linear Algorithms

## 4.1 Definition

A **linear algorithm** (the "sequence" structure) is an algorithm in which
all actions are executed one after another, each exactly once, with no branching
or repetition.

Scheme: `action 1 → action 2 → … → action n`

Typical layout:
```
INPUT the input data
compute intermediate values
compute the result
OUTPUT the result
```

## 4.2 The Assignment Statement

**Python**

```python
variable = expression
```

**C++**

```cpp
// name = expression;
```

**JavaScript**

```javascript
// name = expression;
```

In C++ and JavaScript an assignment is itself an expression (its value is the assigned one), so forms like `x = y = 0` are possible. In Python an assignment is a statement.

Order of execution: **the expression on the right is evaluated first**, then
the result is bound to the name on the left.

**Python**

```python
x = 5
x = x + 3      # computed 5+3=8, then x → 8
```

**C++**

```cpp
int x = 5;
// computed 5+3=8, then x = 8
```

**JavaScript**

```javascript
let x = 5;
// computed 5+3=8, then x = 8
```

### Swapping the Values of Two Variables

The classic way (through a third variable) works in any language:

**Python**

```python
tmp = a
a = b
b = tmp
```

**C++**

```cpp
int tmp = a;
a = b;
b = tmp;
```

**JavaScript**

```javascript
let tmp = a;
a = b;
b = tmp;
```

The Python way (tuple assignment):

**Python**

```python
a, b = b, a
```

**C++**

```cpp
// std::swap, header <utility>
```

**JavaScript**

```javascript
// array destructuring
```

In JavaScript, the line before one that starts with `[` must end with `;`, otherwise the parser will glue them into one expression.

Without a third variable, using arithmetic (a teaching example):

**Python**

```python
a = a + b
b = a - b
a = a - b
```

**C++**

```cpp
a = a + b;
b = a - b;
a = a - b;
```

**JavaScript**

```javascript
a = a + b;
b = a - b;
a = a - b;
```

In C++ this method can overflow `int` for large `a + b`.

### Multiple Assignment

**Python**

```python
x = y = z = 0        # all three refer to one object
a, b, c = 1, 2, 3    # tuple unpacking
```

**C++**

```cpp
int x, y, z;
// evaluated right to left
// tuple unpacking (C++11)
// structured bindings (C++17)
```

**JavaScript**

```javascript

// numbers are copied
// array destructuring
```

## 4.3 Integer Arithmetic — the Main Tool of This Chapter

The operations `//` and `%` let you "take apart" numbers
without converting them to strings.

| Task | Expression |
|------|------------|
| last digit of n | `n % 10` |
| the number without its last digit | `n // 10` |
| second digit from the end | `n // 10 % 10` |
| first digit of a three-digit number | `n // 100` |
| last k digits | `n % 10**k` |
| hours in s seconds | `s // 3600` |
| minutes (excluding hours) | `s % 3600 // 60` |
| kopiykas in an amount given in kopiykas | `c % 100` |

In C++ and JavaScript the same expressions are written as follows: `n % 10`; `n / 10` (C++, for `int`) or `Math.floor(n / 10)` (JavaScript); `n / 100`; `n / 10 % 10`. For non-negative numbers `%` works the same in all three languages.

### Example: reverse a three-digit number

**Python**

```python
n = 473
res = n % 10 * 100 + n // 10 % 10 * 10 + n // 100
print(res)        # 374
```

**C++**

```cpp
int n = 473;
int res = n % 10 * 100 + n / 10 % 10 * 10 + n / 100;
cout << res << endl;         // 374
```

**JavaScript**

```javascript
const n = 473;
const res = (n % 10) * 100 + (Math.floor(n / 10) % 10) * 10 + Math.floor(n / 100);
console.log(res);            // 374
```

### Example: cyclic shift of digits to the left

**Python**

```python
n = 1234
res = n % 1000 * 10 + n // 1000
print(res)        # 2341
```

**C++**

```cpp
int n = 1234;
int res = n % 1000 * 10 + n / 1000;
cout << res << endl;         // 2341
```

**JavaScript**

```javascript
const n = 1234;
const res = (n % 1000) * 10 + Math.floor(n / 1000);
console.log(res);            // 2341
```

## 4.4 Rounding

| Function | 3.5 | 2.5 | −3.7 | Note |
|----------|-----|-----|------|------|
| `int()` | 3 | 2 | −3 | drops the fractional part |
| `round()` | 4 | **2** | −4 | "banker's" rounding to the nearest even |
| `math.floor()` | 3 | 2 | −4 | down |
| `math.ceil()` | 4 | 3 | −3 | up |

Note: `round(2.5)` gives `2`, not `3`. For "school-style" rounding
use `math.floor(x + 0.5)`.

The same operations in C++ and JavaScript:

| Operation | Python | C++ | JavaScript |
|-----|--------|-----|------------|
| drop the fractional part | `int(x)` | `(int)x`, `trunc(x)` | `Math.trunc(x)` |
| down | `math.floor(x)` | `floor(x)` | `Math.floor(x)` |
| up | `math.ceil(x)` | `ceil(x)` | `Math.ceil(x)` |
| to the nearest integer | `round(x)` | `round(x)` | `Math.round(x)` |

The three languages round "halves" differently. For x = 2.5: Python gives 2 (to even), C++ gives 3 (away from zero), JavaScript gives 3 (up). For x = −2.5: Python gives −2, C++ gives −3, JavaScript gives −2 (up).

## 4.5 Formatted Output of Results

**Python**

```python
print(f"{x:.3f}")      # 3 digits after the decimal point
print(f"{x:8.2f}")     # width 8, right-aligned
print(f"{x:<8.2f}|")   # left-aligned
print(f"{n:04d}")      # 0007
print(f"{n:,}")        # 1,234,567
print(f"{x:e}")        # 1.234560e+03
```

**C++**

```cpp
// 3 digits after the decimal point
// width 8, right-aligned
// left-aligned
printf("%04d\n", n);         // 0007
printf("%e\n", x);           // 3.141590e+00
// a thousands separator (1,234,567) needs a locale or manual code
```

**JavaScript**

```javascript
// 3 digits after the decimal point
// width 8, right-aligned
// left-aligned
String(n).padStart(4, "0");         // 0007
(1234567).toLocaleString("en-US");  // 1,234,567
// 3.141590e+0 (exponent without a leading zero)
```

The same with C++ streams: `cout << fixed << setprecision(3) << x`, `setw(8)`, `left`, `setfill('0')` (header `<iomanip>`). `printf` (from `<cstdio>`) is shorter, but does not check types.

## 4.6 A Complete Example

**Problem.** An amount is given in kopiykas. Print it as "X UAH Y kop".

**Python**

```python
total = int(input("Amount in kopiykas: "))
hryvnia = total // 100
kopiyka = total % 100
print(f"{hryvnia} UAH {kopiyka:02d} kop")
```

**C++**

```cpp
long long total;
cout << "Amount in kopiykas: ";
cin >> total;
long long hryvnia = total / 100;
long long kopiyka = total % 100;
cout << hryvnia << " UAH " << setfill('0') << setw(2) << kopiyka << " kop" << endl;
```

**JavaScript**

```javascript
// input (see 3.6)
const total = Number(lines[0]);
const hryvnia = Math.floor(total / 100);
const kopiyka = total % 100;
console.log(`${hryvnia} UAH ${String(kopiyka).padStart(2, "0")} kop`);
```

Tests: `1234` → `12 UAH 34 kop`; `5` → `0 UAH 05 kop`; `100` → `1 UAH 00 kop`.

## 4.7 Common Mistakes

| Mistake | Example | Correct |
|---------|---------|---------|
| division instead of integer division | `s / 3600` → `1.034…` | `s // 3600` |
| wrong order of operations | `a + b / 2` | `(a + b) / 2` |
| using a variable before assignment | `print(s); s = 1` | assign first |
| mixing up `//` and `%` | `n // 10` as the last digit | `n % 10` |
| C++: integer division instead of real | `(a + b) / 2` with `int` | `(a + b) / 2.0` |
| C++: `1 / 2 * x` | `1 / 2` equals `0` | `1.0 / 2 * x` |
| C++: `int` overflow | a result larger than ≈ 2.1·10⁹ | `long long` |
| JS: `n / 10` as "the number without the last digit" | gives a fractional number | `Math.floor(n / 10)` |
