# Practice Tasks for Chapter 4

**Task type:** a linear algorithm with integer arithmetic
(`//`, `%`) — no conditions or loops.

Requirements: read the data from the keyboard and print the result in the specified format.

---

### Task 4.1
A four-digit number is given. Print its digits in reverse order
as a single number.
```
Input:  1234    →    Output: 4321
```

### Task 4.2
A five-digit number is given. Print the sum and the product of its digits.
```
Input:  12345   →    Output: sum = 15, product = 120
```

### Task 4.3
A number of minutes is given. Print how many full days, hours, and minutes that is.
```
Input:  1500    →    Output: 1 day 1 h 0 min
```

### Task 4.4
A three-digit number is given. Swap its first and last digits.
```
Input:  473     →    Output: 374
```

### Task 4.5
A number of days is given. Print how many full weeks and days that is.
```
Input:  25      →    Output: 3 wk 4 d
```

### Task 4.6
An amount in kopiykas is given. Print it as "X UAH Y kop"
(the kopiykas as two digits).
```
Input:  1205    →    Output: 12 UAH 05 kop
```

### Task 4.7
A four-digit number is given. Perform a cyclic shift of its digits to the left
(the first digit becomes the last).
```
Input:  1234    →    Output: 2341
```

### Task 4.8
A number of centimeters is given. Print how many meters
and centimeters that is, and how many full inches (1 inch = 2.54 cm).
```
Input:  375     →    Output: 3 m 75 cm, 147 inches
```

### Task 4.9
A two-digit number is given. Print the number made of the same
digits written in reverse order, and the sum of both numbers.
```
Input:  38      →    Output: 83, sum = 121
```

### Task 4.10
A six-digit number is given — a date in the format `DDMMYY`.
Print it as `DD.MM.20YY`.
```
Input:  150326  →    Output: 15.03.2026
```
