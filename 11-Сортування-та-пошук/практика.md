# Практичні завдання до розділу 11

**Тип завдань:** реалізувати алгоритм сортування або пошуку
**самостійно** (без `sort()`, `sorted()`, `index()`, `in`),
підрахувати кількість порівнянь і обмінів,
перевірити результат на тих самих тестових даних.

Тестові набори для всіх задач:
```
A = [5, 2, 9, 1, 5, 6]        — звичайний, з повтором
B = [1, 2, 3, 4, 5]           — уже відсортований
C = [5, 4, 3, 2, 1]           — зворотний порядок
D = []                        — порожній
E = [7]                       — один елемент
```

---

### Задача 11.1
Реалізувати **сортування вибором**. Вивести кількість
порівнянь і обмінів для кожного тестового набору.

### Задача 11.2
Реалізувати **сортування вставками**. Порівняти кількість
операцій на наборах A, B, C — пояснити різницю.

### Задача 11.3
Реалізувати **сортування бульбашкою** з ранньою зупинкою.
Показати, що на наборі B виконується лише один прохід.

### Задача 11.4
Реалізувати **сортування злиттям** (рекурсивно).
Вивести глибину рекурсії для набору A.

### Задача 11.5
Реалізувати **швидке сортування** (quicksort).
Показати набір, на якому обраний pivot дає гірший випадок.

### Задача 11.6
Реалізувати **сортування за спаданням** і сортування
за ключем (за модулем числа) — на базі будь-якого
з попередніх алгоритмів.
```
[-5, 2, -1, 3] за модулем → [-1, 2, 3, -5]
```

### Задача 11.7
Реалізувати **лінійний пошук**, що повертає індекс
першого входження або −1. Підрахувати кількість порівнянь.
```
A, 9 → індекс 2 (3 порівняння)
A, 100 → -1 (6 порівнянь)
```

### Задача 11.8
Реалізувати **двійковий пошук** ітеративно.
Вивести послідовність перевірених індексів `mid`.
```
[1,3,5,7,9,11], 9 → mid: 2, 4 → індекс 4
```

### Задача 11.9
Реалізувати **двійковий пошук рекурсивно**.
Переконатися, що результат збігається з ітеративним
на всіх елементах відсортованого масиву та на відсутніх значеннях.

### Задача 11.10
Експериментально порівняти час роботи всіх реалізованих
сортувань і вбудованого `sorted()` на випадковому списку
з 2000 елементів. Оформити результат таблицею.
```
вставками   0.0812 с
бульбашкою  0.2451 с
злиттям     0.0051 с
sorted()    0.0002 с
```
