# Розділ 11. Сортування та пошук

## 11.1 Задача сортування

**Дано:** послідовність a[0..n−1].
**Знайти:** перестановку елементів, у якій a[0] ≤ a[1] ≤ … ≤ a[n−1].

### Характеристики алгоритмів сортування

- **Складність** за часом (кращий / середній / гірший випадок).
- **Пам'ять**: *на місці* (in-place, O(1) додаткової) чи ні.
- **Стійкість** (stable): рівні елементи зберігають взаємний порядок.
  Важливо при сортуванні за кількома ключами.
- **Кількість порівнянь і обмінів**.

## 11.2 Прості сортування — O(n²)

### Сортування вибором (selection sort)
На кожному кроці шукаємо мінімум у «невідсортованій» частині
і ставимо його на місце.

**Python**

```python
def selection_sort(a):
    n = len(a)
    for i in range(n - 1):
        mi = i
        for j in range(i + 1, n):
            if a[j] < a[mi]:
                mi = j
        a[i], a[mi] = a[mi], a[i]
    return a
```

**C++**

```cpp
void selection_sort(vector<int> &a) {          // сортує на місці
    int n = a.size();
    for (int i = 0; i < n - 1; ++i) {
        int mi = i;
        for (int j = i + 1; j < n; ++j) {
            if (a[j] < a[mi]) {
                mi = j;
            }
        }
        swap(a[i], a[mi]);
    }
}
```

**JavaScript**

```javascript
function selectionSort(a) {
  const n = a.length;
  for (let i = 0; i < n - 1; i++) {
    let mi = i;
    for (let j = i + 1; j < n; j++) {
      if (a[j] < a[mi]) {
        mi = j;
      }
    }
    [a[i], a[mi]] = [a[mi], a[i]];
  }
  return a;
}
```

У C++ вектор передається за посиланням `&` і сортується на місці, тому `return a` не потрібен.

Порівнянь завжди n(n−1)/2, обмінів ≤ n−1. **Нестійке.**

### Сортування вставками (insertion sort)
Беремо елемент і «вставляємо» на потрібне місце серед попередніх.

**Python**

```python
def insertion_sort(a):
    for i in range(1, len(a)):
        key = a[i]
        j = i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a
```

**C++**

```cpp
void insertion_sort(vector<int> &a) {
    for (size_t i = 1; i < a.size(); ++i) {
        int key = a[i];
        int j = (int)i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
}
```

**JavaScript**

```javascript
function insertionSort(a) {
  for (let i = 1; i < a.length; i++) {
    const key = a[i];
    let j = i - 1;
    while (j >= 0 && a[j] > key) {
      a[j + 1] = a[j];
      j--;
    }
    a[j + 1] = key;
  }
  return a;
}
```

На **майже відсортованих** даних — O(n). **Стійке.**
Найкращий вибір для малих масивів (n < 20).

### Сортування обміном («бульбашка», bubble sort)
Сусідні елементи порівнюються і за потреби обмінюються.

**Python**

```python
def bubble_sort(a):
    n = len(a)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        if not swapped:          # уже відсортовано — вихід
            break
    return a
```

**C++**

```cpp
void bubble_sort(vector<int> &a) {
    int n = a.size();
    for (int i = 0; i < n - 1; ++i) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; ++j) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) {                // уже відсортовано — вихід
            break;
        }
    }
}
```

**JavaScript**

```javascript
function bubbleSort(a) {
  const n = a.length;
  for (let i = 0; i < n - 1; i++) {
    let swapped = false;
    for (let j = 0; j < n - 1 - i; j++) {
      if (a[j] > a[j + 1]) {
        [a[j], a[j + 1]] = [a[j + 1], a[j]];
        swapped = true;
      }
    }
    if (!swapped) {                    // уже відсортовано — вихід
      break;
    }
  }
  return a;
}
```

**Стійке.** Найповільніше з трьох на практиці, але найпростіше.

## 11.3 Швидкі сортування — O(n log n)

### Сортування злиттям (merge sort)
Розділяй і володарюй: ділимо навпіл, сортуємо кожну половину,
зливаємо.

**Python**

```python
def merge_sort(a):
    if len(a) <= 1:
        return a
    mid = len(a) // 2
    left = merge_sort(a[:mid])
    right = merge_sort(a[mid:])
    return merge(left, right)


def merge(x, y):
    res, i, j = [], 0, 0
    while i < len(x) and j < len(y):
        if x[i] <= y[j]:
            res.append(x[i]); i += 1
        else:
            res.append(y[j]); j += 1
    res += x[i:] + y[j:]
    return res
```

**C++**

```cpp
vector<int> merge_vectors(const vector<int> &x, const vector<int> &y) {   // у C++ ім'я merge вже зайняте в std
    vector<int> res;
    size_t i = 0, j = 0;
    while (i < x.size() && j < y.size()) {
        if (x[i] <= y[j]) {
            res.push_back(x[i++]);
        } else {
            res.push_back(y[j++]);
        }
    }
    res.insert(res.end(), x.begin() + i, x.end());
    res.insert(res.end(), y.begin() + j, y.end());
    return res;
}

vector<int> merge_sort(const vector<int> &a) {
    if (a.size() <= 1) {
        return a;
    }
    size_t mid = a.size() / 2;
    vector<int> left = merge_sort(vector<int>(a.begin(), a.begin() + mid));
    vector<int> right = merge_sort(vector<int>(a.begin() + mid, a.end()));
    return merge_vectors(left, right);
}
```

**JavaScript**

```javascript
function mergeSort(a) {
  if (a.length <= 1) {
    return a;
  }
  const mid = Math.floor(a.length / 2);
  const left = mergeSort(a.slice(0, mid));
  const right = mergeSort(a.slice(mid));
  return merge(left, right);
}

function merge(x, y) {
  const res = [];
  let i = 0, j = 0;
  while (i < x.length && j < y.length) {
    if (x[i] <= y[j]) {
      res.push(x[i++]);
    } else {
      res.push(y[j++]);
    }
  }
  return res.concat(x.slice(i), y.slice(j));
}
```

У C++ є готовий алгоритм `merge` (`<algorithm>`) для злиття двох відсортованих діапазонів та `inplace_merge`.

Завжди O(n log n). **Стійке**, але потребує O(n) пам'яті.

### Швидке сортування (quicksort)
Вибираємо опорний елемент (pivot), ділимо на «менші» та «більші».

**Python**

```python
def quick_sort(a):
    if len(a) <= 1:
        return a
    pivot = a[len(a) // 2]
    less = [x for x in a if x < pivot]
    equal = [x for x in a if x == pivot]
    greater = [x for x in a if x > pivot]
    return quick_sort(less) + equal + quick_sort(greater)
```

**C++**

```cpp
vector<int> quick_sort(const vector<int> &a) {
    if (a.size() <= 1) {
        return a;
    }
    int pivot = a[a.size() / 2];
    vector<int> less, equal, greater;
    for (int x : a) {
        if (x < pivot) less.push_back(x);
        else if (x == pivot) equal.push_back(x);
        else greater.push_back(x);
    }
    vector<int> res = quick_sort(less);
    res.insert(res.end(), equal.begin(), equal.end());
    vector<int> right = quick_sort(greater);
    res.insert(res.end(), right.begin(), right.end());
    return res;
}
```

**JavaScript**

```javascript
function quickSort(a) {
  if (a.length <= 1) {
    return a;
  }
  const pivot = a[Math.floor(a.length / 2)];
  const less = a.filter(x => x < pivot);
  const equal = a.filter(x => x === pivot);
  const greater = a.filter(x => x > pivot);
  return [...quickSort(less), ...equal, ...quickSort(greater)];
}
```

Це навчальна версія з O(n) додаткової пам'яті. У реальному коді quicksort виконують «на місці», обмінюючи елементи навколо опорного (схеми Ломуто або Гоара).

Середній випадок O(n log n), гірший — O(n²) (невдалий pivot).
На практиці найшвидше серед порівняльних сортувань.

## 11.4 Порівняльна таблиця

| Алгоритм | Кращий | Середній | Гірший | Пам'ять | Стійке |
|----------|--------|----------|--------|---------|--------|
| вибором | O(n²) | O(n²) | O(n²) | O(1) | ні |
| вставками | O(n) | O(n²) | O(n²) | O(1) | так |
| бульбашкою | O(n) | O(n²) | O(n²) | O(1) | так |
| злиттям | O(n log n) | O(n log n) | O(n log n) | O(n) | так |
| швидке | O(n log n) | O(n log n) | O(n²) | O(log n) | ні |
| `sorted()` (Timsort) | O(n) | O(n log n) | O(n log n) | O(n) | так |

**Теоретична межа** для сортувань на порівняннях: Ω(n log n).

## 11.5 Вбудоване сортування Python

**Python**

```python
a.sort()                              # на місці, повертає None
b = sorted(a)                         # новий список
sorted(a, reverse=True)               # за спаданням
sorted(words, key=len)                # за довжиною
sorted(people, key=lambda p: p[1])    # за другим елементом
sorted(data, key=lambda p: (-p[1], p[0]))   # за двома ключами
```

**C++**

```cpp
sort(a.begin(), a.end());                              // на місці
vector<int> b = a;
sort(b.begin(), b.end());                              // «sorted(a)»: копія + sort
sort(b.begin(), b.end(), greater<int>());              // за спаданням

sort(words.begin(), words.end(),                       // за довжиною
     [](const string &x, const string &y) { return x.size() < y.size(); });

sort(people.begin(), people.end(),                     // за другим елементом
     [](const auto &p, const auto &q) { return p.second < q.second; });

sort(data.begin(), data.end(),                         // за двома ключами
     [](const auto &p, const auto &q) {
         return p.second != q.second ? p.second > q.second : p.first < q.first;
     });
```

**JavaScript**

```javascript
a.sort((x, y) => x - y);                               // на місці (для чисел — з порівнянням!)
const b = [...a].sort((x, y) => x - y);                // «sorted(a)»: новий масив
[...a].sort((x, y) => y - x);                          // за спаданням

[...words].sort((x, y) => x.length - y.length);        // за довжиною
[...people].sort((p, q) => p[1] - q[1]);               // за другим елементом
[...data].sort((p, q) => q[1] - p[1] || p[0].localeCompare(q[0]));   // за двома ключами
```

Алгоритм — **Timsort** (гібрид merge + insertion), стійкий,
використовує вже впорядковані ділянки.

У C++ `std::sort` — це *introsort* (гібрид quicksort, heapsort і insertion sort): O(n log n) навіть у гіршому випадку, але **нестійкий**; стійкий варіант — `std::stable_sort`. У JavaScript `Array.prototype.sort` з 2019 року (ES2019) **стійкий**; у рушії V8 це теж Timsort.

## 11.6 Лінійний пошук — O(n)

**Python**

```python
def linear_search(a, target):
    for i, x in enumerate(a):
        if x == target:
            return i
    return -1
```

**C++**

```cpp
int linear_search(const vector<int> &a, int target) {
    for (size_t i = 0; i < a.size(); ++i) {
        if (a[i] == target) {
            return i;
        }
    }
    return -1;
}
```

**JavaScript**

```javascript
function linearSearch(a, target) {
  for (let i = 0; i < a.length; i++) {
    if (a[i] === target) {
      return i;
    }
  }
  return -1;
}
```

Готові засоби: `find(a.begin(), a.end(), target)` у C++, `a.indexOf(target)` у JavaScript.

Працює на **будь-якому** масиві. Для відсортованого з ранньою
зупинкою: якщо `x > target` — далі шукати немає сенсу.

## 11.7 Двійковий пошук — O(log n)

Працює **лише на відсортованому** масиві.

**Python**

```python
def binary_search(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        if a[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

**C++**

```cpp
int binary_search_index(const vector<int> &a, int target) {   // ім'я binary_search зайняте в std
    int lo = 0, hi = (int)a.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;                         // безпечно від переповнення
        if (a[mid] == target) {
            return mid;
        }
        if (a[mid] < target) {
            lo = mid + 1;
        } else {
            hi = mid - 1;
        }
    }
    return -1;
}
```

**JavaScript**

```javascript
function binarySearch(a, target) {
  let lo = 0, hi = a.length - 1;
  while (lo <= hi) {
    const mid = Math.floor((lo + hi) / 2);
    if (a[mid] === target) {
      return mid;
    }
    if (a[mid] < target) {
      lo = mid + 1;
    } else {
      hi = mid - 1;
    }
  }
  return -1;
}
```

У C++ запис `(lo + hi) / 2` може переповнити `int` для дуже великих масивів, тому пишуть `lo + (hi - lo) / 2`. У Python і JavaScript (для чисел до 2⁵³) цієї проблеми немає.

Рекурсивний варіант:

**Python**

```python
def bsearch_rec(a, target, lo=0, hi=None):
    if hi is None:
        hi = len(a) - 1
    if lo > hi:
        return -1
    mid = (lo + hi) // 2
    if a[mid] == target:
        return mid
    if a[mid] < target:
        return bsearch_rec(a, target, mid + 1, hi)
    return bsearch_rec(a, target, lo, mid - 1)
```

**C++**

```cpp
int bsearch_rec(const vector<int> &a, int target, int lo, int hi) {
    if (lo > hi) {
        return -1;
    }
    int mid = lo + (hi - lo) / 2;
    if (a[mid] == target) {
        return mid;
    }
    if (a[mid] < target) {
        return bsearch_rec(a, target, mid + 1, hi);
    }
    return bsearch_rec(a, target, lo, mid - 1);
}

int bsearch_rec(const vector<int> &a, int target) {          // перевантаження замінює hi=None
    return bsearch_rec(a, target, 0, (int)a.size() - 1);
}
```

**JavaScript**

```javascript
function bsearchRec(a, target, lo = 0, hi = a.length - 1) {  // значення за замовчуванням можуть залежати від попередніх параметрів
  if (lo > hi) {
    return -1;
  }
  const mid = Math.floor((lo + hi) / 2);
  if (a[mid] === target) {
    return mid;
  }
  if (a[mid] < target) {
    return bsearchRec(a, target, mid + 1, hi);
  }
  return bsearchRec(a, target, lo, mid - 1);
}
```

### Чому O(log n)
Кожен крок **вдвічі** зменшує область пошуку:
n → n/2 → n/4 → … → 1, тобто log₂n кроків.

| n | лінійний (гірший) | двійковий |
|---|-------------------|-----------|
| 100 | 100 | 7 |
| 1 000 | 1 000 | 10 |
| 1 000 000 | 1 000 000 | 20 |
| 10⁹ | 10⁹ | 30 |

### Модуль bisect

**Python**

```python
import bisect
bisect.bisect_left(a, x)      # індекс першого ≥ x
bisect.bisect_right(a, x)     # індекс першого > x
bisect.insort(a, x)           # вставити, зберігаючи порядок
```

**C++**

```cpp
lower_bound(a.begin(), a.end(), x) - a.begin();     // bisect_left: індекс першого ≥ x
upper_bound(a.begin(), a.end(), x) - a.begin();     // bisect_right: індекс першого > x
a.insert(upper_bound(a.begin(), a.end(), x), x);    // insort: вставити, зберігаючи порядок
binary_search(a.begin(), a.end(), x);               // чи є x у масиві (bool)
```

**JavaScript**

```javascript
function lowerBound(a, x) {                         // аналог bisect_left
  let lo = 0, hi = a.length;
  while (lo < hi) {
    const mid = (lo + hi) >> 1;
    if (a[mid] < x) lo = mid + 1;
    else hi = mid;
  }
  return lo;
}

function upperBound(a, x) {                         // аналог bisect_right
  let lo = 0, hi = a.length;
  while (lo < hi) {
    const mid = (lo + hi) >> 1;
    if (a[mid] <= x) lo = mid + 1;
    else hi = mid;
  }
  return lo;
}

a.splice(upperBound(a, x), 0, x);                   // insort
```

У JavaScript готових аналогів `bisect` немає — їх пишуть самостійно, як вище.

## 11.8 Коли що використовувати

| Ситуація | Рішення |
|----------|---------|
| один пошук у невідсортованому масиві | лінійний пошук |
| багато пошуків у статичному масиві | відсортувати + двійковий |
| потрібна лише перевірка входження | `set` — O(1) |
| пошук за ключем | `dict` — O(1) |
| реальна робоча задача | `sorted()` / `in` |

Відповідники: C++ — `sort`, `binary_search`, `unordered_set`, `unordered_map`; JavaScript — `sort`, `includes`, `Set`, `Map`.

**Важливо:** сортування коштує O(n log n). Якщо пошук один —
лінійний дешевший, ніж «відсортувати і знайти двійковим».
