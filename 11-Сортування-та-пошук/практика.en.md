# Practice Tasks for Chapter 11

**Task type:** implement a sorting or searching algorithm
**yourself** (without `sort()`, `sorted()`, `index()`, `in`),
count the number of comparisons and swaps,
and check the result on the same test data.

Test sets for all tasks:
```
A = [5, 2, 9, 1, 5, 6]        — ordinary, with a repeat
B = [1, 2, 3, 4, 5]           — already sorted
C = [5, 4, 3, 2, 1]           — reverse order
D = []                        — empty
E = [7]                       — one element
```

---

### Task 11.1
Implement **selection sort**. Print the number of
comparisons and swaps for each test set.

### Task 11.2
Implement **insertion sort**. Compare the number of
operations on sets A, B, C — explain the difference.

### Task 11.3
Implement **bubble sort** with early termination.
Show that on set B only one pass is performed.

### Task 11.4
Implement **merge sort** (recursively).
Print the recursion depth for set A.

### Task 11.5
Implement **quicksort**.
Show a set on which the chosen pivot gives the worst case.

### Task 11.6
Implement **sorting in descending order** and sorting
by a key (by the absolute value of the number) — based on any
of the previous algorithms.
```
[-5, 2, -1, 3] by absolute value → [-1, 2, 3, -5]
```

### Task 11.7
Implement **linear search** that returns the index
of the first occurrence or −1. Count the number of comparisons.
```
A, 9 → index 2 (3 comparisons)
A, 100 → -1 (6 comparisons)
```

### Task 11.8
Implement **binary search** iteratively.
Print the sequence of checked `mid` indices.
```
[1,3,5,7,9,11], 9 → mid: 2, 4 → index 4
```

### Task 11.9
Implement **binary search recursively**.
Make sure the result matches the iterative one
on all elements of a sorted array and on absent values.

### Task 11.10
Experimentally compare the running time of all the implemented
sorts and the built-in `sorted()` on a random list
of 2000 elements. Present the result as a table.
```
insertion   0.0812 s
bubble      0.2451 s
merge       0.0051 s
sorted()    0.0002 s
```
