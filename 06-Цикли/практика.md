# Практичні завдання до розділу 6

**Тип завдань:** обробка натурального числа / послідовності чисел циклом.
Обробку виконувати **накопичувачами** (сума, добуток, лічильник,
максимум) — зберігати всі значення в списку заборонено.
Список допускається лише для складання рядка виводу.

---

### Задача 6.1
Дано натуральне n. Вивести суму й добуток його цифр.
```
12345 → сума = 15, добуток = 120
7     → сума = 7,  добуток = 7
```

### Задача 6.2
Дано натуральне n. Вивести кількість цифр і кількість парних цифр.
```
70524 → цифр = 5, парних = 3    (0, 2, 4)
```

### Задача 6.3
Дано натуральне n. Вивести його найбільшу та найменшу цифри.
```
58391 → max = 9, min = 1
```

### Задача 6.4
Дано натуральне n. Вивести число, записане тими самими цифрами
у зворотному порядку (без використання рядків).
```
12345 → 54321       1200 → 21
```

### Задача 6.5
Дано натуральне n. Вивести всі його дільники та їхню кількість.
```
12 → 1 2 3 4 6 12 (6 дільників)
```

### Задача 6.6
Дано натуральне n. Визначити, чи воно просте
(перевіряти дільники лише до √n).
```
21 → складене      29 → просте      1 → ні просте, ні складене
```

### Задача 6.7
Дано натуральне n. Вивести перші n чисел Фібоначчі та їхню суму.
```
7 → 0 1 1 2 3 5 8, сума = 20
```

### Задача 6.8
Дано натуральне n. Обчислити n! та суму 1! + 2! + … + n!.
```
5 → 5! = 120, сума = 153
```

### Задача 6.9
Дано натуральне n. Вивести всі прості числа від 2 до n
та їхню кількість.
```
20 → 2 3 5 7 11 13 17 19 (8 чисел)
```

### Задача 6.10
Дано натуральне n. Перевірити, чи є число **досконалим**
(рівним сумі своїх дільників, крім самого себе).
```
6  → досконале (1+2+3)        28 → досконале
12 → не досконале
```
