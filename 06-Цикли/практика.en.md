# Practice Tasks for Chapter 6

**Task type:** processing a natural number / a sequence of numbers with a loop.
Do the processing with **accumulators** (sum, product, counter,
maximum) — storing all the values in a list is forbidden.
A list is allowed only for building the output string.

---

### Task 6.1
A natural number n is given. Print the sum and the product of its digits.
```
12345 → sum = 15, product = 120
7     → sum = 7,  product = 7
```

### Task 6.2
A natural number n is given. Print the number of digits and the number of even digits.
```
70524 → digits = 5, even = 3    (0, 2, 4)
```

### Task 6.3
A natural number n is given. Print its largest and smallest digits.
```
58391 → max = 9, min = 1
```

### Task 6.4
A natural number n is given. Print the number written with the same digits
in reverse order (without using strings).
```
12345 → 54321       1200 → 21
```

### Task 6.5
A natural number n is given. Print all its divisors and their count.
```
12 → 1 2 3 4 6 12 (6 divisors)
```

### Task 6.6
A natural number n is given. Determine whether it is prime
(check divisors only up to √n).
```
21 → composite      29 → prime      1 → neither prime nor composite
```

### Task 6.7
A natural number n is given. Print the first n Fibonacci numbers and their sum.
```
7 → 0 1 1 2 3 5 8, sum = 20
```

### Task 6.8
A natural number n is given. Compute n! and the sum 1! + 2! + … + n!.
```
5 → 5! = 120, sum = 153
```

### Task 6.9
A natural number n is given. Print all prime numbers from 2 to n
and their count.
```
20 → 2 3 5 7 11 13 17 19 (8 numbers)
```

### Task 6.10
A natural number n is given. Check whether the number is **perfect**
(equal to the sum of its divisors other than itself).
```
6  → perfect (1+2+3)        28 → perfect
12 → not perfect
```
