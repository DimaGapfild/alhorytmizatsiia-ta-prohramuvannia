# Chapter 6. Loops

## 6.1 Kinds of Loops

| Kind | When to use | Python |
|------|-------------|--------|
| with a parameter (counter) | the number of repetitions is known in advance | `for` |
| with a precondition | the number is unknown, the condition is checked before the body | `while` |
| with a postcondition | the body must run at least once | `while True` + `break` |

## 6.2 The for Loop and range

```python
for i in range(5):            # 0 1 2 3 4
    print(i)

for i in range(1, 6):         # 1 2 3 4 5
    print(i)

for i in range(10, 0, -2):    # 10 8 6 4 2
    print(i)
```

`range(start, stop, step)`:
- `start` is included, `stop` is **not included**;
- `step` may be negative;
- all arguments are integers.

Number of repetitions: `len(range(a, b, s))`.

### Iterating over the elements of a sequence
```python
for ch in "abc":
    print(ch)

for x in [10, 20, 30]:
    print(x)

for i, x in enumerate([10, 20, 30]):    # index + value
    print(i, x)
```

## 6.3 The while Loop

```python
i = 1                 # 1. initialization
while i <= 5:         # 2. continuation condition
    print(i)          # 3. body
    i += 1            # 4. change of the loop variable (!)
```

**The most common mistake** is forgetting step 4 → an infinite loop.
To interrupt execution: `Ctrl+C`.

### Loop with a postcondition (do-while)
Python has no dedicated construct; it is emulated like this:
```python
while True:
    n = int(input("Enter a positive number: "))
    if n > 0:
        break
```

## 6.4 break, continue, else

```python
for x in range(10):
    if x == 3:
        continue       # skip the rest of the body, go to the next iteration
    if x == 7:
        break          # leave the loop completely
    print(x)
else:
    print("the loop finished without break")
```

The `else` block of a loop runs **only if there was no `break`** —
convenient for "found / not found" tasks.

```python
for d in range(2, int(n ** 0.5) + 1):
    if n % d == 0:
        print("composite")
        break
else:
    print("prime")
```

## 6.5 Nested Loops

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}*{j}={i*j}", end="  ")
    print()
```

The total number of iterations of the body is the product of the counts.
`break` leaves only the **inner** loop.

## 6.6 Accumulators — Basic Patterns

| Task | Initialization | Step |
|------|----------------|------|
| sum | `s = 0` | `s += x` |
| product | `p = 1` | `p *= x` |
| count by condition | `k = 0` | `if condition: k += 1` |
| maximum | `m = -float("inf")` | `if x > m: m = x` |
| minimum | `m = float("inf")` | `if x < m: m = x` |
| "all" flag | `flag = True` | `if not condition: flag = False` |
| "at least one" flag | `flag = False` | `if condition: flag = True` |

## 6.7 Classic Algorithms with Loops

### Sum of digits / number of digits
```python
s, k = 0, 0
m = n
while m > 0:
    s += m % 10
    k += 1
    m //= 10
```

### Fibonacci numbers
```python
a, b = 0, 1
for _ in range(n):
    a, b = b, a + b
# a is the n-th Fibonacci number
```

### GCD (Euclid's algorithm with remainder)
```python
while b != 0:
    a, b = b, a % b
# a is the GCD
```

### Fast exponentiation
```python
result, base, e = 1, a, n
while e > 0:
    if e % 2 == 1:
        result *= base
    base *= base
    e //= 2
```

### Primality test
```python
if n < 2:
    prime = False
else:
    prime = True
    d = 2
    while d * d <= n:
        if n % d == 0:
            prime = False
            break
        d += 1
```

## 6.8 Infinite Loops and Their Causes

| Cause | Example |
|-------|---------|
| the condition variable does not change | `while i < 5: print(i)` |
| the condition never becomes false | `while x != 0.1: x += 0.1` (float error) |
| change in the wrong direction | `while i < 5: i -= 1` |
| modifying a list while iterating over it | `for x in lst: lst.remove(x)` |
