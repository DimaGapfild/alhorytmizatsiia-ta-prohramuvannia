# Chapter 6. Loops

## 6.1 Kinds of Loops

| Kind | When to use | Python | C++ | JavaScript |
|-----|----------------------|--------|-----|------------|
| with a parameter (counter) | the number of repetitions is known in advance | `for` | `for` | `for` |
| with a precondition | the number is unknown, the condition is checked before the body | `while` | `while` | `while` |
| with a postcondition | the body must run at least once | `while True` + `break` | `do { } while (...)` | `do { } while (...)` |

## 6.2 The for Loop and range

**Python**

```python
for i in range(5):            # 0 1 2 3 4
    print(i)

for i in range(1, 6):         # 1 2 3 4 5
    print(i)

for i in range(10, 0, -2):    # 10 8 6 4 2
    print(i)
```

**C++**

```cpp
for (int i = 0; i < 5; ++i) {            // 0 1 2 3 4
    cout << i << endl;
}

for (int i = 1; i <= 5; ++i) {           // 1 2 3 4 5
    cout << i << endl;
}

for (int i = 10; i > 0; i -= 2) {        // 10 8 6 4 2
    cout << i << endl;
}
```

**JavaScript**

```javascript
for (let i = 0; i < 5; i++) {            // 0 1 2 3 4
  console.log(i);
}

for (let i = 1; i <= 5; i++) {           // 1 2 3 4 5
  console.log(i);
}

for (let i = 10; i > 0; i -= 2) {        // 10 8 6 4 2
  console.log(i);
}
```

`range(start, stop, step)`:
- `start` is included, `stop` is **not included**;
- `step` may be negative;
- all arguments are integers.

C++ and JavaScript have no `range` function: the `for` loop is written in three parts `for (initialization; condition; step)`. So `range(a, b, s)` → `for (int i = a; i < b; i += s)`, and `range(10, 0, -2)` → `for (int i = 10; i > 0; i -= 2)` (use `>` in the condition for a negative step).

Number of repetitions: `len(range(a, b, s))`.

### Iterating over the elements of a sequence

**Python**

```python
for ch in "abc":
    print(ch)

for x in [10, 20, 30]:
    print(x)

for i, x in enumerate([10, 20, 30]):    # index + value
    print(i, x)
```

**C++**

```cpp
// Latin letters; Cyrillic takes 2 bytes in UTF-8
    cout << ch << endl;
}

vector<int> v = {10, 20, 30};
for (int x : v) {
    cout << x << endl;
}

// index + value
    cout << i << " " << v[i] << endl;
}
```

**JavaScript**

```javascript
for (const ch of "абв") {
  console.log(ch);
}

for (const x of [10, 20, 30]) {
  console.log(x);
}

// index + value
  console.log(i, x);
}
```

The "for each" loop (`for (int x : v)` in C++, `for (const x of arr)` in JavaScript) iterates over values. Do not confuse `for ... of` with `for ... in`: in JavaScript `for ... in` iterates over **keys** (for an array — indices as strings).

## 6.3 The while Loop

**Python**

```python
i = 1                 # 1. initialization
while i <= 5:         # 2. continuation condition
    print(i)          # 3. body
    i += 1            # 4. change of the loop variable (!)
```

**C++**

```cpp
// 1. initialization
// 2. continuation condition
    // 3. body
    // 4. changing the loop variable (!)
}
```

**JavaScript**

```javascript
// 1. initialization
// 2. continuation condition
  // 3. body
  // 4. changing the loop variable (!)
}
```

To interrupt an infinite loop in the terminal: `Ctrl+C` (the same for C++ and Node.js).

**The most common mistake** is forgetting step 4 → an infinite loop.
To interrupt execution: `Ctrl+C`.

### Loop with a postcondition (do-while)
Python has no dedicated construct; it is emulated like this:

**Python**

```python
while True:
    n = int(input("Enter a positive number: "))
    if n > 0:
        break
```

**C++**

```cpp
int n;
do {
    cout << "Enter a positive number: ";
    cin >> n;
} while (n <= 0);
```

**JavaScript**

```javascript
let n;
do {
  // prompt exists in browsers; in Node.js use readline
} while (!(n > 0));
```

C++ and JavaScript have a real post-condition loop `do { ... } while (condition);` — the body runs at least once, and the loop **continues** while the condition is true (in Python the condition for `break` is the opposite one).

## 6.4 break, continue, else

**Python**

```python
for x in range(10):
    if x == 3:
        continue       # skip the rest of the body, go to the next iteration
    if x == 7:
        break          # leave the loop completely
    print(x)
else:
    print("the loop finished without break")
```

**C++**

```cpp
bool broken = false;
for (int x = 0; x < 10; ++x) {
    // skip the rest of the body, go to the next iteration
    // leave the loop completely
        broken = true;
        break;
    }
    cout << x << endl;
}
if (!broken) cout << "the loop finished without break" << endl;
```

**JavaScript**

```javascript
let broken = false;
for (let x = 0; x < 10; x++) {
  // skip the rest of the body, go to the next iteration
  // leave the loop completely
    broken = true;
    break;
  }
  console.log(x);
}
if (!broken) console.log("the loop finished without break");
```

C++ and JavaScript have **no** `else` for loops — a flag (`broken`) is used instead.

The `else` block of a loop runs **only if there was no `break`** —
convenient for "found / not found" tasks.

**Python**

```python
for d in range(2, int(n ** 0.5) + 1):
    if n % d == 0:
        print("composite")
        break
else:
    print("prime")
```

**C++**

```cpp
bool prime = true;
for (int d = 2; d * d <= n; ++d) {
    if (n % d == 0) {
        cout << "composite" << endl;
        prime = false;
        break;
    }
}
if (prime) cout << "prime" << endl;
```

**JavaScript**

```javascript
let prime = true;
for (let d = 2; d * d <= n; d++) {
  if (n % d === 0) {
    console.log("composite");
    prime = false;
    break;
  }
}
if (prime) console.log("prime");
```

## 6.5 Nested Loops

**Python**

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}*{j}={i*j}", end="  ")
    print()
```

**C++**

```cpp
for (int i = 1; i <= 3; ++i) {
    for (int j = 1; j <= 3; ++j) {
        cout << i << "*" << j << "=" << i * j << "  ";
    }
    cout << endl;
}
```

**JavaScript**

```javascript
for (let i = 1; i <= 3; i++) {
  let row = "";
  for (let j = 1; j <= 3; j++) {
    row += `${i}*${j}=${i * j}  `;
  }
  // console.log adds the line break itself
}
```

The total number of iterations of the body is the product of the counts.
`break` leaves only the **inner** loop.

## 6.6 Accumulators — Basic Patterns

| Task | Initialization | Step |
|------|----------------|------|
| sum | `s = 0` | `s += x` |
| product | `p = 1` | `p *= x` |
| count by condition | `k = 0` | `if condition: k += 1` |
| maximum | `m = -float("inf")` | `if x > m: m = x` |
| minimum | `m = float("inf")` | `if x < m: m = x` |
| "all" flag | `flag = True` | `if not condition: flag = False` |
| "at least one" flag | `flag = False` | `if condition: flag = True` |

Initial values for the maximum and the minimum: in C++ — `INT_MIN`/`INT_MAX` (`<climits>`) or `numeric_limits<double>::infinity()`, in JavaScript — `-Infinity` and `Infinity`. The most reliable choice is to take the first element as the initial value.

## 6.7 Classic Algorithms with Loops

### Sum of digits / number of digits

**Python**

```python
s, k = 0, 0
m = n
while m > 0:
    s += m % 10
    k += 1
    m //= 10
```

**C++**

```cpp
int s = 0, k = 0;
int m = n;
while (m > 0) {
    s += m % 10;
    k += 1;
    m /= 10;
}
```

**JavaScript**

```javascript
let s = 0, k = 0;
let m = n;
while (m > 0) {
  s += m % 10;
  k += 1;
  m = Math.floor(m / 10);
}
```

### Fibonacci numbers

**Python**

```python
a, b = 0, 1
for _ in range(n):
    a, b = b, a + b
# a is the n-th Fibonacci number
```

**C++**

```cpp
long long a = 0, b = 1;
for (int i = 0; i < n; ++i) {
    long long next = a + b;
    a = b;
    b = next;
}
// a is the n-th Fibonacci number
```

**JavaScript**

```javascript
let a = 0, b = 1;
for (let i = 0; i < n; i++) {
  [a, b] = [b, a + b];
}
// a is the n-th Fibonacci number
```

`long long` holds Fibonacci numbers only up to F(92); a JavaScript `number` is exact only up to F(78). Beyond that you need `BigInt` (JavaScript) or your own long arithmetic (C++); Python has long arithmetic out of the box.

### GCD (Euclid's algorithm with remainder)

**Python**

```python
while b != 0:
    a, b = b, a % b
# a is the GCD
```

**C++**

```cpp
while (b != 0) {
    int t = a % b;
    a = b;
    b = t;
}
// a is the GCD
```

**JavaScript**

```javascript
while (b !== 0) {
  [a, b] = [b, a % b];
}
// a is the GCD
```

C++17 has a ready-made `gcd(a, b)` (`<numeric>`).

### Fast exponentiation

**Python**

```python
result, base, e = 1, a, n
while e > 0:
    if e % 2 == 1:
        result *= base
    base *= base
    e //= 2
```

**C++**

```cpp
long long result = 1, base = a;
int e = n;
while (e > 0) {
    if (e % 2 == 1) {
        result *= base;
    }
    base *= base;
    e /= 2;
}
```

**JavaScript**

```javascript
let result = 1, base = a, e = n;
while (e > 0) {
  if (e % 2 === 1) {
    result *= base;
  }
  base *= base;
  e = Math.floor(e / 2);
}
```

The result in C++ is limited by the width of `long long`, in JavaScript by the precision of `number` (up to 2⁵³); for large powers in JavaScript use `BigInt` (`result = 1n`, `base = BigInt(a)`).

### Primality test

**Python**

```python
if n < 2:
    prime = False
else:
    prime = True
    d = 2
    while d * d <= n:
        if n % d == 0:
            prime = False
            break
        d += 1
```

**C++**

```cpp
bool prime;
if (n < 2) {
    prime = false;
} else {
    prime = true;
    long long d = 2;
    while (d * d <= n) {
        if (n % d == 0) {
            prime = false;
            break;
        }
        d += 1;
    }
}
```

**JavaScript**

```javascript
let prime;
if (n < 2) {
  prime = false;
} else {
  prime = true;
  let d = 2;
  while (d * d <= n) {
    if (n % d === 0) {
      prime = false;
      break;
    }
    d += 1;
  }
}
```

## 6.8 Infinite Loops and Their Causes

| Cause | Example |
|-------|---------|
| the condition variable does not change | `while i < 5: print(i)` |
| the condition never becomes false | `while x != 0.1: x += 0.1` (float error) |
| change in the wrong direction | `while i < 5: i -= 1` |
| modifying a list while iterating over it | `for x in lst: lst.remove(x)` |
