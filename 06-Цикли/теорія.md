# Розділ 6. Цикли

## 6.1 Види циклів

| Вид | Коли використовувати | Python |
|-----|----------------------|--------|
| з параметром (лічильником) | кількість повторень відома заздалегідь | `for` |
| з передумовою | кількість невідома, умова перевіряється до тіла | `while` |
| з постумовою | тіло має виконатись хоча б раз | `while True` + `break` |

## 6.2 Цикл for і range

```python
for i in range(5):            # 0 1 2 3 4
    print(i)

for i in range(1, 6):         # 1 2 3 4 5
    print(i)

for i in range(10, 0, -2):    # 10 8 6 4 2
    print(i)
```

`range(start, stop, step)`:
- `start` включається, `stop` **не включається**;
- `step` може бути від'ємним;
- усі аргументи — цілі.

Кількість повторень: `len(range(a, b, s))`.

### Перебір елементів послідовності
```python
for ch in "абв":
    print(ch)

for x in [10, 20, 30]:
    print(x)

for i, x in enumerate([10, 20, 30]):    # індекс + значення
    print(i, x)
```

## 6.3 Цикл while

```python
i = 1                 # 1. ініціалізація
while i <= 5:         # 2. умова продовження
    print(i)          # 3. тіло
    i += 1            # 4. зміна змінної циклу (!)
```

**Найчастіша помилка** — забути крок 4 → нескінченний цикл.
Перервати виконання: `Ctrl+C`.

### Цикл з постумовою (do-while)
У Python немає окремої конструкції, емулюється так:
```python
while True:
    n = int(input("Введіть додатне число: "))
    if n > 0:
        break
```

## 6.4 break, continue, else

```python
for x in range(10):
    if x == 3:
        continue       # пропустити решту тіла, перейти до наступної ітерації
    if x == 7:
        break          # вийти з циклу повністю
    print(x)
else:
    print("цикл завершився без break")
```

Блок `else` при циклі виконується **лише якщо не було `break`** —
зручно для задач «знайти / не знайдено».

```python
for d in range(2, int(n ** 0.5) + 1):
    if n % d == 0:
        print("складене")
        break
else:
    print("просте")
```

## 6.5 Вкладені цикли

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}*{j}={i*j}", end="  ")
    print()
```

Загальна кількість ітерацій тіла — добуток кількостей.
`break` виходить лише з **внутрішнього** циклу.

## 6.6 Накопичувачі — базові шаблони

| Задача | Ініціалізація | Крок |
|--------|---------------|------|
| сума | `s = 0` | `s += x` |
| добуток | `p = 1` | `p *= x` |
| кількість за умовою | `k = 0` | `if умова: k += 1` |
| максимум | `m = -float("inf")` | `if x > m: m = x` |
| мінімум | `m = float("inf")` | `if x < m: m = x` |
| ознака «усі» | `flag = True` | `if not умова: flag = False` |
| ознака «хоча б один» | `flag = False` | `if умова: flag = True` |

## 6.7 Класичні алгоритми з циклами

### Сума цифр / кількість цифр
```python
s, k = 0, 0
m = n
while m > 0:
    s += m % 10
    k += 1
    m //= 10
```

### Числа Фібоначчі
```python
a, b = 0, 1
for _ in range(n):
    a, b = b, a + b
# a — n-те число Фібоначчі
```

### НСД (алгоритм Евкліда з остачею)
```python
while b != 0:
    a, b = b, a % b
# a — НСД
```

### Швидке піднесення до степеня
```python
result, base, e = 1, a, n
while e > 0:
    if e % 2 == 1:
        result *= base
    base *= base
    e //= 2
```

### Перевірка на простоту
```python
if n < 2:
    prime = False
else:
    prime = True
    d = 2
    while d * d <= n:
        if n % d == 0:
            prime = False
            break
        d += 1
```

## 6.8 Нескінченні цикли та їх причини

| Причина | Приклад |
|---------|---------|
| не змінюється змінна умови | `while i < 5: print(i)` |
| умова ніколи не стає хибною | `while x != 0.1: x += 0.1` (похибка float) |
| зміна в неправильний бік | `while i < 5: i -= 1` |
| модифікація списку під час перебору | `for x in lst: lst.remove(x)` |
