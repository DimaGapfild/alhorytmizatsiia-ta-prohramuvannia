# Розділ 6. Цикли

## 6.1 Види циклів

| Вид | Коли використовувати | Python | C++ | JavaScript |
|-----|----------------------|--------|-----|------------|
| з параметром (лічильником) | кількість повторень відома заздалегідь | `for` | `for` | `for` |
| з передумовою | кількість невідома, умова перевіряється до тіла | `while` | `while` | `while` |
| з постумовою | тіло має виконатись хоча б раз | `while True` + `break` | `do { } while (...)` | `do { } while (...)` |

## 6.2 Цикл for і range

**Python**

```python
for i in range(5):            # 0 1 2 3 4
    print(i)

for i in range(1, 6):         # 1 2 3 4 5
    print(i)

for i in range(10, 0, -2):    # 10 8 6 4 2
    print(i)
```

**C++**

```cpp
for (int i = 0; i < 5; ++i) {            // 0 1 2 3 4
    cout << i << endl;
}

for (int i = 1; i <= 5; ++i) {           // 1 2 3 4 5
    cout << i << endl;
}

for (int i = 10; i > 0; i -= 2) {        // 10 8 6 4 2
    cout << i << endl;
}
```

**JavaScript**

```javascript
for (let i = 0; i < 5; i++) {            // 0 1 2 3 4
  console.log(i);
}

for (let i = 1; i <= 5; i++) {           // 1 2 3 4 5
  console.log(i);
}

for (let i = 10; i > 0; i -= 2) {        // 10 8 6 4 2
  console.log(i);
}
```

`range(start, stop, step)`:
- `start` включається, `stop` **не включається**;
- `step` може бути від'ємним;
- усі аргументи — цілі.

У C++ і JavaScript функції `range` немає: цикл `for` записують із трьох частин `for (ініціалізація; умова; крок)`. Тому `range(a, b, s)` → `for (int i = a; i < b; i += s)`, а `range(10, 0, -2)` → `for (int i = 10; i > 0; i -= 2)` (для від'ємного кроку умова з `>`).

Кількість повторень: `len(range(a, b, s))`.

### Перебір елементів послідовності

**Python**

```python
for ch in "абв":
    print(ch)

for x in [10, 20, 30]:
    print(x)

for i, x in enumerate([10, 20, 30]):    # індекс + значення
    print(i, x)
```

**C++**

```cpp
for (char ch : string("abc")) {          // латиниця; кирилиця в UTF-8 займає 2 байти
    cout << ch << endl;
}

vector<int> v = {10, 20, 30};
for (int x : v) {
    cout << x << endl;
}

for (size_t i = 0; i < v.size(); ++i) {  // індекс + значення
    cout << i << " " << v[i] << endl;
}
```

**JavaScript**

```javascript
for (const ch of "абв") {
  console.log(ch);
}

for (const x of [10, 20, 30]) {
  console.log(x);
}

for (const [i, x] of [10, 20, 30].entries()) {   // індекс + значення
  console.log(i, x);
}
```

Цикл «для кожного» (`for (int x : v)` у C++, `for (const x of arr)` у JavaScript) перебирає значення. Не плутайте `for ... of` з `for ... in`: у JavaScript `for ... in` перебирає **ключі** (для масиву — індекси як рядки).

## 6.3 Цикл while

**Python**

```python
i = 1                 # 1. ініціалізація
while i <= 5:         # 2. умова продовження
    print(i)          # 3. тіло
    i += 1            # 4. зміна змінної циклу (!)
```

**C++**

```cpp
int i = 1;                      // 1. ініціалізація
while (i <= 5) {                // 2. умова продовження
    cout << i << endl;          // 3. тіло
    i += 1;                     // 4. зміна змінної циклу (!)
}
```

**JavaScript**

```javascript
let i = 1;                      // 1. ініціалізація
while (i <= 5) {                // 2. умова продовження
  console.log(i);               // 3. тіло
  i += 1;                       // 4. зміна змінної циклу (!)
}
```

Перервати нескінченний цикл у терміналі: `Ctrl+C` (так само для C++ і Node.js).

**Найчастіша помилка** — забути крок 4 → нескінченний цикл.
Перервати виконання: `Ctrl+C`.

### Цикл з постумовою (do-while)
У Python немає окремої конструкції, емулюється так:

**Python**

```python
while True:
    n = int(input("Введіть додатне число: "))
    if n > 0:
        break
```

**C++**

```cpp
int n;
do {
    cout << "Введіть додатне число: ";
    cin >> n;
} while (n <= 0);
```

**JavaScript**

```javascript
let n;
do {
  n = Number(prompt("Введіть додатне число: "));   // prompt є в браузері; у Node.js — readline
} while (!(n > 0));
```

У C++ і JavaScript є справжній цикл із постумовою `do { ... } while (умова);` — тіло виконується хоча б раз, а цикл **продовжується**, поки умова істинна (у Python умова для `break` — протилежна).

## 6.4 break, continue, else

**Python**

```python
for x in range(10):
    if x == 3:
        continue       # пропустити решту тіла, перейти до наступної ітерації
    if x == 7:
        break          # вийти з циклу повністю
    print(x)
else:
    print("цикл завершився без break")
```

**C++**

```cpp
bool broken = false;
for (int x = 0; x < 10; ++x) {
    if (x == 3) continue;       // пропустити решту тіла, перейти до наступної ітерації
    if (x == 7) {               // вийти з циклу повністю
        broken = true;
        break;
    }
    cout << x << endl;
}
if (!broken) cout << "цикл завершився без break" << endl;
```

**JavaScript**

```javascript
let broken = false;
for (let x = 0; x < 10; x++) {
  if (x === 3) continue;        // пропустити решту тіла, перейти до наступної ітерації
  if (x === 7) {                // вийти з циклу повністю
    broken = true;
    break;
  }
  console.log(x);
}
if (!broken) console.log("цикл завершився без break");
```

Конструкції `else` для циклу в C++ і JavaScript **немає** — замість неї використовують прапорець (`broken`).

Блок `else` при циклі виконується **лише якщо не було `break`** —
зручно для задач «знайти / не знайдено».

**Python**

```python
for d in range(2, int(n ** 0.5) + 1):
    if n % d == 0:
        print("складене")
        break
else:
    print("просте")
```

**C++**

```cpp
bool prime = true;
for (int d = 2; d * d <= n; ++d) {
    if (n % d == 0) {
        cout << "складене" << endl;
        prime = false;
        break;
    }
}
if (prime) cout << "просте" << endl;
```

**JavaScript**

```javascript
let prime = true;
for (let d = 2; d * d <= n; d++) {
  if (n % d === 0) {
    console.log("складене");
    prime = false;
    break;
  }
}
if (prime) console.log("просте");
```

## 6.5 Вкладені цикли

**Python**

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}*{j}={i*j}", end="  ")
    print()
```

**C++**

```cpp
for (int i = 1; i <= 3; ++i) {
    for (int j = 1; j <= 3; ++j) {
        cout << i << "*" << j << "=" << i * j << "  ";
    }
    cout << endl;
}
```

**JavaScript**

```javascript
for (let i = 1; i <= 3; i++) {
  let row = "";
  for (let j = 1; j <= 3; j++) {
    row += `${i}*${j}=${i * j}  `;
  }
  console.log(row);               // console.log сам додає перехід на новий рядок
}
```

Загальна кількість ітерацій тіла — добуток кількостей.
`break` виходить лише з **внутрішнього** циклу.

## 6.6 Накопичувачі — базові шаблони

| Задача | Ініціалізація | Крок |
|--------|---------------|------|
| сума | `s = 0` | `s += x` |
| добуток | `p = 1` | `p *= x` |
| кількість за умовою | `k = 0` | `if умова: k += 1` |
| максимум | `m = -float("inf")` | `if x > m: m = x` |
| мінімум | `m = float("inf")` | `if x < m: m = x` |
| ознака «усі» | `flag = True` | `if not умова: flag = False` |
| ознака «хоча б один» | `flag = False` | `if умова: flag = True` |

Початкові значення для максимуму та мінімуму: у C++ — `INT_MIN`/`INT_MAX` (`<climits>`) або `numeric_limits<double>::infinity()`, у JavaScript — `-Infinity` та `Infinity`. Надійніше за все взяти за початкове значення перший елемент.

## 6.7 Класичні алгоритми з циклами

### Сума цифр / кількість цифр

**Python**

```python
s, k = 0, 0
m = n
while m > 0:
    s += m % 10
    k += 1
    m //= 10
```

**C++**

```cpp
int s = 0, k = 0;
int m = n;
while (m > 0) {
    s += m % 10;
    k += 1;
    m /= 10;
}
```

**JavaScript**

```javascript
let s = 0, k = 0;
let m = n;
while (m > 0) {
  s += m % 10;
  k += 1;
  m = Math.floor(m / 10);
}
```

### Числа Фібоначчі

**Python**

```python
a, b = 0, 1
for _ in range(n):
    a, b = b, a + b
# a — n-те число Фібоначчі
```

**C++**

```cpp
long long a = 0, b = 1;
for (int i = 0; i < n; ++i) {
    long long next = a + b;
    a = b;
    b = next;
}
// a — n-те число Фібоначчі
```

**JavaScript**

```javascript
let a = 0, b = 1;
for (let i = 0; i < n; i++) {
  [a, b] = [b, a + b];
}
// a — n-те число Фібоначчі
```

`long long` вміщує числа Фібоначчі лише до F(92); `number` у JavaScript — точно лише до F(78). Далі потрібен `BigInt` (JavaScript) або власна довга арифметика (C++); Python має довгу арифметику «з коробки».

### НСД (алгоритм Евкліда з остачею)

**Python**

```python
while b != 0:
    a, b = b, a % b
# a — НСД
```

**C++**

```cpp
while (b != 0) {
    int t = a % b;
    a = b;
    b = t;
}
// a — НСД
```

**JavaScript**

```javascript
while (b !== 0) {
  [a, b] = [b, a % b];
}
// a — НСД
```

У C++17 є готова `gcd(a, b)` (`<numeric>`).

### Швидке піднесення до степеня

**Python**

```python
result, base, e = 1, a, n
while e > 0:
    if e % 2 == 1:
        result *= base
    base *= base
    e //= 2
```

**C++**

```cpp
long long result = 1, base = a;
int e = n;
while (e > 0) {
    if (e % 2 == 1) {
        result *= base;
    }
    base *= base;
    e /= 2;
}
```

**JavaScript**

```javascript
let result = 1, base = a, e = n;
while (e > 0) {
  if (e % 2 === 1) {
    result *= base;
  }
  base *= base;
  e = Math.floor(e / 2);
}
```

Результат у C++ обмежений розрядністю `long long`, у JavaScript — точністю `number` (до 2⁵³); для великих степенів у JavaScript використовують `BigInt` (`result = 1n`, `base = BigInt(a)`).

### Перевірка на простоту

**Python**

```python
if n < 2:
    prime = False
else:
    prime = True
    d = 2
    while d * d <= n:
        if n % d == 0:
            prime = False
            break
        d += 1
```

**C++**

```cpp
bool prime;
if (n < 2) {
    prime = false;
} else {
    prime = true;
    long long d = 2;
    while (d * d <= n) {
        if (n % d == 0) {
            prime = false;
            break;
        }
        d += 1;
    }
}
```

**JavaScript**

```javascript
let prime;
if (n < 2) {
  prime = false;
} else {
  prime = true;
  let d = 2;
  while (d * d <= n) {
    if (n % d === 0) {
      prime = false;
      break;
    }
    d += 1;
  }
}
```

## 6.8 Нескінченні цикли та їх причини

| Причина | Приклад |
|---------|---------|
| не змінюється змінна умови | `while i < 5: print(i)` |
| умова ніколи не стає хибною | `while x != 0.1: x += 0.1` (похибка float) |
| зміна в неправильний бік | `while i < 5: i -= 1` |
| модифікація списку під час перебору | `for x in lst: lst.remove(x)` |
