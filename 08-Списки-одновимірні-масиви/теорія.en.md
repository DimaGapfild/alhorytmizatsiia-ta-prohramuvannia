# Chapter 8. Lists (One-Dimensional Arrays)

## 8.1 The Concepts of Array and List

An **array** is a collection of elements of the same type accessed by index.
In Python the role of an array is played by the **list** (`list`) — a mutable
sequence of elements of **any** types.

In C++ the closest counterpart is `vector<T>` (header `<vector>`): a dynamic array whose elements all have **one** type `T`. There are also fixed-size arrays: the C array `int a[5]` and `array<int, 5>`. In JavaScript it is the `Array`, which, like a Python list, can hold values of any types.

**Python**

```python
a = [10, 20, 30]
a = []                      # empty
a = [0] * 5                 # [0, 0, 0, 0, 0]
a = list(range(1, 6))       # [1, 2, 3, 4, 5]
a = list("abc")             # ['a', 'b', 'c']
```

**C++**

```cpp
vector<int> a = {10, 20, 30};
// empty
a.assign(5, 0);                          // {0, 0, 0, 0, 0}
vector<int> r(5);
iota(r.begin(), r.end(), 1);             // {1, 2, 3, 4, 5}   (<numeric>)
string t = "abc";
vector<char> c(t.begin(), t.end());      // {'a', 'b', 'c'}
```

**JavaScript**

```javascript
let a = [10, 20, 30];
// empty
a = new Array(5).fill(0);                // [0, 0, 0, 0, 0]
a = Array.from({ length: 5 }, (_, i) => i + 1);   // [1, 2, 3, 4, 5]
a = [..."abc"];                          // ['a', 'b', 'c']
```

## 8.4 List Methods

| Method | Action | Complexity |
|--------|--------|------------|
| `a.append(x)` | add to the end | O(1) |
| `a.insert(i, x)` | insert at an index | O(n) |
| `a.extend(b)` / `a += b` | add all elements of b | O(k) |
| `a.pop()` | remove and return the last | O(1) |
| `a.pop(i)` | remove by index | O(n) |
| `a.remove(x)` | remove the **first** occurrence of x | O(n) |
| `a.index(x)` | index of the first occurrence | O(n) |
| `a.count(x)` | number of occurrences | O(n) |
| `a.sort()` | sort **in place** | O(n log n) |
| `a.reverse()` | reverse in place | O(n) |
| `a.clear()` | clear | O(1) |
| `a.copy()` | shallow copy | O(n) |

Counterparts of the methods in C++ (`vector`) and JavaScript:

| Python | C++ (`vector`) | JavaScript |
|--------|----------------|------------|
| `a.append(x)` | `a.push_back(x)` | `a.push(x)` |
| `a.insert(i, x)` | `a.insert(a.begin() + i, x)` | `a.splice(i, 0, x)` |
| `a.extend(b)` | `a.insert(a.end(), b.begin(), b.end())` | `a.push(...b)` |
| `a.pop()` | `a.pop_back()` (returns nothing) | `a.pop()` |
| `a.pop(i)` | `a.erase(a.begin() + i)` | `a.splice(i, 1)` |
| `a.remove(x)` | `a.erase(find(a.begin(), a.end(), x))` | `a.splice(a.indexOf(x), 1)` |
| `a.index(x)` | `find(a.begin(), a.end(), x) - a.begin()` | `a.indexOf(x)` |
| `a.count(x)` | `count(a.begin(), a.end(), x)` | `a.filter(v => v === x).length` |
| `a.sort()` | `sort(a.begin(), a.end())` | `a.sort((p, q) => p - q)` |
| `a.reverse()` | `reverse(a.begin(), a.end())` | `a.reverse()` |
| `a.clear()` | `a.clear()` | `a.length = 0` |
| `a.copy()` | `vector<int> b = a;` | `[...a]` or `a.slice()` |

**Warning:** `a.sort()` in JavaScript without a comparison function sorts the elements **as strings**: `[10, 9, 1].sort()` gives `[1, 10, 9]`. For numbers always pass `(p, q) => p - q`.

## 8.5 Built-in Functions

**Python**

```python
sum(a)        min(a)        max(a)        len(a)
sorted(a)                   # a new sorted list
sorted(a, reverse=True)
sorted(a, key=abs)          # by a key
any(x > 0 for x in a)       # at least one
all(x > 0 for x in a)       # all
```

**C++**

```cpp
accumulate(a.begin(), a.end(), 0);                   // sum   (<numeric>)
*min_element(a.begin(), a.end());                    // min
*max_element(a.begin(), a.end());                    // max
a.size();                                            // len

// sorted(a): a copy + sort
// a new sorted vector
sort(s.begin(), s.end(), greater<int>());            // reverse=True
sort(s.begin(), s.end(), [](int p, int q) { return abs(p) < abs(q); });   // key=abs

// at least one
// all
```

**JavaScript**

```javascript
a.reduce((p, q) => p + q, 0);                        // sum
Math.min(...a);                                      // min
Math.max(...a);                                      // max
a.length;                                            // len

// sorted(a): a new sorted array
[...a].sort((p, q) => q - p);                        // reverse=True
[...a].sort((p, q) => Math.abs(p) - Math.abs(q));    // key=abs

// at least one
// all
```

In C++ and JavaScript `sort` changes the container **in place**; to keep the original, copy it first.

## 8.6 Copying — Important!

**Python**

```python
b = a            # NOT a copy: two names for one list
b = a.copy()     # a copy
b = a[:]         # a copy
b = list(a)      # a copy
```

**C++**

```cpp
// a reference: r is a second name of the same vector (like b = a in Python)
// a copy
// a copy
// a copy
```

**JavaScript**

```javascript
// NOT a copy: two names for one array
// a copy
// a copy
// a copy
```

All these copies are **shallow**: for nested arrays the inner elements remain shared (in JavaScript `structuredClone(a)` makes a full copy).

**Python**

```python
a = [1, 2, 3]
b = a
b[0] = 99
print(a)         # [99, 2, 3]  — a changed too!
```

**C++**

```cpp
vector<int> a = {1, 2, 3};
// a copy: b is an independent vector
b[0] = 99;
// 1 — a did not change (unlike Python)

// a reference to a
c[0] = 99;
// 99 — a changed too
```

**JavaScript**

```javascript
const a = [1, 2, 3];
const b = a;
b[0] = 99;
// [ 99, 2, 3 ] — a changed too!
```

In C++ value types (`vector`, `string`) are **copied** by default; in Python and JavaScript arrays/lists are passed **by reference**. This is one of the most important differences.

## 8.7 List Comprehensions

**Python**

```python
[x ** 2 for x in range(5)]               # [0, 1, 4, 9, 16]
[x for x in a if x > 0]                  # filter
[x if x > 0 else 0 for x in a]           # transformation
[abs(x) for x in a]
```

**C++**

```cpp
vector<int> sq;
for (int x = 0; x < 5; ++x) sq.push_back(x * x);     // {0, 1, 4, 9, 16}

vector<int> pos;
// filter

vector<int> t(a.size());
// transformation
transform(a.begin(), a.end(), t.begin(), [](int x) { return abs(x); });
```

**JavaScript**

```javascript
Array.from({ length: 5 }, (_, x) => x ** 2);         // [0, 1, 4, 9, 16]
// filter
// transformation
a.map(x => Math.abs(x));
```

C++ has no list comprehensions (there are the `copy_if` and `transform` algorithms); in JavaScript the `map` and `filter` methods replace them.

It reads like a "mathematical set description" and runs faster than a loop
with `append`.

## 8.8 Iterating over a List

**Python**

```python
for x in a:                  # by values (the element cannot be changed)
    print(x)

for i in range(len(a)):      # by indices (can modify)
    a[i] *= 2

for i, x in enumerate(a):    # index + value
    print(i, x)

for x, y in zip(a, b):       # two lists in parallel
    print(x + y)
```

**C++**

```cpp
// by values (x is a copy, the element cannot be changed)
    cout << x << endl;
}

// by indices (can be modified)
    a[i] *= 2;
}

// by reference — can be modified too
    x += 1;
}

// index + value
    cout << i << " " << a[i] << endl;
}

// two vectors in parallel
    cout << a[i] + b[i] << endl;
}
```

**JavaScript**

```javascript
// by values
  console.log(x);
}

// by indices (can be modified)
  a[i] *= 2;
}

// index + value
  console.log(i, x);
}

// two arrays in parallel
  console.log(x + b[i]);
});
```

**Do not change the length of a list while iterating over it** — this leads
to skipped elements.

## 8.9 Classic Algorithms

### Sum, count by condition

**Python**

```python
s = sum(a)
k = sum(1 for x in a if x > 0)
```

**C++**

```cpp
int s = accumulate(a.begin(), a.end(), 0);
int k = count_if(a.begin(), a.end(), [](int x) { return x > 0; });
```

**JavaScript**

```javascript
const s = a.reduce((p, q) => p + q, 0);
const k = a.filter(x => x > 0).length;
```

### Maximum and its index

**Python**

```python
m = a[0]
pos = 0
for i in range(1, len(a)):
    if a[i] > m:
        m, pos = a[i], i
# or: pos = a.index(max(a))
```

**C++**

```cpp
int m = a[0];
int pos = 0;
for (size_t i = 1; i < a.size(); ++i) {
    if (a[i] > m) {
        m = a[i];
        pos = i;
    }
}
// or: pos = max_element(a.begin(), a.end()) - a.begin();
```

**JavaScript**

```javascript
let m = a[0];
let pos = 0;
for (let i = 1; i < a.length; i++) {
  if (a[i] > m) {
    m = a[i];
    pos = i;
  }
}
// or: pos = a.indexOf(Math.max(...a));
```

### Swapping two elements

**Python**

```python
a[i], a[j] = a[j], a[i]
```

**C++**

```cpp

```

**JavaScript**


### Reversing in place (without a slice)

**Python**

```python
for i in range(len(a) // 2):
    a[i], a[-1 - i] = a[-1 - i], a[i]
```

**C++**

```cpp
for (size_t i = 0; i < a.size() / 2; ++i) {
    swap(a[i], a[a.size() - 1 - i]);
}
// or: reverse(a.begin(), a.end());
```

**JavaScript**

```javascript
for (let i = 0; i < Math.floor(a.length / 2); i++) {
  [a[i], a[a.length - 1 - i]] = [a[a.length - 1 - i], a[i]];
}
// or: a.reverse();
```


**JavaScript**

### Remove all elements that satisfy a condition

**Python**

```python
a = [x for x in a if not condition(x)]       # correct
```

**C++**

```cpp
a.erase(remove_if(a.begin(), a.end(), condition), a.end());     // correct: the erase–remove idiom
// C++20: erase_if(a, condition);
```

**JavaScript**

```javascript
a = a.filter(x => !condition(x));                               // correct
```

In C++ `remove_if` only moves the elements to keep to the front, and `erase` actually shortens the vector.

### Merging two sorted lists

**Python**

```python
res, i, j = [], 0, 0
while i < len(a) and j < len(b):
    if a[i] <= b[j]:
        res.append(a[i]); i += 1
    else:
        res.append(b[j]); j += 1
res += a[i:] + b[j:]
```

**C++**

```cpp
vector<int> res;
size_t i = 0, j = 0;
while (i < a.size() && j < b.size()) {
    if (a[i] <= b[j]) {
        res.push_back(a[i]);
        i++;
    } else {
        res.push_back(b[j]);
        j++;
    }
}
res.insert(res.end(), a.begin() + i, a.end());
res.insert(res.end(), b.begin() + j, b.end());
// ready-made: merge(a.begin(), a.end(), b.begin(), b.end(), back_inserter(res));
```

**JavaScript**

```javascript
const res = [];
let i = 0, j = 0;
while (i < a.length && j < b.length) {
  if (a[i] <= b[j]) {
    res.push(a[i]);
    i++;
  } else {
    res.push(b[j]);
    j++;
  }
}
res.push(...a.slice(i), ...b.slice(j));
```

## 8.10 Common Mistakes

| Mistake | Cause |
|---------|-------|
| `IndexError: list index out of range` | accessing `a[len(a)]` |
| `b = a` does not give a copy | lists are references |
| `a.sort()` returns `None` | it sorts in place; use `sorted(a)` |
| skipped elements in a loop | removal during iteration |
| `[0] * n` for a matrix | all rows are the same list |
| C++: `a[i]` outside a `vector` | undefined behaviour, no exception (the safe way is `a.at(i)`) |
| C++: `a.size() - 1` for an empty vector | `size()` is unsigned: `0 - 1` gives a huge number |
| JS: `a.sort()` for numbers | sorts as strings; `(p, q) => p - q` is needed |
| JS: `a[10] = 1` beyond the array | the array becomes "holey", `length` grows to 11 |
