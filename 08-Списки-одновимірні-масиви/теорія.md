# Розділ 8. Списки (одновимірні масиви)

## 8.1 Поняття масиву і списку

**Масив** — набір однотипних елементів, доступних за індексом.
У Python роль масиву виконує **список** (`list`) — змінна
послідовність елементів **будь-яких** типів.

У C++ ближчий аналог — `vector<T>` (заголовок `<vector>`): динамічний масив, елементи якого мають **один** тип `T`. Є ще масиви фіксованого розміру: C-масив `int a[5]` та `array<int, 5>`. У JavaScript — масив `Array`, який, як і список Python, може містити значення будь-яких типів.

**Python**

```python
a = [10, 20, 30]
a = []                      # порожній
a = [0] * 5                 # [0, 0, 0, 0, 0]
a = list(range(1, 6))       # [1, 2, 3, 4, 5]
a = list("абв")             # ['а', 'б', 'в']
```

**C++**

```cpp
vector<int> a = {10, 20, 30};
a = {};                                  // порожній
a.assign(5, 0);                          // {0, 0, 0, 0, 0}
vector<int> r(5);
iota(r.begin(), r.end(), 1);             // {1, 2, 3, 4, 5}   (<numeric>)
string t = "abc";
vector<char> c(t.begin(), t.end());      // {'a', 'b', 'c'}
```

**JavaScript**

```javascript
let a = [10, 20, 30];
a = [];                                  // порожній
a = new Array(5).fill(0);                // [0, 0, 0, 0, 0]
a = Array.from({ length: 5 }, (_, i) => i + 1);   // [1, 2, 3, 4, 5]
a = [..."abc"];                          // ['a', 'b', 'c']
```

## 8.2 Створення списку з вводу

**Python**

```python
a = list(map(int, input().split()))        # числа в одному рядку

n = int(input())                           # n чисел у окремих рядках
a = [int(input()) for _ in range(n)]

a = [int(x) for x in input().split()]      # те саме, що map
```

**C++**

```cpp
string line;
getline(cin, line);
istringstream iss(line);
vector<int> a;
for (int x; iss >> x; ) a.push_back(x);  // числа в одному рядку

int n;
cin >> n;
vector<int> b(n);
for (int &v : b) cin >> v;               // n чисел
```

**JavaScript**

```javascript
const lines = require("fs").readFileSync(0, "utf8").split("\n");   // див. 3.6
const a = lines[0].trim().split(/\s+/).map(Number);                 // числа в одному рядку

const n = Number(lines[1]);                                         // n чисел у окремих рядках
const b = lines.slice(2, 2 + n).map(Number);
```

## 8.3 Доступ, зрізи, довжина

**Python**

```python
a[0]        # перший
a[-1]       # останній
a[2:5]      # зріз — новий список
a[::-1]     # копія у зворотному порядку
len(a)      # кількість елементів
```

**C++**

```cpp
a[0];                                              // перший
a.back();                                          // останній
vector<int> part(a.begin() + 2, a.begin() + 5);    // зріз a[2:5] — новий вектор
vector<int> rev(a.rbegin(), a.rend());             // копія у зворотному порядку
a.size();                                          // кількість елементів
```

**JavaScript**

```javascript
a[0];                       // перший
a.at(-1);                   // останній
a.slice(2, 5);              // зріз — новий масив
[...a].reverse();           // копія у зворотному порядку
a.length;                   // кількість елементів
```

На відміну від рядків, **елементи списку можна змінювати**:

**Python**

```python
a[0] = 99
a[1:3] = [7, 8, 9]       # зріз теж
```

**C++**

```cpp
a[0] = 99;
a.erase(a.begin() + 1, a.begin() + 3);   // a[1:3] = [7, 8, 9]: спершу видалити зріз,
a.insert(a.begin() + 1, {7, 8, 9});      // потім вставити нові елементи
```

**JavaScript**

```javascript
a[0] = 99;
a.splice(1, 2, 7, 8, 9);                 // a[1:3] = [7, 8, 9]: видалити 2 елементи з індексу 1 і вставити 7, 8, 9
```

## 8.4 Методи списку

| Метод | Дія | Складність |
|-------|-----|------------|
| `a.append(x)` | додати в кінець | O(1) |
| `a.insert(i, x)` | вставити за індексом | O(n) |
| `a.extend(b)` / `a += b` | додати всі елементи b | O(k) |
| `a.pop()` | вилучити і повернути останній | O(1) |
| `a.pop(i)` | вилучити за індексом | O(n) |
| `a.remove(x)` | вилучити **перше** входження x | O(n) |
| `a.index(x)` | індекс першого входження | O(n) |
| `a.count(x)` | кількість входжень | O(n) |
| `a.sort()` | відсортувати **на місці** | O(n log n) |
| `a.reverse()` | розвернути на місці | O(n) |
| `a.clear()` | очистити | O(1) |
| `a.copy()` | поверхнева копія | O(n) |

Відповідники методів у C++ (`vector`) та JavaScript:

| Python | C++ (`vector`) | JavaScript |
|--------|----------------|------------|
| `a.append(x)` | `a.push_back(x)` | `a.push(x)` |
| `a.insert(i, x)` | `a.insert(a.begin() + i, x)` | `a.splice(i, 0, x)` |
| `a.extend(b)` | `a.insert(a.end(), b.begin(), b.end())` | `a.push(...b)` |
| `a.pop()` | `a.pop_back()` (нічого не повертає) | `a.pop()` |
| `a.pop(i)` | `a.erase(a.begin() + i)` | `a.splice(i, 1)` |
| `a.remove(x)` | `a.erase(find(a.begin(), a.end(), x))` | `a.splice(a.indexOf(x), 1)` |
| `a.index(x)` | `find(a.begin(), a.end(), x) - a.begin()` | `a.indexOf(x)` |
| `a.count(x)` | `count(a.begin(), a.end(), x)` | `a.filter(v => v === x).length` |
| `a.sort()` | `sort(a.begin(), a.end())` | `a.sort((p, q) => p - q)` |
| `a.reverse()` | `reverse(a.begin(), a.end())` | `a.reverse()` |
| `a.clear()` | `a.clear()` | `a.length = 0` |
| `a.copy()` | `vector<int> b = a;` | `[...a]` або `a.slice()` |

**Увага:** `a.sort()` у JavaScript без функції порівняння сортує елементи **як рядки**: `[10, 9, 1].sort()` дає `[1, 10, 9]`. Для чисел завжди передавайте `(p, q) => p - q`.

## 8.5 Вбудовані функції

**Python**

```python
sum(a)        min(a)        max(a)        len(a)
sorted(a)                   # новий відсортований список
sorted(a, reverse=True)
sorted(a, key=abs)          # за ключем
any(x > 0 for x in a)       # хоча б один
all(x > 0 for x in a)       # усі
```

**C++**

```cpp
accumulate(a.begin(), a.end(), 0);                   // sum   (<numeric>)
*min_element(a.begin(), a.end());                    // min
*max_element(a.begin(), a.end());                    // max
a.size();                                            // len

vector<int> s = a;                                   // sorted(a): копія + sort
sort(s.begin(), s.end());                            // новий відсортований вектор
sort(s.begin(), s.end(), greater<int>());            // reverse=True
sort(s.begin(), s.end(), [](int p, int q) { return abs(p) < abs(q); });   // key=abs

any_of(a.begin(), a.end(), [](int x) { return x > 0; });   // хоча б один
all_of(a.begin(), a.end(), [](int x) { return x > 0; });   // усі
```

**JavaScript**

```javascript
a.reduce((p, q) => p + q, 0);                        // sum
Math.min(...a);                                      // min
Math.max(...a);                                      // max
a.length;                                            // len

[...a].sort((p, q) => p - q);                        // sorted(a): новий відсортований масив
[...a].sort((p, q) => q - p);                        // reverse=True
[...a].sort((p, q) => Math.abs(p) - Math.abs(q));    // key=abs

a.some(x => x > 0);                                  // хоча б один
a.every(x => x > 0);                                 // усі
```

У C++ і JavaScript метод `sort` змінює контейнер **на місці**; щоб зберегти оригінал, спершу копіюють.

## 8.6 Копіювання — важливо!

**Python**

```python
b = a            # НЕ копія: два імені на один список
b = a.copy()     # копія
b = a[:]         # копія
b = list(a)      # копія
```

**C++**

```cpp
vector<int> &r = a;                  // посилання: r — друге ім'я того самого вектора (як b = a у Python)
vector<int> b1 = a;                  // копія
vector<int> b2(a);                   // копія
vector<int> b3(a.begin(), a.end());  // копія
```

**JavaScript**

```javascript
let b = a;                           // НЕ копія: два імені на один масив
b = [...a];                          // копія
b = a.slice();                       // копія
b = Array.from(a);                   // копія
```

Усі ці копії — **поверхневі**: для вкладених масивів вкладені елементи залишаються спільними (у JavaScript повну копію робить `structuredClone(a)`).

**Python**

```python
a = [1, 2, 3]
b = a
b[0] = 99
print(a)         # [99, 2, 3]  — змінився і a!
```

**C++**

```cpp
vector<int> a = {1, 2, 3};
vector<int> b = a;                   // копія: b — незалежний вектор
b[0] = 99;
cout << a[0] << endl;                // 1 — a не змінився (на відміну від Python)

vector<int> &c = a;                  // посилання на a
c[0] = 99;
cout << a[0] << endl;                // 99 — змінився і a
```

**JavaScript**

```javascript
const a = [1, 2, 3];
const b = a;
b[0] = 99;
console.log(a);                      // [ 99, 2, 3 ] — змінився і a!
```

У C++ типи-значення (`vector`, `string`) за замовчуванням **копіюються**; у Python і JavaScript масиви/списки передаються **за посиланням**. Це одна з найважливіших відмінностей.

## 8.7 Генератори списків (list comprehension)

**Python**

```python
[x ** 2 for x in range(5)]               # [0, 1, 4, 9, 16]
[x for x in a if x > 0]                  # фільтр
[x if x > 0 else 0 for x in a]           # перетворення
[abs(x) for x in a]
```

**C++**

```cpp
vector<int> sq;
for (int x = 0; x < 5; ++x) sq.push_back(x * x);     // {0, 1, 4, 9, 16}

vector<int> pos;
copy_if(a.begin(), a.end(), back_inserter(pos), [](int x) { return x > 0; });   // фільтр

vector<int> t(a.size());
transform(a.begin(), a.end(), t.begin(), [](int x) { return x > 0 ? x : 0; });  // перетворення
transform(a.begin(), a.end(), t.begin(), [](int x) { return abs(x); });
```

**JavaScript**

```javascript
Array.from({ length: 5 }, (_, x) => x ** 2);         // [0, 1, 4, 9, 16]
a.filter(x => x > 0);                                // фільтр
a.map(x => (x > 0 ? x : 0));                         // перетворення
a.map(x => Math.abs(x));
```

Спискових включень у C++ немає (є алгоритми `copy_if`, `transform`); у JavaScript їх замінюють методи `map` та `filter`.

Читається як «математичний опис множини» і працює швидше за цикл
з `append`.

## 8.8 Перебір списку

**Python**

```python
for x in a:                  # за значеннями (змінити елемент не можна)
    print(x)

for i in range(len(a)):      # за індексами (можна змінювати)
    a[i] *= 2

for i, x in enumerate(a):    # індекс + значення
    print(i, x)

for x, y in zip(a, b):       # паралельно два списки
    print(x + y)
```

**C++**

```cpp
for (int x : a) {                          // за значеннями (x — копія, змінити елемент не можна)
    cout << x << endl;
}

for (size_t i = 0; i < a.size(); ++i) {    // за індексами (можна змінювати)
    a[i] *= 2;
}

for (int &x : a) {                         // за посиланням — теж можна змінювати
    x += 1;
}

for (size_t i = 0; i < a.size(); ++i) {    // індекс + значення
    cout << i << " " << a[i] << endl;
}

for (size_t i = 0; i < min(a.size(), b.size()); ++i) {   // паралельно два вектори
    cout << a[i] + b[i] << endl;
}
```

**JavaScript**

```javascript
for (const x of a) {                       // за значеннями
  console.log(x);
}

for (let i = 0; i < a.length; i++) {       // за індексами (можна змінювати)
  a[i] *= 2;
}

for (const [i, x] of a.entries()) {        // індекс + значення
  console.log(i, x);
}

a.forEach((x, i) => {                      // паралельно два масиви
  console.log(x + b[i]);
});
```

**Не змінюйте довжину списку під час перебору** — це призводить
до пропущених елементів.

## 8.9 Класичні алгоритми

### Сума, кількість за умовою

**Python**

```python
s = sum(a)
k = sum(1 for x in a if x > 0)
```

**C++**

```cpp
int s = accumulate(a.begin(), a.end(), 0);
int k = count_if(a.begin(), a.end(), [](int x) { return x > 0; });
```

**JavaScript**

```javascript
const s = a.reduce((p, q) => p + q, 0);
const k = a.filter(x => x > 0).length;
```

### Максимум та його індекс

**Python**

```python
m = a[0]
pos = 0
for i in range(1, len(a)):
    if a[i] > m:
        m, pos = a[i], i
# або: pos = a.index(max(a))
```

**C++**

```cpp
int m = a[0];
int pos = 0;
for (size_t i = 1; i < a.size(); ++i) {
    if (a[i] > m) {
        m = a[i];
        pos = i;
    }
}
// або: pos = max_element(a.begin(), a.end()) - a.begin();
```

**JavaScript**

```javascript
let m = a[0];
let pos = 0;
for (let i = 1; i < a.length; i++) {
  if (a[i] > m) {
    m = a[i];
    pos = i;
  }
}
// або: pos = a.indexOf(Math.max(...a));
```

### Обмін двох елементів

**Python**

```python
a[i], a[j] = a[j], a[i]
```

**C++**

```cpp
swap(a[i], a[j]);
```

**JavaScript**

```javascript
[a[i], a[j]] = [a[j], a[i]];
```

### Реверс на місці (без зрізу)

**Python**

```python
for i in range(len(a) // 2):
    a[i], a[-1 - i] = a[-1 - i], a[i]
```

**C++**

```cpp
for (size_t i = 0; i < a.size() / 2; ++i) {
    swap(a[i], a[a.size() - 1 - i]);
}
// або: reverse(a.begin(), a.end());
```

**JavaScript**

```javascript
for (let i = 0; i < Math.floor(a.length / 2); i++) {
  [a[i], a[a.length - 1 - i]] = [a[a.length - 1 - i], a[i]];
}
// або: a.reverse();
```

### Циклічний зсув уліво на 1

**Python**

```python
a.append(a.pop(0))
# або: a = a[1:] + a[:1]
```

**C++**

```cpp
rotate(a.begin(), a.begin() + 1, a.end());     // циклічний зсув уліво на 1 (<algorithm>)
// або: a.push_back(a.front()); a.erase(a.begin());
```

**JavaScript**

```javascript
a.push(a.shift());                             // shift() вилучає перший елемент
// або: a = [...a.slice(1), ...a.slice(0, 1)];
```

### Видалити всі елементи, що задовольняють умову

**Python**

```python
a = [x for x in a if not умова(x)]       # правильно
```

**C++**

```cpp
a.erase(remove_if(a.begin(), a.end(), умова), a.end());     // правильно: ідіома erase–remove
// C++20: erase_if(a, умова);
```

**JavaScript**

```javascript
a = a.filter(x => !умова(x));                               // правильно
```

`remove_if` у C++ лише пересуває елементи, що залишаються, на початок, а `erase` фактично скорочує вектор.

### Злиття двох відсортованих списків

**Python**

```python
res, i, j = [], 0, 0
while i < len(a) and j < len(b):
    if a[i] <= b[j]:
        res.append(a[i]); i += 1
    else:
        res.append(b[j]); j += 1
res += a[i:] + b[j:]
```

**C++**

```cpp
vector<int> res;
size_t i = 0, j = 0;
while (i < a.size() && j < b.size()) {
    if (a[i] <= b[j]) {
        res.push_back(a[i]);
        i++;
    } else {
        res.push_back(b[j]);
        j++;
    }
}
res.insert(res.end(), a.begin() + i, a.end());
res.insert(res.end(), b.begin() + j, b.end());
// готова функція: merge(a.begin(), a.end(), b.begin(), b.end(), back_inserter(res));
```

**JavaScript**

```javascript
const res = [];
let i = 0, j = 0;
while (i < a.length && j < b.length) {
  if (a[i] <= b[j]) {
    res.push(a[i]);
    i++;
  } else {
    res.push(b[j]);
    j++;
  }
}
res.push(...a.slice(i), ...b.slice(j));
```

## 8.10 Типові помилки

| Помилка | Причина |
|---------|---------|
| `IndexError: list index out of range` | звернення до `a[len(a)]` |
| `b = a` не дає копії | списки — посилання |
| `a.sort()` повертає `None` | сортує на місці; потрібен `sorted(a)` |
| пропуск елементів у циклі | видалення під час перебору |
| `[0] * n` для матриці | усі рядки — той самий список |
| C++: `a[i]` за межами `vector` | невизначена поведінка, винятку немає (безпечно — `a.at(i)`) |
| C++: `a.size() - 1` для порожнього вектора | `size()` беззнакове: `0 - 1` дає величезне число |
| JS: `a.sort()` для чисел | сортує як рядки; потрібен `(p, q) => p - q` |
| JS: `a[10] = 1` за межами масиву | масив стає «дірявим», `length` зростає до 11 |
