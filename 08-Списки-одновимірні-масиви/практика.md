# Практичні завдання до розділу 8

**Тип завдань:** обробка одновимірного списку цілих чисел,
введеного одним рядком через пробіл.

Формат вводу для всіх задач:
```
1 -5 3 0 7 -2
```

---

### Задача 8.1
Вивести суму, добуток, кількість елементів
і середнє арифметичне списку.
```
[1, 2, 3, 4] → сума 10, добуток 24, n=4, середнє 2.50
```

### Задача 8.2
Вивести максимальний та мінімальний елементи і їхні індекси.
```
[3, 9, 1, 9] → max=9 (індекс 1), min=1 (індекс 2)
```

### Задача 8.3
Підрахувати кількість додатних, від'ємних і нульових елементів.
```
[1, -5, 0, 7, -2] → додатних 2, від'ємних 2, нулів 1
```

### Задача 8.4
Вивести суму елементів з парними індексами
і суму елементів з непарними індексами.
```
[10, 20, 30, 40] → парні індекси 40, непарні 60
```

### Задача 8.5
Вивести список у зворотному порядку **без** використання
зрізу `[::-1]` і методу `reverse()`.
```
[1, 2, 3, 4] → [4, 3, 2, 1]
```

### Задача 8.6
Поміняти місцями перший і останній елементи,
другий і передостанній тощо (реверс на місці) — показати
результат і підтвердити, що створено не новий список.
```
[1, 2, 3, 4, 5] → [5, 4, 3, 2, 1]
```

### Задача 8.7
Видалити зі списку всі від'ємні елементи
та вивести, скільки елементів видалено.
```
[1, -5, 3, -2] → [1, 3], видалено 2
```

### Задача 8.8
Виконати циклічний зсув елементів уліво на k позицій.
```
[1, 2, 3, 4, 5], k=2 → [3, 4, 5, 1, 2]
```

### Задача 8.9
Вивести список без повторів, зберігаючи порядок першої появи.
```
[3, 1, 3, 2, 1] → [3, 1, 2]
```

### Задача 8.10
Дано два **відсортованих** списки. Злити їх в один
відсортований без використання `sort()` / `sorted()`.
```
[1, 3, 5] + [2, 3, 8] → [1, 2, 3, 3, 5, 8]
```
