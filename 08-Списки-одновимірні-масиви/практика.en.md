# Practice Tasks for Chapter 8

**Task type:** processing a one-dimensional list of integers
entered on one line, separated by spaces.

Input format for all tasks:
```
1 -5 3 0 7 -2
```

---

### Task 8.1
Print the sum, product, number of elements,
and arithmetic mean of the list.
```
[1, 2, 3, 4] → sum 10, product 24, n=4, mean 2.50
```

### Task 8.2
Print the maximum and minimum elements and their indices.
```
[3, 9, 1, 9] → max=9 (index 1), min=1 (index 2)
```

### Task 8.3
Count the positive, negative, and zero elements.
```
[1, -5, 0, 7, -2] → positive 2, negative 2, zeros 1
```

### Task 8.4
Print the sum of the elements at even indices
and the sum of the elements at odd indices.
```
[10, 20, 30, 40] → even indices 40, odd 60
```

### Task 8.5
Print the list in reverse order **without** using
the slice `[::-1]` or the `reverse()` method.
```
[1, 2, 3, 4] → [4, 3, 2, 1]
```

### Task 8.6
Swap the first and last elements,
the second and second-to-last, and so on (reverse in place) — show
the result and confirm that no new list was created.
```
[1, 2, 3, 4, 5] → [5, 4, 3, 2, 1]
```

### Task 8.7
Remove all negative elements from the list
and print how many elements were removed.
```
[1, -5, 3, -2] → [1, 3], removed 2
```

### Task 8.8
Perform a cyclic shift of the elements to the left by k positions.
```
[1, 2, 3, 4, 5], k=2 → [3, 4, 5, 1, 2]
```

### Task 8.9
Print the list without duplicates, keeping the order of first appearance.
```
[3, 1, 3, 2, 1] → [3, 1, 2]
```

### Task 8.10
Two **sorted** lists are given. Merge them into one
sorted list without using `sort()` / `sorted()`.
```
[1, 3, 5] + [2, 3, 8] → [1, 2, 3, 3, 5, 8]
```
