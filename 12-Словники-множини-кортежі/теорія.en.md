# Chapter 12. Dictionaries, Sets, Tuples

## 12.1 Overview of Python Collections

| Type | Notation | Mutable | Ordered | Duplicates | Access |
|------|----------|---------|---------|------------|--------|
| `list` | `[1, 2, 3]` | yes | yes | yes | by index |
| `tuple` | `(1, 2, 3)` | **no** | yes | yes | by index |
| `dict` | `{"a": 1}` | yes | yes (since 3.7) | keys — no | by key |
| `set` | `{1, 2, 3}` | yes | **no** | **no** | membership only |
| `frozenset` | `frozenset({1,2})` | no | no | no | membership |

Counterparts in C++ and JavaScript:

| Python | C++ | JavaScript |
|--------|-----|------------|
| `list` | `vector` | `Array` |
| `tuple` | `tuple`, `pair`, `struct` | array (`Object.freeze`) |
| `dict` | `unordered_map` (hash), `map` (sorted by key) | `Map`, a plain object `{}` |
| `set` | `unordered_set` (hash), `set` (ascending) | `Set` |
| `deque` | `deque` | array (`shift`/`unshift`) |

Order of elements: `dict` in Python and `Map`/`Set` in JavaScript keep the **insertion** order; `map`/`set` in C++ keep the elements **sorted by key** (search O(log n)); `unordered_map`/`unordered_set` — arbitrary order (search O(1) on average).

## 12.2 The Tuple

An immutable sequence. Uses: returning several values,
dictionary keys, fixed records.

**Python**

```python
t = (1, 2, 3)
t = 1, 2, 3            # the parentheses are optional
t = (5,)               # a tuple of ONE element — the comma is required!
t = ()                 # empty

t[0]                   # 1
len(t)                 # 3
a, b, c = t            # unpacking
x, *rest = (1, 2, 3)   # x=1, rest=[2, 3]
```

**C++**

```cpp
tuple<int, int, int> t = make_tuple(1, 2, 3);
// a tuple of ONE element
// empty

// 1 — the index must be a compile-time constant
// 3 — the "length"
// unpacking (C++17)
```

**JavaScript**

```javascript
// there is no separate "tuple" type: array + freeze
t[0];                                    // 1
t.length;                                // 3
// unpacking
const [x, ...rest] = [1, 2, 3];          // x = 1, rest = [2, 3]
```

For two values `pair<A, B>` is convenient in C++ (fields `first`, `second`); for named fields use a `struct`.

`t[0] = 9` → `TypeError`. But a tuple may **contain** mutable objects:

**Python**

```python
t = ([1, 2], 3)
t[0].append(9)         # allowed — the list inside changed
```

**C++**

```cpp
tuple<vector<int>, int> t = {{1, 2}, 3};
// allowed: the vector inside changed
// const tuple<...> — then it cannot be changed
```

**JavaScript**

```javascript
const t = Object.freeze([[1, 2], 3]);
// allowed: freeze is shallow, the inner array changed
```

### A tuple as a key

**Python**

```python
coords = {(0, 0): "origin", (1, 2): "point A"}
```

**C++**

```cpp
map<pair<int, int>, string> coords = {{{0, 0}, "origin"}, {{1, 2}, "point A"}};
```

**JavaScript**

```javascript
// a string key: an array as a key is compared by reference
coords.get(`${1},${2}`);                                           // "point A"
```

A list cannot be a key — it is mutable (unhashable).

## 12.3 The Set

An unordered collection of **unique** hashable elements.
The main point: a membership check in **O(1)**.

**Python**

```python
s = {1, 2, 3}
s = set()              # empty ({} is a dictionary!)
s = set([1, 2, 2, 3])  # {1, 2, 3} — duplicates vanished

s.add(4)
s.discard(9)           # no error if absent
s.remove(9)            # KeyError if absent
s.pop()                # removes an arbitrary element
3 in s                 # True — O(1)
len(s)
```

**C++**

```cpp
// ordered set (tree): O(log n)
// hash table: O(1) on average
vector<int> src = {1, 2, 2, 3};
// {1, 2, 3} — duplicates disappeared

s.insert(4);                               // add
// discard: no error if absent
// removes the smallest element
// 1 — present; in C++20 also s.contains(3)
s.size();
```

**JavaScript**

```javascript
let s = new Set([1, 2, 3]);
// empty
// Set {1, 2, 3} — duplicates disappeared

s.add(4);
// false if absent — no error
s.has(3);                                  // true — O(1)
s.size;
```

In C++ an empty set is just a declared variable `set<int> s;`, and `{}` in an initialization context is not confused with a dictionary.

### Set Operations

| Operation | Operator | Method | Result |
|-----------|----------|--------|--------|
| union | `a \| b` | `a.union(b)` | elements from both |
| intersection | `a & b` | `a.intersection(b)` | common ones |
| difference | `a - b` | `a.difference(b)` | only from a |
| symmetric difference | `a ^ b` | `a.symmetric_difference(b)` | only in one |
| subset | `a <= b` | `a.issubset(b)` | bool |
| superset | `a >= b` | `a.issuperset(b)` | bool |
| disjoint | | `a.isdisjoint(b)` | bool |

**Python**

```python
a, b = {1, 2, 3}, {3, 4}
a | b      # {1, 2, 3, 4}
a & b      # {3}
a - b      # {1, 2}
a ^ b      # {1, 2, 4}
```

**C++**

```cpp
set<int> a = {1, 2, 3}, b = {3, 4};
set<int> u, i, d, sd;
set_union(a.begin(), a.end(), b.begin(), b.end(), inserter(u, u.end()));                  // {1, 2, 3, 4}
set_intersection(a.begin(), a.end(), b.begin(), b.end(), inserter(i, i.end()));           // {3}
set_difference(a.begin(), a.end(), b.begin(), b.end(), inserter(d, d.end()));             // {1, 2}
set_symmetric_difference(a.begin(), a.end(), b.begin(), b.end(), inserter(sd, sd.end())); // {1, 2, 4}
// is b ⊆ a
```

**JavaScript**

```javascript
const a = new Set([1, 2, 3]), b = new Set([3, 4]);
new Set([...a, ...b]);                              // {1, 2, 3, 4}
new Set([...a].filter(x => b.has(x)));              // {3}
new Set([...a].filter(x => !b.has(x)));             // {1, 2}
new Set([...a].filter(x => !b.has(x)).concat([...b].filter(x => !a.has(x))));   // {1, 2, 4}
// newer versions have a.union(b), a.intersection(b), a.difference(b), a.symmetricDifference(b)
```

In C++ set operations are algorithms over **sorted** ranges (`<algorithm>`); there are no `|`, `&`, `-` operators for `set`.

### Typical use

**Python**

```python
unique = set(a)                    # unique elements
len(set(a)) == len(a)              # whether all elements are distinct
set(a) & set(b)                    # common elements of two lists
```

**C++**

```cpp
// unique elements
// are all elements different

// common elements of two vectors
for (int x : uniq) {
    if (sb.count(x)) common.insert(x);
}
```

**JavaScript**

```javascript
// unique elements
// are all elements different

// common elements of two arrays
const common = [...uniq].filter(x => sb.has(x));
```

## 12.4 The Dictionary

A **key → value** mapping. Access by key is O(1).

**Python**

```python
d = {"apple": 5, "pear": 3}
d = dict(apple=5, pear=3)
d = {}                      # empty
d = dict.fromkeys(["a", "b"], 0)    # {'a': 0, 'b': 0}
```

**C++**

```cpp
// sorted by key
// hash table
// empty
map<string, int> z = {{"a", 0}, {"b", 0}};                     // fromkeys(["a", "b"], 0)
```

**JavaScript**

```javascript
// Map is a full-fledged dictionary
// an object also works as a dictionary (keys are strings)
// empty
const z = new Map(["a", "b"].map(k => [k, 0]));                // fromkeys
```

### Access and modification

**Python**

```python
d["apple"]           # 5
d["plum"]            # KeyError!
d.get("plum")        # None — no error
d.get("plum", 0)     # 0 — a default value

d["plum"] = 7        # add / change
del d["pear"]        # remove (KeyError if absent)
d.pop("pear", None)  # remove safely
"apple" in d         # checks the KEY — O(1)
len(d)
```

**C++**

```cpp
// 5 — WARNING: [] creates the key with value 0 if it is absent!
// d.at("plum") throws out_of_range (the counterpart of KeyError)
auto it = d.find("plum");                      // d.get("plum")
int v = (it != d.end()) ? it->second : 0;      // d.get("plum", 0)

// add / change
// remove (no error if absent)
// checks the KEY; in C++20 d.contains("apple")
d.size();
```

**JavaScript**

```javascript
d.get("apple");                // 5
// undefined — no error
// 0 — a default value

// add / change
// remove (false if absent)
// checks the KEY — O(1)
d.size;
```

The `[]` operator of `map`/`unordered_map` **modifies the dictionary** when an absent key is read — use `find`, `count` or `at` for checks.

### Iteration

**Python**

```python
for k in d:                  # by keys
for k in d.keys():
for v in d.values():         # by values
for k, v in d.items():       # by pairs
```

**C++**

```cpp
// by pairs (structured bindings, C++17)
    cout << k << " " << v << endl;
}

// keys only: kv.first; values only: kv.second
    cout << kv.first << endl;
}
```

**JavaScript**

```javascript
// by keys
  console.log(k);
}
// by values
  console.log(v);
}
// by pairs (the same as d.entries())
  console.log(k, v);
}
```

### Useful methods

**Python**

```python
d.setdefault("a", 0)         # return or create with a value
d.update({"b": 1})           # merge another dictionary
d1 | d2                      # union (Python 3.9+)
sorted(d.items(), key=lambda kv: -kv[1])    # by value, descending
max(d, key=d.get)            # the key with the largest value
```

**C++**

```cpp
// setdefault: inserts only if the key is absent
// update: merge another dictionary

vector<pair<string, int>> items(d.begin(), d.end());
// by value, descending
     [](const auto &p, const auto &q) { return p.second > q.second; });

// the key with the largest value
            [](const auto &p, const auto &q) { return p.second < q.second; })->first;
```

**JavaScript**

```javascript
// setdefault
// update: merge another dictionary
const merged = new Map([...d, ...other]);        // d1 | d2

// by value, descending
// the key with the largest value
```

## 12.5 The Main Pattern: a Frequency Dictionary

**Python**

```python
counts = {}
for x in data:
    counts[x] = counts.get(x, 0) + 1
```

**C++**

```cpp
map<int, int> counts;
for (int x : data) {
    // [] creates 0 for a new key, so ++ works right away
}
```

**JavaScript**

```javascript
const counts = new Map();
for (const x of data) {
  counts.set(x, (counts.get(x) ?? 0) + 1);
}
```

The same via `collections.Counter`:

**Python**

```python
from collections import Counter

c = Counter("abracadabra")
c.most_common(3)        # [('a', 5), ('b', 2), ('r', 2)]
c["a"]                  # 5 (0 for an absent one — no KeyError)
```

**C++**

```cpp
map<char, int> c;
for (char ch : string("abracadabra")) c[ch]++;

vector<pair<char, int>> top(c.begin(), c.end());
sort(top.begin(), top.end(), [](const auto &p, const auto &q) {
    return p.second != q.second ? p.second > q.second : p.first < q.first;
});
top.resize(3);                    // most_common(3): a:5, b:2, r:2

// 5 (for an absent key [] creates an entry with value 0)
```

**JavaScript**

```javascript
const c = new Map();
for (const ch of "abracadabra") {
  c.set(ch, (c.get(ch) ?? 0) + 1);
}

const top = [...c].sort((p, q) => q[1] - p[1]).slice(0, 3);   // most_common(3): [['a',5],['b',2],['r',2]]
// 5 (for an absent one — undefined)
```

There is no `Counter` class in the standard libraries of C++ and JavaScript — counting is done with `map`/`Map` and a loop.

### Other useful containers

**Python**

```python
from collections import defaultdict, deque

groups = defaultdict(list)
groups["vowels"].append("a")        # the key is created automatically

q = deque([1, 2, 3])
q.appendleft(0)                     # O(1), unlike list.insert(0,x)
q.popleft()                         # O(1)
```

**C++**

```cpp
map<string, vector<string>> groups;
// the key is created automatically (by the [] operator)

deque<int> q = {1, 2, 3};
// O(1), unlike vector::insert(begin, x)
q.pop_front();                        // O(1)
```

**JavaScript**

```javascript
const groups = new Map();
// there is no automatic key creation
groups.get("vowels").push("a");

const q = [1, 2, 3];
// add to the front
// remove from the front
```

In C++ the `[]` operator of `map` works like `defaultdict`: it creates a default value. In JavaScript `shift`/`unshift` are O(n) in general; for large queues use your own implementation with indices.

## 12.6 Dictionary and Set Comprehensions

**Python**

```python
{x: x ** 2 for x in range(5)}                  # {0:0, 1:1, 2:4, ...}
{k: v for k, v in d.items() if v > 3}          # filter
{v: k for k, v in d.items()}                   # invert (key↔value)
{ch for ch in "abracadabra"}                   # a set of characters
```

**C++**

```cpp
map<int, int> squares;
for (int x = 0; x < 5; ++x) squares[x] = x * x;           // {0:0, 1:1, 2:4, ...}

map<string, int> big;
// filter

map<int, string> inv;
// invert (key↔value)

set<char> chars;
// a set of characters
```

**JavaScript**

```javascript
Object.fromEntries(Array.from({ length: 5 }, (_, x) => [x, x ** 2]));   // {0:0, 1:1, 2:4, ...}
// filter
// invert (key↔value)
// a set of characters
```

## 12.7 Hashability

Only **immutable (hashable)** objects can be dictionary keys and set elements:
`int`, `float`, `str`, `bool`,
`tuple` (of immutable items), `frozenset`.

These cannot: `list`, `dict`, `set`.

In C++ the key of an `unordered_map` can be any type for which `std::hash` and `==` are defined; `map` and `set` need only the `<` operator, so a `pair` or a `vector` can be a key. In JavaScript `Map` and `Set` accept any keys, but objects and arrays are compared by **reference**, not by content.

**Python**

```python
hash("text")          # works
hash([1, 2])          # TypeError: unhashable type: 'list'
```

**C++**

```cpp
// works: std::hash<string>
// compilation error: there is no std::hash for vector
// but an ordered set works: < is defined for vector
```

**JavaScript**

```javascript
const s = new Set();
s.add([1, 2]);
// false — this is another array in memory: comparison by reference
```

## 12.8 Choosing a Data Structure

| Task | Structure | Why |
|------|-----------|-----|
| an ordered sequence | `list` | indices, order |
| a "is the element present" check | `set` | O(1) instead of O(n) |
| remove duplicates | `set` | automatic |
| count frequencies | `dict` / `Counter` | key → count |
| a "name → data" mapping | `dict` | access by key |
| a fixed record | `tuple` | immutability, hashability |
| a queue | `deque` | O(1) at both ends |
