# Розділ 12. Словники, множини, кортежі

## 12.1 Огляд колекцій Python

| Тип | Запис | Змінний | Упорядкований | Дублікати | Доступ |
|-----|-------|---------|---------------|-----------|--------|
| `list` | `[1, 2, 3]` | так | так | так | за індексом |
| `tuple` | `(1, 2, 3)` | **ні** | так | так | за індексом |
| `dict` | `{"a": 1}` | так | так (з 3.7) | ключі — ні | за ключем |
| `set` | `{1, 2, 3}` | так | **ні** | **ні** | тільки входження |
| `frozenset` | `frozenset({1,2})` | ні | ні | ні | входження |

Відповідники у C++ та JavaScript:

| Python | C++ | JavaScript |
|--------|-----|------------|
| `list` | `vector` | `Array` |
| `tuple` | `tuple`, `pair`, `struct` | масив (`Object.freeze`) |
| `dict` | `unordered_map` (хеш), `map` (за ключем) | `Map`, звичайний об'єкт `{}` |
| `set` | `unordered_set` (хеш), `set` (за зростанням) | `Set` |
| `deque` | `deque` | масив (`shift`/`unshift`) |

Порядок елементів: `dict` у Python і `Map`/`Set` у JavaScript зберігають порядок **додавання**; `map`/`set` у C++ тримають елементи **відсортованими за ключем** (пошук O(log n)); `unordered_map`/`unordered_set` — порядок довільний (пошук O(1) у середньому).

## 12.2 Кортеж (tuple)

Незмінна послідовність. Застосування: повернення кількох значень,
ключі словника, фіксовані записи.

**Python**

```python
t = (1, 2, 3)
t = 1, 2, 3            # дужки необов'язкові
t = (5,)               # кортеж з ОДНОГО елемента — кома обов'язкова!
t = ()                 # порожній

t[0]                   # 1
len(t)                 # 3
a, b, c = t            # розпакування
x, *rest = (1, 2, 3)   # x=1, rest=[2, 3]
```

**C++**

```cpp
tuple<int, int, int> t = make_tuple(1, 2, 3);
tuple<int> single(5);                    // кортеж з ОДНОГО елемента
tuple<> empty;                           // порожній

get<0>(t);                               // 1 — індекс має бути константою часу компіляції
tuple_size_v<decltype(t)>;               // 3 — «довжина»
auto [a, b, c] = t;                      // розпакування (C++17)
```

**JavaScript**

```javascript
const t = Object.freeze([1, 2, 3]);      // окремого типу «кортеж» немає: масив + freeze
t[0];                                    // 1
t.length;                                // 3
const [a, b, c] = t;                     // розпакування
const [x, ...rest] = [1, 2, 3];          // x = 1, rest = [2, 3]
```

Для двох значень у C++ зручний `pair<A, B>` (поля `first`, `second`); для іменованих полів — `struct`.

`t[0] = 9` → `TypeError`. Але кортеж може **містити** змінні об'єкти:

**Python**

```python
t = ([1, 2], 3)
t[0].append(9)         # дозволено — змінився список усередині
```

**C++**

```cpp
tuple<vector<int>, int> t = {{1, 2}, 3};
get<0>(t).push_back(9);                  // дозволено: змінився вектор усередині
// const tuple<...> — тоді змінити не вдасться
```

**JavaScript**

```javascript
const t = Object.freeze([[1, 2], 3]);
t[0].push(9);                            // дозволено: freeze поверхневий, внутрішній масив змінився
```

### Кортеж як ключ

**Python**

```python
coords = {(0, 0): "початок", (1, 2): "точка A"}
```

**C++**

```cpp
map<pair<int, int>, string> coords = {{{0, 0}, "origin"}, {{1, 2}, "point A"}};
```

**JavaScript**

```javascript
const coords = new Map([["0,0", "origin"], ["1,2", "point A"]]);   // ключ-рядок: масив як ключ порівнюється за посиланням
coords.get(`${1},${2}`);                                           // "point A"
```

Список ключем бути не може — він змінний (unhashable).

## 12.3 Множина (set)

Невпорядкована колекція **унікальних** хешованих елементів.
Головне: перевірка входження за **O(1)**.

**Python**

```python
s = {1, 2, 3}
s = set()              # порожня ({} — це словник!)
s = set([1, 2, 2, 3])  # {1, 2, 3} — дублікати зникли

s.add(4)
s.discard(9)           # без помилки, якщо немає
s.remove(9)            # KeyError, якщо немає
s.pop()                # вилучає довільний
3 in s                 # True — O(1)
len(s)
```

**C++**

```cpp
set<int> s = {1, 2, 3};                    // впорядкована множина (дерево): O(log n)
unordered_set<int> u = {1, 2, 3};          // хеш-таблиця: O(1) у середньому
vector<int> src = {1, 2, 2, 3};
set<int> s3(src.begin(), src.end());       // {1, 2, 3} — дублікати зникли

s.insert(4);                               // add
s.erase(9);                                // discard: без помилки, якщо немає
s.erase(s.begin());                        // вилучає найменший елемент
s.count(3);                                // 1 — є; у C++20 також s.contains(3)
s.size();
```

**JavaScript**

```javascript
let s = new Set([1, 2, 3]);
s = new Set();                             // порожня
s = new Set([1, 2, 2, 3]);                 // Set {1, 2, 3} — дублікати зникли

s.add(4);
s.delete(9);                               // false, якщо немає — без помилки
s.has(3);                                  // true — O(1)
s.size;
```

У C++ порожня множина — це просто оголошена змінна `set<int> s;`, а `{}` у контексті ініціалізації не плутається зі словником.

### Операції над множинами

| Операція | Оператор | Метод | Результат |
|----------|----------|-------|-----------|
| об'єднання | `a \| b` | `a.union(b)` | елементи з обох |
| перетин | `a & b` | `a.intersection(b)` | спільні |
| різниця | `a - b` | `a.difference(b)` | лише з a |
| симетрична різниця | `a ^ b` | `a.symmetric_difference(b)` | лише в одній |
| підмножина | `a <= b` | `a.issubset(b)` | bool |
| надмножина | `a >= b` | `a.issuperset(b)` | bool |
| не перетинаються | | `a.isdisjoint(b)` | bool |

**Python**

```python
a, b = {1, 2, 3}, {3, 4}
a | b      # {1, 2, 3, 4}
a & b      # {3}
a - b      # {1, 2}
a ^ b      # {1, 2, 4}
```

**C++**

```cpp
set<int> a = {1, 2, 3}, b = {3, 4};
set<int> u, i, d, sd;
set_union(a.begin(), a.end(), b.begin(), b.end(), inserter(u, u.end()));                  // {1, 2, 3, 4}
set_intersection(a.begin(), a.end(), b.begin(), b.end(), inserter(i, i.end()));           // {3}
set_difference(a.begin(), a.end(), b.begin(), b.end(), inserter(d, d.end()));             // {1, 2}
set_symmetric_difference(a.begin(), a.end(), b.begin(), b.end(), inserter(sd, sd.end())); // {1, 2, 4}
includes(a.begin(), a.end(), b.begin(), b.end());   // чи b ⊆ a
```

**JavaScript**

```javascript
const a = new Set([1, 2, 3]), b = new Set([3, 4]);
new Set([...a, ...b]);                              // {1, 2, 3, 4}
new Set([...a].filter(x => b.has(x)));              // {3}
new Set([...a].filter(x => !b.has(x)));             // {1, 2}
new Set([...a].filter(x => !b.has(x)).concat([...b].filter(x => !a.has(x))));   // {1, 2, 4}
// у нових версіях є a.union(b), a.intersection(b), a.difference(b), a.symmetricDifference(b)
```

У C++ операції над множинами — це алгоритми для **відсортованих** діапазонів (`<algorithm>`); операторів `|`, `&`, `-` для `set` немає.

### Типове застосування

**Python**

```python
unique = set(a)                    # унікальні елементи
len(set(a)) == len(a)              # чи всі елементи різні
set(a) & set(b)                    # спільні елементи двох списків
```

**C++**

```cpp
set<int> uniq(a.begin(), a.end());           // унікальні елементи
bool all_different = uniq.size() == a.size();   // чи всі елементи різні

set<int> sb(b.begin(), b.end()), common;     // спільні елементи двох векторів
for (int x : uniq) {
    if (sb.count(x)) common.insert(x);
}
```

**JavaScript**

```javascript
const uniq = new Set(a);                     // унікальні елементи
const allDifferent = uniq.size === a.length; // чи всі елементи різні

const sb = new Set(b);                       // спільні елементи двох масивів
const common = [...uniq].filter(x => sb.has(x));
```

## 12.4 Словник (dict)

Відображення **ключ → значення**. Доступ за ключем — O(1).

**Python**

```python
d = {"яблуко": 5, "груша": 3}
d = dict(яблуко=5, груша=3)
d = {}                      # порожній
d = dict.fromkeys(["a", "b"], 0)    # {'a': 0, 'b': 0}
```

**C++**

```cpp
map<string, int> d = {{"apple", 5}, {"pear", 3}};              // впорядкований за ключем
unordered_map<string, int> h = {{"apple", 5}, {"pear", 3}};    // хеш-таблиця
map<string, int> e;                                            // порожній
map<string, int> z = {{"a", 0}, {"b", 0}};                     // fromkeys(["a", "b"], 0)
```

**JavaScript**

```javascript
const d = new Map([["apple", 5], ["pear", 3]]);                // Map — повноцінний словник
const o = { apple: 5, pear: 3 };                               // об'єкт теж працює як словник (ключі — рядки)
const e = new Map();                                           // порожній
const z = new Map(["a", "b"].map(k => [k, 0]));                // fromkeys
```

### Доступ і зміна

**Python**

```python
d["яблуко"]          # 5
d["слива"]           # KeyError!
d.get("слива")       # None — без помилки
d.get("слива", 0)    # 0 — значення за замовчуванням

d["слива"] = 7       # додати / змінити
del d["груша"]       # вилучити (KeyError, якщо немає)
d.pop("груша", None) # вилучити безпечно
"яблуко" in d        # перевірка КЛЮЧА — O(1)
len(d)
```

**C++**

```cpp
d["apple"];                                    // 5 — УВАГА: [] створює ключ зі значенням 0, якщо його немає!
// d.at("plum") кидає out_of_range (аналог KeyError)
auto it = d.find("plum");                      // d.get("plum")
int v = (it != d.end()) ? it->second : 0;      // d.get("plum", 0)

d["plum"] = 7;                                 // додати / змінити
d.erase("pear");                               // вилучити (без помилки, якщо немає)
d.count("apple") > 0;                          // перевірка КЛЮЧА; у C++20 d.contains("apple")
d.size();
```

**JavaScript**

```javascript
d.get("apple");                // 5
d.get("plum");                 // undefined — помилки немає
d.get("plum") ?? 0;            // 0 — значення за замовчуванням

d.set("plum", 7);              // додати / змінити
d.delete("pear");              // вилучити (false, якщо немає)
d.has("apple");                // перевірка КЛЮЧА — O(1)
d.size;
```

Оператор `[]` у `map`/`unordered_map` **змінює словник** при читанні відсутнього ключа — для перевірки використовують `find`, `count` або `at`.

### Перебір

**Python**

```python
for k in d:                  # за ключами
for k in d.keys():
for v in d.values():         # за значеннями
for k, v in d.items():       # за парами
```

**C++**

```cpp
for (const auto &[k, v] : d) {         // за парами (структуровані прив'язки, C++17)
    cout << k << " " << v << endl;
}

for (const auto &kv : d) {             // лише ключі: kv.first; лише значення: kv.second
    cout << kv.first << endl;
}
```

**JavaScript**

```javascript
for (const k of d.keys()) {            // за ключами
  console.log(k);
}
for (const v of d.values()) {          // за значеннями
  console.log(v);
}
for (const [k, v] of d) {              // за парами (те саме, що d.entries())
  console.log(k, v);
}
```

### Корисні методи

**Python**

```python
d.setdefault("a", 0)         # повернути або створити зі значенням
d.update({"б": 1})           # злити інший словник
d1 | d2                      # об'єднання (Python 3.9+)
sorted(d.items(), key=lambda kv: -kv[1])    # за значенням, спадання
max(d, key=d.get)            # ключ із найбільшим значенням
```

**C++**

```cpp
d.try_emplace("a", 0);                           // setdefault: вставляє, лише якщо ключа ще немає
for (const auto &[k, v] : other) d[k] = v;       // update: злити інший словник

vector<pair<string, int>> items(d.begin(), d.end());
sort(items.begin(), items.end(),                 // за значенням, спадання
     [](const auto &p, const auto &q) { return p.second > q.second; });

max_element(d.begin(), d.end(),                  // ключ із найбільшим значенням
            [](const auto &p, const auto &q) { return p.second < q.second; })->first;
```

**JavaScript**

```javascript
if (!d.has("a")) d.set("a", 0);                  // setdefault
for (const [k, v] of other) d.set(k, v);         // update: злити інший словник
const merged = new Map([...d, ...other]);        // d1 | d2

[...d].sort((p, q) => q[1] - p[1]);              // за значенням, спадання
[...d].reduce((best, kv) => (kv[1] > best[1] ? kv : best))[0];   // ключ із найбільшим значенням
```

## 12.5 Головний шаблон: частотний словник

**Python**

```python
counts = {}
for x in data:
    counts[x] = counts.get(x, 0) + 1
```

**C++**

```cpp
map<int, int> counts;
for (int x : data) {
    counts[x]++;                  // [] створює 0 для нового ключа, тому ++ працює одразу
}
```

**JavaScript**

```javascript
const counts = new Map();
for (const x of data) {
  counts.set(x, (counts.get(x) ?? 0) + 1);
}
```

Те саме через `collections.Counter`:

**Python**

```python
from collections import Counter

c = Counter("абракадабра")
c.most_common(3)        # [('а', 5), ('б', 2), ('р', 2)]
c["а"]                  # 5 (0 для відсутнього — без KeyError)
```

**C++**

```cpp
map<char, int> c;
for (char ch : string("abracadabra")) c[ch]++;

vector<pair<char, int>> top(c.begin(), c.end());
sort(top.begin(), top.end(), [](const auto &p, const auto &q) {
    return p.second != q.second ? p.second > q.second : p.first < q.first;
});
top.resize(3);                    // most_common(3): a:5, b:2, r:2

c['a'];                           // 5 (для відсутнього ключа [] створить запис зі значенням 0)
```

**JavaScript**

```javascript
const c = new Map();
for (const ch of "abracadabra") {
  c.set(ch, (c.get(ch) ?? 0) + 1);
}

const top = [...c].sort((p, q) => q[1] - p[1]).slice(0, 3);   // most_common(3): [['a',5],['b',2],['r',2]]
c.get("a");                       // 5 (для відсутнього — undefined)
```

Класу `Counter` у стандартних бібліотеках C++ і JavaScript немає — підрахунок роблять `map`/`Map` та циклом.

### Інші корисні контейнери

**Python**

```python
from collections import defaultdict, deque

groups = defaultdict(list)
groups["голосні"].append("а")      # ключ створюється автоматично

q = deque([1, 2, 3])
q.appendleft(0)                     # O(1), на відміну від list.insert(0,x)
q.popleft()                         # O(1)
```

**C++**

```cpp
map<string, vector<string>> groups;
groups["vowels"].push_back("a");      // ключ створюється автоматично (оператором [])

deque<int> q = {1, 2, 3};
q.push_front(0);                      // O(1), на відміну від vector::insert(begin, x)
q.pop_front();                        // O(1)
```

**JavaScript**

```javascript
const groups = new Map();
if (!groups.has("vowels")) groups.set("vowels", []);   // автоматичного створення ключа немає
groups.get("vowels").push("a");

const q = [1, 2, 3];
q.unshift(0);                         // додати на початок
q.shift();                            // вилучити з початку
```

У C++ оператор `[]` для `map` працює як `defaultdict`: створює значення за замовчуванням. У JavaScript `shift`/`unshift` у загальному випадку O(n); для великих черг використовують власну реалізацію з індексами.

## 12.6 Генератори словників і множин

**Python**

```python
{x: x ** 2 for x in range(5)}                  # {0:0, 1:1, 2:4, ...}
{k: v for k, v in d.items() if v > 3}          # фільтр
{v: k for k, v in d.items()}                   # обернути (ключ↔значення)
{ch for ch in "абракадабра"}                   # множина символів
```

**C++**

```cpp
map<int, int> squares;
for (int x = 0; x < 5; ++x) squares[x] = x * x;           // {0:0, 1:1, 2:4, ...}

map<string, int> big;
for (const auto &[k, v] : d) if (v > 3) big[k] = v;       // фільтр

map<int, string> inv;
for (const auto &[k, v] : d) inv[v] = k;                  // обернути (ключ↔значення)

set<char> chars;
for (char ch : string("abracadabra")) chars.insert(ch);   // множина символів
```

**JavaScript**

```javascript
Object.fromEntries(Array.from({ length: 5 }, (_, x) => [x, x ** 2]));   // {0:0, 1:1, 2:4, ...}
new Map([...d].filter(([k, v]) => v > 3));                               // фільтр
new Map([...d].map(([k, v]) => [v, k]));                                 // обернути (ключ↔значення)
new Set("abracadabra");                                                  // множина символів
```

## 12.7 Хешованість

Ключами словника й елементами множини можуть бути лише
**незмінні (хешовані)** об'єкти: `int`, `float`, `str`, `bool`,
`tuple` (з незмінних), `frozenset`.

Не можуть: `list`, `dict`, `set`.

У C++ ключем `unordered_map` може бути тип, для якого визначено `std::hash` і `==`; для `map` і `set` потрібен лише оператор `<`, тож ключем може бути і `pair`, і `vector`. У JavaScript `Map` і `Set` приймають будь-які ключі, але об'єкти та масиви порівнюються за **посиланням**, а не за вмістом.

**Python**

```python
hash("текст")         # працює
hash([1, 2])          # TypeError: unhashable type: 'list'
```

**C++**

```cpp
hash<string>{}("text");              // працює: std::hash<string>
// unordered_set<vector<int>> s;     // помилка компіляції: для vector немає std::hash
set<vector<int>> ok;                 // а впорядкована множина працює: для vector визначено <
```

**JavaScript**

```javascript
const s = new Set();
s.add([1, 2]);
s.has([1, 2]);                       // false — це інший масив у пам'яті: порівняння за посиланням
```

## 12.8 Вибір структури даних

| Задача | Структура | Чому |
|--------|-----------|------|
| впорядкована послідовність | `list` | індекси, порядок |
| перевірка «чи є елемент» | `set` | O(1) замість O(n) |
| видалити дублікати | `set` | автоматично |
| підрахувати частоти | `dict` / `Counter` | ключ → кількість |
| відповідність «ім'я → дані» | `dict` | доступ за ключем |
| фіксований запис | `tuple` | незмінність, хешованість |
| черга | `deque` | O(1) з обох боків |
