# Практичні завдання до розділу 15

**Тип завдань:** для кожної задачі
1. визначити складність **наївного** розв'язку (за часом і пам'яттю),
   обґрунтувавши підрахунок;
2. написати **оптимізований** розв'язок із меншою складністю;
3. **експериментально** підтвердити різницю: виміряти час
   для n = 1 000, 2 000, 4 000 і показати, як зростає час
   (таблицею).

Шаблон вимірювання:
```python
import time
t0 = time.perf_counter()
solve(data)
print(f"{time.perf_counter() - t0:.4f} с")
```

### Задача 15.1
Перевірити, чи є у списку повторювані елементи.
```
наївно:  два вкладені цикли     → O(n²)
краще:   множина                → O(n)
```

### Задача 15.2
Знайти спільні елементи двох списків.
```
наївно:  x in b для списку      → O(n·m)
краще:   set(b)                 → O(n+m)
```

### Задача 15.3
Побудувати рядок із n символів у циклі.
```
наївно:  s += ch                → O(n²)
краще:   "".join(parts)         → O(n)
```
**Увага:** у CPython `s += ch` оптимізовано (буфер подовжується
на місці, якщо на рядок одне посилання), тому вимірювання покаже
лінійне зростання. Щоб побачити справжнє O(n²), запишіть
`keep = s; s = keep + ch` — друге посилання вимикає оптимізацію.

### Задача 15.4
Підрахувати частоту елементів списку.
```
наївно:  a.count(x) для кожного x → O(n²)
краще:   словник-накопичувач      → O(n)
```

### Задача 15.5
Багаторазовий пошук (1000 запитів) у масиві з n елементів.
```
наївно:  лінійний пошук щоразу      → O(q·n)
краще:   сортування + двійковий     → O(n log n + q log n)
ще краще: set                       → O(n + q)
```

### Задача 15.6
Обчислити n-те число Фібоначчі.
```
наївно:  рекурсія без кешу      → O(2ⁿ)
краще:   ітерація / мемоізація  → O(n)
```
Виміряти час для n = 25, 30, 32 у наївному варіанті
й показати експоненційне зростання.

### Задача 15.7
Побудувати список із n елементів, додаючи кожен **на початок**.
```
наївно:  a.insert(0, x)         → O(n²)
краще:   append + reverse       → O(n)
ще краще: collections.deque     → O(n)
```

### Задача 15.8
Знайти два числа у списку, сума яких дорівнює заданому значенню.
```
наївно:  два вкладені цикли     → O(n²)
краще:   словник «бачене»       → O(n)
```

### Задача 15.9
Знайти k найбільших елементів списку.
```
наївно:  k разів шукати максимум і видаляти → O(k·n)
краще:   повне сортування                   → O(n log n)
ще краще: heapq.nlargest                    → O(n log k)
```
При малому k (10) і n ≤ 4000 різниця майже не видна —
константи переважають асимптотику. Повторіть експеримент при k = 1000.

### Задача 15.10
Перевірити, чи є число простим.
```
наївно:  дільники до n       → O(n)
краще:   дільники до √n      → O(√n)
```
Для списку всіх простих до n порівняти з **решетом Ератосфена**
→ O(n log log n).
