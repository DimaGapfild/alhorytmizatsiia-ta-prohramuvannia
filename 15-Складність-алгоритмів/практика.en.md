# Practice Tasks for Chapter 15

**Task type:** for each task
1. determine the complexity of the **naive** solution (time and memory),
   justifying the count;
2. write an **optimized** solution with lower complexity;
3. **experimentally** confirm the difference: measure the time
   for n = 1 000, 2 000, 4 000 and show how the time grows
   (in a table).

Measurement template:
```python
import time
t0 = time.perf_counter()
solve(data)
print(f"{time.perf_counter() - t0:.4f} s")
```

---

### Task 15.1
Check whether a list contains duplicate elements.
```
naive:   two nested loops       → O(n²)
better:  a set                  → O(n)
```

### Task 15.2
Find the common elements of two lists.
```
naive:   x in b for a list      → O(n·m)
better:  set(b)                 → O(n+m)
```

### Task 15.3
Build a string of n characters in a loop.
```
naive:   s += ch                → O(n²)
better:  "".join(parts)         → O(n)
```
**Note:** in CPython `s += ch` is optimized (the buffer is extended
in place if the string has a single reference), so the measurement will show
linear growth. To see the true O(n²), write
`keep = s; s = keep + ch` — the second reference disables the optimization.

### Task 15.4
Count the frequency of the elements of a list.
```
naive:   a.count(x) for each x  → O(n²)
better:  an accumulator dict    → O(n)
```

### Task 15.5
Repeated searching (1000 queries) in an array of n elements.
```
naive:   linear search each time    → O(q·n)
better:  sorting + binary search    → O(n log n + q log n)
even better: a set                  → O(n + q)
```

### Task 15.6
Compute the n-th Fibonacci number.
```
naive:   recursion without a cache  → O(2ⁿ)
better:  iteration / memoization    → O(n)
```
Measure the time for n = 25, 30, 32 in the naive version
and show the exponential growth.

### Task 15.7
Build a list of n elements by adding each one **to the front**.
```
naive:   a.insert(0, x)         → O(n²)
better:  append + reverse       → O(n)
even better: collections.deque  → O(n)
```

### Task 15.8
Find two numbers in a list whose sum equals a given value.
```
naive:   two nested loops       → O(n²)
better:  a "seen" dictionary    → O(n)
```

### Task 15.9
Find the k largest elements of a list.
```
naive:   k times find the maximum and remove it → O(k·n)
better:  full sorting                           → O(n log n)
even better: heapq.nlargest                     → O(n log k)
```
With a small k (10) and n ≤ 4000 the difference is almost invisible —
the constants outweigh the asymptotics. Repeat the experiment with k = 1000.

### Task 15.10
Check whether a number is prime.
```
naive:   divisors up to n       → O(n)
better:  divisors up to √n      → O(√n)
```
For a list of all primes up to n, compare with the **Sieve of Eratosthenes**
→ O(n log log n).
