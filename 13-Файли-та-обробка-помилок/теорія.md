# Розділ 13. Файли та обробка помилок

## 13.1 Навіщо файли

Дані у змінних живуть лише під час роботи програми.
Файл дає **постійне (persistent) зберігання**: дані залишаються
після завершення програми.

## 13.2 Відкриття файлу

**Python**

```python
f = open("data.txt", "r", encoding="utf-8")
...
f.close()          # обов'язково!
```

**C++**

```cpp
ifstream f("data.txt");               // відкриття для читання (<fstream>)
// ...
f.close();                            // необов'язково: деструктор закриє файл сам
```

**JavaScript**

```javascript
const fs = require("fs");

const fd = fs.openSync("data.txt", "r");
// ...
fs.closeSync(fd);                     // обов'язково!
```

### Правильний спосіб — менеджер контексту `with`

**Python**

```python
with open("data.txt", "r", encoding="utf-8") as f:
    text = f.read()
# файл закрито автоматично, навіть якщо сталася помилка
```

**C++**

```cpp
string text;
{
    ifstream f("data.txt");
    stringstream buf;
    buf << f.rdbuf();
    text = buf.str();
}                                     // f закрито автоматично в кінці блоку (RAII)
```

**JavaScript**

```javascript
const text = fs.readFileSync("data.txt", "utf8");   // відкриття й закриття — всередині виклику
```

У C++ роль `with` виконує сам час життя об'єкта: коли змінна `ifstream` виходить з області видимості, файл закривається (ідіома **RAII**).

### Режими відкриття

| Режим | Дія | Якщо файлу немає | Якщо є |
|-------|-----|------------------|--------|
| `"r"` | читання | `FileNotFoundError` | читає |
| `"w"` | запис | створює | **стирає вміст!** |
| `"a"` | дозапис | створює | дописує в кінець |
| `"x"` | створення | створює | `FileExistsError` |
| `"r+"` | читання+запис | помилка | не стирає |
| `"rb"` / `"wb"` | бінарний | | для картинок, архівів |

Відповідники у C++ (`<fstream>`) і Node.js (`fs`):

| Python | C++ | Node.js |
|--------|-----|---------|
| `"r"` | `ifstream` (`ios::in`) | `readFileSync` (`"r"`) |
| `"w"` | `ofstream` (`ios::out`) | `writeFileSync` (`"w"`) |
| `"a"` | `ofstream f(path, ios::app)` | `appendFileSync` (`"a"`) |
| `"x"` | немає прямого відповідника | `"wx"` |
| `"r+"` | `fstream` (`ios::in` + `ios::out`) | `"r+"` |
| `"rb"` / `"wb"` | `ios::binary` | `Buffer` (без параметра `"utf8"`) |

У C++ файл — це потік байтів, перетворення кодування немає: український текст у UTF-8 просто читається й записується як є. У Node.js без аргументу `"utf8"` функції `fs` повертають `Buffer`, а не рядок.

**`encoding="utf-8"` вказувати завжди** — інакше поведінка залежить
від операційної системи, і український текст може «поламатися».

## 13.3 Читання

**Python**

```python
with open("f.txt", encoding="utf-8") as f:
    text = f.read()              # увесь файл одним рядком
    
with open("f.txt", encoding="utf-8") as f:
    lines = f.readlines()        # список рядків (із \n на кінці)

with open("f.txt", encoding="utf-8") as f:
    line = f.readline()          # один рядок

with open("f.txt", encoding="utf-8") as f:
    for line in f:               # НАЙКРАЩЕ: по рядку, економно до пам'яті
        print(line.rstrip())     # rstrip() знімає \n
```

**C++**

```cpp
ifstream f("f.txt");
stringstream buf;
buf << f.rdbuf();
string text = buf.str();              // увесь файл одним рядком

ifstream g("f.txt");
vector<string> lines;
for (string s; getline(g, s); ) lines.push_back(s);   // усі рядки (без \n)

ifstream h("f.txt");
string line;
getline(h, line);                     // один рядок

ifstream k("f.txt");
while (getline(k, line)) {            // НАЙКРАЩЕ: по рядку, економно до пам'яті
    cout << line << endl;             // getline уже прибирає \n
}
```

**JavaScript**

```javascript
const text = fs.readFileSync("f.txt", "utf8");      // увесь файл одним рядком
const lines = text.split("\n");                     // список рядків
const first = lines[0];                             // один рядок

const rl = require("readline").createInterface({ input: fs.createReadStream("f.txt") });
rl.on("line", (line) => {                           // НАЙКРАЩЕ для великих файлів: потік, по рядку
  console.log(line);
});
```

## 13.4 Запис

**Python**

```python
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("перший рядок\n")       # \n треба писати самому!
    f.writelines(["a\n", "b\n"])
    print("через print", file=f)     # print сам додає \n
```

**C++**

```cpp
ofstream f("out.txt");
f << "first line\n";                 // \n треба писати самому (або endl)
f << "a\n" << "b\n";
f << "via print" << '\n';            // << приймає і числа: f << 42
```

**JavaScript**

```javascript
fs.writeFileSync("out.txt", "first line\n");        // перезаписує файл (режим "w"), \n — самі
fs.appendFileSync("out.txt", "a\nb\n");             // дозапис (режим "a")
fs.appendFileSync("out.txt", "via print\n");
```

Потік `<<` у C++ перетворює числа на текст сам; у Node.js `fs` приймає лише рядки (або `Buffer`), тому числа перетворюють через `String(n)` чи шаблонний рядок.

`write()` приймає **лише рядок** — числа перетворювати через `str()`
або f-рядок.

## 13.5 Модуль pathlib (сучасний підхід)

**Python**

```python
from pathlib import Path

p = Path("data.txt")
p.exists()                     # чи існує
p.is_file()  p.is_dir()
p.suffix                       # '.txt'
p.stem                         # 'data'
p.stat().st_size               # розмір у байтах

p.write_text("текст", encoding="utf-8")
text = p.read_text(encoding="utf-8")

for f in Path(".").glob("*.txt"):     # перебір файлів
    print(f.name)
```

**C++**

```cpp
namespace fs = std::filesystem;      // заголовок <filesystem>, C++17

fs::path p = "data.txt";
fs::exists(p);                       // чи існує
fs::is_regular_file(p);              // is_file
fs::is_directory(p);                 // is_dir
p.extension();                       // ".txt"
p.stem();                            // "data"
fs::file_size(p);                    // розмір у байтах

for (const auto &e : fs::directory_iterator(".")) {    // перебір файлів
    if (e.path().extension() == ".txt") {
        cout << e.path().filename() << endl;
    }
}
```

**JavaScript**

```javascript
const fs = require("fs");
const path = require("path");

fs.existsSync("data.txt");                    // чи існує
fs.statSync("data.txt").isFile();             // is_file
fs.statSync(".").isDirectory();               // is_dir
path.extname("data.txt");                     // '.txt'
path.parse("data.txt").name;                  // 'data'
fs.statSync("data.txt").size;                 // розмір у байтах

for (const f of fs.readdirSync(".")) {        // перебір файлів
  if (f.endsWith(".txt")) {
    console.log(f);
  }
}
```

## 13.6 CSV — таблиці в текстовому файлі

**Python**

```python
import csv

with open("t.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.writer(f)
    w.writerow(["прізвище", "бал"])
    w.writerows([["Коваль", 74], ["Ткач", 58]])

with open("t.csv", encoding="utf-8") as f:
    for row in csv.reader(f):
        print(row)                    # список рядків

with open("t.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):     # словник за заголовками
        print(row["прізвище"])
```

**C++**

```cpp
{
    ofstream out("t.csv");
    out << "surname,score\n";
    out << "Koval,74\n" << "Tkach,58\n";
}

ifstream in("t.csv");
string line;
while (getline(in, line)) {
    vector<string> row;
    stringstream ss(line);
    for (string cell; getline(ss, cell, ','); ) row.push_back(cell);   // список рядків
    cout << row[0] << endl;
}
```

**JavaScript**

```javascript
fs.writeFileSync("t.csv", ["surname,score", "Koval,74", "Tkach,58"].join("\n") + "\n");

const rows = fs.readFileSync("t.csv", "utf8").trim().split("\n").map(line => line.split(","));
for (const row of rows) {
  console.log(row);                           // список рядків
}

const [header, ...body] = rows;               // аналог DictReader: словник за заголовками
const records = body.map(r => Object.fromEntries(r.map((v, i) => [header[i], v])));
for (const rec of records) {
  console.log(rec.surname);
}
```

Такий розбір працює лише для простих CSV: поля з комами чи лапками потребують бібліотеки (наприклад, `csv-parse` для Node.js). Числа теж читаються як рядки — їх треба перетворити (`stoi`, `Number`).

## 13.7 JSON — структуровані дані

**Python**

```python
import json

data = {"ім'я": "Іван", "бали": [92, 74]}

with open("d.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

with open("d.json", encoding="utf-8") as f:
    data = json.load(f)

s = json.dumps(data, ensure_ascii=False)     # у рядок
data = json.loads(s)                          # з рядка
```

**C++**

```cpp
#include <nlohmann/json.hpp>               // сторонній заголовок (nlohmann/json)
using json = nlohmann::json;

json data = {{"name", "Ivan"}, {"scores", {92, 74}}};

ofstream("d.json") << data.dump(2);        // запис з відступами
ifstream f("d.json");
data = json::parse(f);

string s = data.dump();                    // у рядок
data = json::parse(s);                     // з рядка
```

**JavaScript**

```javascript
let data = { name: "Ivan", scores: [92, 74] };

fs.writeFileSync("d.json", JSON.stringify(data, null, 2));
data = JSON.parse(fs.readFileSync("d.json", "utf8"));

const s = JSON.stringify(data);            // у рядок
data = JSON.parse(s);                      // з рядка
```

У стандартній бібліотеці C++ роботи з JSON немає — використовують сторонню (`nlohmann/json`, `RapidJSON`). У JavaScript `JSON` — вбудований об'єкт, і юнікод він записує як є (параметр на кшталт `ensure_ascii` не потрібен).

`ensure_ascii=False` — щоб українські літери лишались літерами,
а не escape-послідовностями виду `\u0456`.

## 13.8 Виключення (exceptions)

**Виключення** — об'єкт, що описує помилку часу виконання
і перериває нормальний хід програми.

### Основні вбудовані виключення

| Виключення | Коли виникає |
|------------|--------------|
| `ValueError` | правильний тип, неправильне значення: `int("abc")` |
| `TypeError` | неправильний тип: `"a" + 1` |
| `ZeroDivisionError` | ділення на нуль |
| `IndexError` | індекс поза межами списку |
| `KeyError` | немає такого ключа в словнику |
| `FileNotFoundError` | файл не знайдено |
| `PermissionError` | немає прав на файл |
| `AttributeError` | немає такого атрибута/методу |
| `NameError` | змінна не визначена |
| `UnicodeDecodeError` | неправильне кодування файлу |
| `KeyboardInterrupt` | Ctrl+C |

Що відбувається в C++ і JavaScript у схожих ситуаціях:

| Python | C++ | JavaScript |
|--------|-----|------------|
| `ValueError` | `invalid_argument` (`stoi("abc")`) | `NaN` — без винятку |
| `TypeError` | помилка компіляції (статична типізація) | `TypeError` |
| `ZeroDivisionError` | `int`: невизначена поведінка, аварія; `double`: `inf` | `Infinity` — без винятку |
| `IndexError` | `out_of_range` (`at`) або невизначена поведінка (`[]`) | `undefined` — без винятку |
| `KeyError` | `out_of_range` (`map::at`) | `undefined` — без винятку |
| `FileNotFoundError` | потік у стані помилки (`if (!f)`) | `Error` з `code: "ENOENT"` |
| `AttributeError` | помилка компіляції | `TypeError` або `undefined` |
| `NameError` | помилка компіляції | `ReferenceError` |

Висновок: у C++ значну частину помилок виявляє компілятор, а інші призводять до невизначеної поведінки; JavaScript часто «мовчки» повертає `NaN` або `undefined`, тому результати потрібно перевіряти вручну.

## 13.9 Конструкція try / except

**Python**

```python
try:
    n = int(input("Число: "))
    r = 100 / n
except ValueError:
    print("Це не число")
except ZeroDivisionError:
    print("Нуль не підходить")
except (TypeError, KeyError) as e:        # кілька типів разом
    print(f"Помилка: {e}")
else:
    print(f"Результат: {r}")              # якщо винятку НЕ було
finally:
    print("Виконується завжди")           # прибирання ресурсів
```

**C++**

```cpp
try {
    cout << "Число: ";
    string s;
    cin >> s;
    int n = stoi(s);                       // кидає invalid_argument
    if (n == 0) {
        throw domain_error("zero");        // ціле ділення на нуль винятку не кидає — перевіряємо самі
    }
    double r = 100.0 / n;
    cout << "Результат: " << r << endl;
} catch (const invalid_argument &) {
    cout << "Це не число" << endl;
} catch (const domain_error &) {
    cout << "Нуль не підходить" << endl;
} catch (const exception &e) {             // базовий тип стандартних виключень
    cout << "Помилка: " << e.what() << endl;
}
// finally у C++ немає: ресурси звільняють деструктори (RAII)
```

**JavaScript**

```javascript
try {
  const n = Number(lines[0]);
  if (Number.isNaN(n)) throw new TypeError("Це не число");
  if (n === 0) throw new RangeError("Нуль не підходить");
  console.log(`Результат: ${100 / n}`);
} catch (e) {                              // один блок catch: тип перевіряють вручну
  if (e instanceof TypeError || e instanceof RangeError) {
    console.log(e.message);
  } else {
    throw e;                               // невідомі помилки не ковтаємо
  }
} finally {
  console.log("Виконується завжди");
}
```

У C++ і JavaScript немає блоку `else` для `try` — код, який має виконуватись лише без винятку, просто розміщують у кінці `try`. У JavaScript є лише один `catch`, а не кілька за типами.

Порядок блоків: `try` → `except` → `else` → `finally`.

### Чого не робити

**Python**

```python
except:                 # ловить ВСЕ, навіть Ctrl+C — погано
    pass                # помилка проглинута без слідів — дуже погано

except Exception as e:  # прийнятно, якщо ви логуєте помилку
    print(f"Збій: {e}")
```

**C++**

```cpp
try { risky(); }
catch (...) {                         // ловить ВСЕ — погано
    // помилка проглинута без слідів — дуже погано
}

try { risky(); }
catch (const exception &e) {          // прийнятно, якщо ви логуєте помилку
    cerr << "Збій: " << e.what() << endl;
}
```

**JavaScript**

```javascript
try { risky(); }
catch {                               // помилка проглинута без слідів — дуже погано
}

try { risky(); }
catch (e) {                           // прийнятно, якщо ви логуєте помилку
  console.error(`Збій: ${e.message}`);
}
```

Ловіть **конкретні** виключення, які вмієте обробити.

## 13.10 Генерація виключень

**Python**

```python
def sqrt(x):
    if x < 0:
        raise ValueError(f"від'ємний аргумент: {x}")
    return x ** 0.5
```

**C++**

```cpp
double my_sqrt(double x) {
    if (x < 0) {
        throw invalid_argument("від'ємний аргумент: " + to_string(x));
    }
    return sqrt(x);
}
```

**JavaScript**

```javascript
function sqrt(x) {
  if (x < 0) {
    throw new RangeError(`від'ємний аргумент: ${x}`);
  }
  return x ** 0.5;
}
```

У C++ і JavaScript генерують виняток оператором `throw` (а не `raise`). У C++ можна кинути значення будь-якого типу, але прийнято — об'єкт, похідний від `std::exception`.

### Власне виключення

**Python**

```python
class InvalidGradeError(ValueError):
    """Бал поза діапазоном 0..100."""


def check(score):
    if not 0 <= score <= 100:
        raise InvalidGradeError(f"бал {score} поза межами 0..100")
```

**C++**

```cpp
// Бал поза діапазоном 0..100.
class InvalidGradeError : public invalid_argument {
public:
    using invalid_argument::invalid_argument;
};

void check(int score) {
    if (!(0 <= score && score <= 100)) {
        throw InvalidGradeError("бал " + to_string(score) + " поза межами 0..100");
    }
}
```

**JavaScript**

```javascript
// Бал поза діапазоном 0..100.
class InvalidGradeError extends RangeError {
  constructor(score) {
    super(`бал ${score} поза межами 0..100`);
    this.name = "InvalidGradeError";
  }
}

function check(score) {
  if (!(0 <= score && score <= 100)) {
    throw new InvalidGradeError(score);
  }
}
```

## 13.11 Типовий шаблон: надійне читання вводу

**Python**

```python
def read_int(prompt: str) -> int:
    while True:
        try:
            return int(input(prompt))
        except ValueError:
            print("Введіть ціле число.")
```

**C++**

```cpp
int read_int(const string &prompt) {
    while (true) {
        cout << prompt;
        string s;
        cin >> s;
        try {
            return stoi(s);
        } catch (const invalid_argument &) {
            cout << "Введіть ціле число." << endl;
        }
    }
}
```

**JavaScript**

```javascript
const readline = require("readline/promises");
const rl = readline.createInterface({ input: process.stdin, output: process.stdout });

async function readInt(prompt) {
  while (true) {
    const s = await rl.question(prompt);
    const n = Number(s);
    if (s.trim() !== "" && Number.isInteger(n)) {   // Number("abc") дає NaN, а не виняток
      return n;
    }
    console.log("Введіть ціле число.");
  }
}
```

`stoi("12abc")` у C++ поверне 12 без помилки (розбирає лише початок рядка) — для суворої перевірки використовують другий аргумент `stoi(s, &pos)` і порівнюють `pos` з довжиною рядка.

## 13.12 Шаблон: безпечна робота з файлом

**Python**

```python
def load_numbers(path: str) -> list[int]:
    try:
        with open(path, encoding="utf-8") as f:
            return [int(x) for x in f.read().split()]
    except FileNotFoundError:
        print(f"Файл {path} не знайдено")
        return []
    except ValueError as e:
        print(f"Файл містить не лише числа: {e}")
        return []
```

**C++**

```cpp
vector<int> load_numbers(const string &path) {
    ifstream f(path);
    if (!f) {
        cout << "Файл " << path << " не знайдено" << endl;
        return {};
    }
    try {
        vector<int> nums;
        for (string tok; f >> tok; ) nums.push_back(stoi(tok));
        return nums;
    } catch (const invalid_argument &e) {
        cout << "Файл містить не лише числа: " << e.what() << endl;
        return {};
    }
}
```

**JavaScript**

```javascript
function loadNumbers(path) {
  try {
    const text = fs.readFileSync(path, "utf8");
    const nums = text.split(/\s+/).filter(Boolean).map(Number);
    if (nums.some(Number.isNaN)) {
      throw new TypeError("not a number");
    }
    return nums;
  } catch (e) {
    if (e.code === "ENOENT") {
      console.log(`Файл ${path} не знайдено`);
    } else {
      console.log(`Файл містить не лише числа: ${e.message}`);
    }
    return [];
  }
}
```

## 13.13 assert — перевірка припущень

**Python**

```python
assert n > 0, "n має бути додатним"
```

**C++**

```cpp
assert(n > 0 && "n має бути додатним");
```

**JavaScript**

```javascript
const assert = require("assert");
assert(n > 0, "n має бути додатним");
```

У C++ `assert` вимикається макросом `NDEBUG` (типово в release-збірці) — так само, як `python -O` вимикає `assert`. У JavaScript варто користуватись модулем `assert` у Node.js: `console.assert` лише друкує повідомлення й не перериває програму.

Використовується для **внутрішніх інваріантів** і тестів,
а не для перевірки даних користувача (вимикається прапорцем `-O`).
