# Practice Tasks for Chapter 13

**Task type:** reading/writing a file with full error handling.

General requirements for **every** task:
- open files only via `with` and with `encoding="utf-8"`;
- handle `FileNotFoundError` and `ValueError` in separate `except` blocks;
- the function returns the result rather than printing it;
- do not catch exceptions "in general" (`except:` is forbidden).

Preparatory step: create the test files in the `demo/` folder.

```
numbers.txt   10 -3 7 0 25 -8 14
text.txt      three lines of text
students.csv  surname,score — 4 records
broken.txt    10 abc 7 3.5 25 -- 14   ← deliberately corrupted
```

---

### Task 13.1
Read a file of numbers (separated by spaces) and return
their sum, count, maximum, and minimum.
If the file does not exist, return a message instead of "crashing".

### Task 13.2
Read a text file and return the number of lines,
words, and characters (an analogue of the `wc` utility).

### Task 13.3
Write to a file a table of the squares and cubes of the numbers from 1 to n,
aligned in columns. Then read it back and print it.

### Task 13.4
Append (`"a"` mode) a line to a log with a timestamp.
Show that the previous contents are not lost.

### Task 13.5
Read a file of numbers, sort them,
and write the result to a **different** file.
If the output file already exists — warn and do not overwrite it
(`"x"` mode).

### Task 13.6
Write a function `read_int(prompt)` that keeps asking
for an integer until the user enters a valid value.
Test it on a prepared list of "inputs"
(without a real `input()`).

### Task 13.7
Read a CSV file of students and return a dictionary
`surname → score`, as well as the average score.
Handle the case when a score is not a number.

### Task 13.8
Save the dictionary of students to JSON (with `ensure_ascii=False`,
`indent=2`), read it back, and check that the data match.

### Task 13.9
Write a function `safe_divide(a, b)` that handles
`ZeroDivisionError` and `TypeError` and returns `None` on error.
Also create a custom exception `InvalidGradeError`
and a function that raises it for a score outside 0..100.

### Task 13.10
Read the file `broken.txt`, in which there is garbage among the numbers.
Return the sum of the valid numbers only and a list of the positional
numbers of the erroneous tokens. No exception
may interrupt the function.
