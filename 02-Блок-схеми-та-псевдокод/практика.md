# Практичні завдання до розділу 2

**Тип завдань:** побудувати блок-схему, записати псевдокод
і виконати трасування для одного набору вхідних даних.

Оформлення кожної задачі:
1. **блок-схема** (від руки або в draw.io / Excalidraw);
2. **псевдокод** за угодами розділу 2.5;
3. **таблиця трасування** для вказаного тесту.

---

### Задача 2.1
Знайти максимум із трьох чисел. Трасувати для (5, 9, 2).

### Задача 2.2
Визначити, чи є введене число додатним, від'ємним або нулем.
Трасувати для −7.

### Задача 2.3
Обчислити n! (факторіал). Трасувати для n = 5.

### Задача 2.4
Обчислити суму цифр натурального числа. Трасувати для 1234.

### Задача 2.5
Обчислити кількість цифр натурального числа. Трасувати для 70500.

### Задача 2.6
Обчислити a^n для цілого n ≥ 0 без оператора піднесення до степеня.
Трасувати для a = 3, n = 4.

### Задача 2.7
Знайти найбільший спільний дільник двох натуральних чисел
(алгоритм Евкліда з відніманням). Трасувати для (48, 18).

### Задача 2.8
Вивести всі дільники натурального числа n. Трасувати для n = 12.

### Задача 2.9
Перевірити, чи є натуральне число простим. Трасувати для 21.

### Задача 2.10
Обчислити суму ряду 1 + 1/2 + 1/3 + … + 1/n. Трасувати для n = 4.

## Зразок виконання (задача «сума від 1 до n», n = 3)

**Псевдокод**
```
ПОЧАТОК
  ВВЕСТИ n
  s ← 0; i ← 1
  ПОКИ i ≤ n ВИКОНУВАТИ
    s ← s + i
    i ← i + 1
  ВСЕ
  ВИВЕСТИ s
КІНЕЦЬ
```

**Трасування**

| Крок | i | s | i ≤ n |
|------|---|---|-------|
| 0 | 1 | 0 | так |
| 1 | 2 | 1 | так |
| 2 | 3 | 3 | так |
| 3 | 4 | 6 | ні |

Вивід: `6`
