# Розділ 2. Блок-схеми та псевдокод

## 2.1 Призначення блок-схеми

**Блок-схема** — графічне подання алгоритму, де кожна дія позначена
геометричною фігурою, а порядок виконання — стрілками (лініями потоку).

Переваги: наочність, незалежність від мови програмування.
Недоліки: громіздкість для великих алгоритмів.

Стандарт: ДСТУ ISO 5807 (аналог ГОСТ 19.701-90).

## 2.2 Основні блоки

| Фігура | Назва | Призначення |
|--------|-------|-------------|
| овал | **Термінатор** | початок / кінець алгоритму |
| паралелограм | **Дані** | ввід / вивід |
| прямокутник | **Процес** | обчислення, присвоєння |
| ромб | **Рішення** | перевірка умови (2 виходи: так/ні) |
| шестикутник | **Підготовка** | заголовок циклу `for` |
| прямокутник з подвійними боками | **Виклик** | виклик підпрограми |
| коло | **З'єднувач** | розрив лінії потоку |

### Правила оформлення
1. Один вхід і один вихід у блоку «Процес».
2. Потік — зверху вниз, зліва вправо; стрілки обов'язкові лише при відхиленні.
3. З ромба виходять рівно дві лінії, підписані **так** / **ні**.
4. Блоки нумерують для посилань у тексті.
5. Лінії не перетинаються (використовують з'єднувачі).

## 2.3 Три базові структури в блок-схемах

```
СЛІДУВАННЯ        РОЗГАЛУЖЕННЯ              ЦИКЛ "ПОКИ"
                                        
 ┌─────────┐          ◇ умова            ┌──►◇ умова ──нi──►
 │ дія 1   │        так│   │нi           │    │так
 └────┬────┘      ┌────┘   └────┐        │  ┌─▼──────┐
 ┌────▼────┐   ┌──▼───┐   ┌──▼───┐       └──┤ тiло   │
 │ дія 2   │   │ дія А│   │ дія Б│          └────────┘
 └─────────┘   └──┬───┘   └──┬───┘
                  └────┬─────┘
                       ▼
```

## 2.4 Приклад: максимум із двох чисел

```
       ┌──────────┐
       │  Початок │
       └─────┬────┘
       ╔═════▼═════╗
       ║ Ввести a,b║
       ╚═════┬═════╝
             │
          ◇ a > b ?
       так │     │ нi
      ┌────▼──┐ ┌▼──────┐
      │ m ← a │ │ m ← b │
      └────┬──┘ └┬──────┘
           └──┬──┘
       ╔══════▼═══╗
       ║ Вивести m║
       ╚══════┬═══╝
       ┌──────▼───┐
       │  Кінець  │
       └──────────┘
```

## 2.5 Псевдокод

**Псевдокод** — текстовий запис алгоритму з використанням службових
слів, але без строгого синтаксису конкретної мови.

### Угоди, прийняті в курсі

| Конструкція | Запис |
|-------------|-------|
| початок/кінець | `ПОЧАТОК` … `КІНЕЦЬ` |
| ввід/вивід | `ВВЕСТИ x`, `ВИВЕСТИ x` |
| присвоєння | `x ← вираз` |
| розгалуження | `ЯКЩО умова ТО … ІНАКШЕ … ВСЕ` |
| цикл з умовою | `ПОКИ умова ВИКОНУВАТИ … ВСЕ` |
| цикл з параметром | `ДЛЯ i ВІД 1 ДО n ВИКОНУВАТИ … ВСЕ` |
| цикл з постумовою | `ПОВТОРЮВАТИ … ДОКИ умова` |
| підпрограма | `ФУНКЦІЯ f(x) … ПОВЕРНУТИ y … ВСЕ` |
| коментар | `// текст` |

### Приклад: сума чисел від 1 до n

```
ПОЧАТОК
  ВВЕСТИ n
  s ← 0
  ДЛЯ i ВІД 1 ДО n ВИКОНУВАТИ
    s ← s + i
  ВСЕ
  ВИВЕСТИ s
КІНЕЦЬ
```

### Той самий алгоритм на Python

```python
n = int(input())
s = 0
for i in range(1, n + 1):
    s += i
print(s)
```

## 2.6 Трасування алгоритму

**Трасування** — покрокове заповнення таблиці значень змінних.
Основний спосіб перевірки алгоритму «на папері».

Приклад для n = 4:

| Крок | i | s | Умова i ≤ n |
|------|---|---|-------------|
| 0 | — | 0 | — |
| 1 | 1 | 1 | так |
| 2 | 2 | 3 | так |
| 3 | 3 | 6 | так |
| 4 | 4 | 10 | так |
| 5 | 5 | 10 | ні → вихід |

Результат: s = 10. ✔
