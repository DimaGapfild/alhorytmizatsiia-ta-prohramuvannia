# Practice Tasks for Chapter 2

**Task type:** draw a flowchart, write pseudocode,
and trace the algorithm for one set of input data.

How to present each task:
1. a **flowchart** (by hand or in draw.io / Excalidraw);
2. **pseudocode** following the conventions of Section 2.5;
3. a **trace table** for the specified test.

## Worked Sample (the "sum from 1 to n" task, n = 3)

**Pseudocode**
```
BEGIN
  INPUT n
  s ← 0; i ← 1
  WHILE i ≤ n DO
    s ← s + i
    i ← i + 1
  END
  OUTPUT s
END
```

**Trace**

| Step | i | s | i ≤ n |
|------|---|---|-------|
| 0 | 1 | 0 | yes |
| 1 | 2 | 1 | yes |
| 2 | 3 | 3 | yes |
| 3 | 4 | 6 | no |

Output: `6`
