# Розділ 1. Вступ до алгоритмізації

## 1.1 Поняття алгоритму

**Алгоритм** — це чітко визначена скінченна послідовність дій, яка за
скінченний час перетворює вхідні дані у результат.

Назва походить від імені математика IX ст. аль-Хорезмі (al-Khwārizmī).

## 1.2 Властивості алгоритму

| Властивість | Зміст | Приклад порушення |
|-------------|-------|-------------------|
| **Дискретність** | складається з окремих завершених кроків | «якось перемішати» |
| **Визначеність** (детермінованість) | кожен крок однозначний, не допускає тлумачень | «додати трохи солі» |
| **Результативність** | завершується і дає результат | нескінченний цикл |
| **Масовість** | працює для цілого класу вхідних даних | «розв'язати 2x=6» (лише один випадок) |
| **Скінченність** | кількість кроків обмежена | «перебрати всі натуральні числа» |
| **Коректність** | результат відповідає задачі | сортування, що псує дані |

## 1.3 Виконавець алгоритму

**Виконавець** — об'єкт, що виконує команди алгоритму.
Його характеризують:
- **система команд** — перелік дій, які він розуміє;
- **середовище** — умови, в яких він діє;
- **відмови** — ситуації, коли команду виконати неможливо.

Приклад: виконавець «процесор», система команд — машинні інструкції,
відмова — ділення на нуль.

## 1.4 Способи опису алгоритмів

1. **Словесний (вербальний)** — текстом природною мовою.
2. **Графічний** — блок-схема (див. розділ 2).
3. **Псевдокод** — напівформальна мова, проміжна між природною і мовою програмування.
4. **Табличний** — таблиці переходів, вирішальні таблиці.
5. **Програма** — запис мовою програмування.

### Приклад: словесний опис

Задача: знайти суму двох чисел.

```
1. Отримати число a.
2. Отримати число b.
3. Обчислити s = a + b.
4. Вивести s.
5. Кінець.
```

## 1.5 Базові структури алгоритмів

Будь-який алгоритм можна скласти з трьох конструкцій
(теорема Бьома–Якопіні):

| Структура | Назва | Сутність |
|-----------|-------|----------|
| **Слідування** | лінійна | дії одна за одною |
| **Розгалуження** | умовна | вибір однієї з гілок за умовою |
| **Повторення** | циклічна | повторення дій |

## 1.6 Етапи розв'язування задачі на комп'ютері

1. **Постановка задачі** — що дано, що знайти.
2. **Побудова математичної моделі** — формули, обмеження.
3. **Розробка алгоритму** — блок-схема / псевдокод.
4. **Запис програми** — кодування.
5. **Тестування й відлагодження** — перевірка на тестах, у т.ч. крайніх.
6. **Аналіз результатів і документування**.

## 1.7 Вхідні, вихідні та проміжні дані

- **Вхідні** — те, що алгоритм отримує (`a`, `b`).
- **Вихідні** — результат (`s`).
- **Проміжні** — допоміжні величини, потрібні лише під час обчислення.

## 1.8 Приклад повного оформлення задачі

**Задача.** Обчислити площу прямокутного трикутника за катетами.

- **Дано:** a > 0, b > 0 — довжини катетів.
- **Знайти:** S — площу.
- **Модель:** S = (a · b) / 2.
- **Алгоритм:**
  ```
  ПОЧАТОК
    ВВЕСТИ a, b
    S ← a * b / 2
    ВИВЕСТИ S
  КІНЕЦЬ
  ```
- **Тести:** (3, 4) → 6; (1, 1) → 0.5; (10, 0.2) → 1.0.
