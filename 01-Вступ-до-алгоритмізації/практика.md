# Практичні завдання до розділу 1

**Тип завдань:** формальна постановка задачі та словесний опис алгоритму.

Для кожної задачі оформити **чотири пункти**:
1. **Дано** — вхідні дані з обмеженнями;
2. **Знайти** — вихідні дані;
3. **Модель** — формули;
4. **Алгоритм** — нумерований словесний опис (без мови програмування);
5. **Тести** — щонайменше 3 набори, зокрема один крайній.

---

### Задача 1.1
Обчислити периметр і площу прямокутника за двома сторонами.

### Задача 1.2
Обчислити довжину кола і площу круга за радіусом.

### Задача 1.3
Обчислити об'єм і площу повної поверхні прямокутного паралелепіпеда
за трьома вимірами.

### Задача 1.4
Обчислити середнє арифметичне трьох дійсних чисел.

### Задача 1.5
Перевести температуру з градусів Цельсія у градуси Фаренгейта.

### Задача 1.6
Обчислити відстань між двома точками площини за їхніми координатами.

### Задача 1.7
Обчислити шлях, який проїде автомобіль за час t зі швидкістю v,
та витрату палива, якщо на 100 км витрачається q літрів.

### Задача 1.8
Обчислити суму вкладу через рік за простими відсотками:
дано початкову суму та річну ставку у відсотках.

### Задача 1.9
Обчислити площу трикутника за трьома сторонами (формула Герона).
Вказати обмеження на вхідні дані.

### Задача 1.10
Обчислити вартість покупки: дано ціну одиниці товару, кількість
і знижку у відсотках.

## Форма звіту (зразок для задачі 1.1)

```
Дано:    a > 0, b > 0 — сторони прямокутника (дійсні)
Знайти:  P — периметр, S — площа
Модель:  P = 2*(a + b);  S = a * b
Алгоритм:
  1. Ввести a.
  2. Ввести b.
  3. P ← 2 * (a + b)
  4. S ← a * b
  5. Вивести P, S.
  6. Кінець.
Тести:   (3, 4) → P=14, S=12
         (1, 1) → P=4,  S=1
         (0.5, 100) → P=201, S=50
```
