# Розділ 9. Матриці (двовимірні масиви)

## 9.1 Поняття

**Двовимірний масив (матриця)** — таблиця з m рядків і n стовпців.
Елемент позначається `a[i][j]`, де `i` — номер рядка, `j` — стовпця
(нумерація з 0).

```
        j=0  j=1  j=2
i=0  [   1    2    3  ]
i=1  [   4    5    6  ]
i=2  [   7    8    9  ]
```

У Python матриця — це **список списків**:
```python
a = [[1, 2, 3],
     [4, 5, 6],
     [7, 8, 9]]

a[1][2]        # 6
len(a)         # 3  — кількість рядків
len(a[0])      # 3  — кількість стовпців
```

## 9.2 Створення матриці

### Правильно
```python
m, n = 3, 4
a = [[0] * n for _ in range(m)]            # m різних рядків
a = [[0 for _ in range(n)] for _ in range(m)]
```

### ПОМИЛКА — так робити не можна
```python
a = [[0] * n] * m        # усі m рядків — ОДИН і той самий список!
a[0][0] = 1
print(a)                 # [[1,0,0,0], [1,0,0,0], [1,0,0,0]]
```

### Зі вводу
```python
m, n = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(m)]
```

### Заповнення за формулою
```python
a = [[i * n + j + 1 for j in range(n)] for i in range(m)]
```

## 9.3 Вивід матриці

```python
for row in a:
    print(" ".join(f"{x:4d}" for x in row))
```
або
```python
for row in a:
    print(*row)
```

## 9.4 Перебір

### Усі елементи
```python
for i in range(m):
    for j in range(n):
        ...a[i][j]...
```

### По рядках / стовпцях
```python
for i in range(m):            # сума i-го рядка
    s = sum(a[i])

for j in range(n):            # сума j-го стовпця
    s = sum(a[i][j] for i in range(m))
```

### Транспонування
```python
t = [[a[i][j] for i in range(m)] for j in range(n)]
# або: t = [list(row) for row in zip(*a)]
```

## 9.5 Діагоналі квадратної матриці (m = n)

| Назва | Умова | Приклад елементів |
|-------|-------|-------------------|
| **головна** діагональ | `i == j` | a[0][0], a[1][1], … |
| **побічна** (антидіагональ) | `i + j == n - 1` | a[0][n-1], a[1][n-2], … |
| **вище** головної | `i < j` | |
| **нижче** головної | `i > j` | |
| вище побічної | `i + j < n - 1` | |
| нижче побічної | `i + j > n - 1` | |

```python
main_diag = sum(a[i][i] for i in range(n))
anti_diag = sum(a[i][n - 1 - i] for i in range(n))
above = sum(a[i][j] for i in range(n) for j in range(n) if i < j)
```

## 9.6 Операції над матрицями

### Додавання (однакові розміри)
```python
c = [[a[i][j] + b[i][j] for j in range(n)] for i in range(m)]
```

### Множення на число
```python
c = [[k * a[i][j] for j in range(n)] for i in range(m)]
```

### Множення матриць (m×k) · (k×n) = (m×n)
```python
c = [[sum(a[i][t] * b[t][j] for t in range(k))
      for j in range(n)] for i in range(m)]
```

### Пошук максимуму та його позиції
```python
best, pi, pj = a[0][0], 0, 0
for i in range(m):
    for j in range(n):
        if a[i][j] > best:
            best, pi, pj = a[i][j], i, j
```

### Обмін двох рядків / стовпців
```python
a[i], a[k] = a[k], a[i]                       # рядки
for i in range(m):                            # стовпці
    a[i][j], a[i][k] = a[i][k], a[i][j]
```

### Сортування рядків матриці за сумою
```python
a.sort(key=sum)
```

## 9.7 Спеціальні види матриць

| Вид | Умова |
|-----|-------|
| квадратна | m = n |
| одинична | `a[i][j] == (1 if i == j else 0)` |
| симетрична | `a[i][j] == a[j][i]` для всіх i, j |
| верхня трикутна | `a[i][j] == 0` при i > j |
| нульова | усі елементи 0 |

## 9.8 Поворот квадратної матриці на 90° за годинниковою

```python
b = [[a[n - 1 - j][i] for j in range(n)] for i in range(n)]
# коротко: b = [list(row) for row in zip(*a[::-1])]
```
