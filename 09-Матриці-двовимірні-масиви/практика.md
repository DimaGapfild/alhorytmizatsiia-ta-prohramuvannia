# Практичні завдання до розділу 9

**Тип завдань:** обробка двовимірного масиву (матриці) цілих чисел.

Формат вводу:
```
3 3            ← кількість рядків і стовпців
1 2 3
4 5 6
7 8 9
```

Для задач із діагоналями матриця квадратна (m = n).
Матрицю-результат виводити рівними стовпчиками (`f"{x:4d}"`).

---

### Задача 9.1
Вивести суму всіх елементів, максимум і мінімум із їхніми позиціями.
```
max=9 (2,2), min=1 (0,0), сума=45
```

### Задача 9.2
Вивести суму елементів кожного рядка та кожного стовпця.
```
рядки: 6 15 24
стовпці: 12 15 18
```

### Задача 9.3
Вивести транспоновану матрицю.
```
1 4 7
2 5 8
3 6 9
```

### Задача 9.4
Обчислити суму елементів головної та побічної діагоналей
(для квадратної матриці).
```
головна = 15, побічна = 15
```

### Задача 9.5
Обчислити суму елементів вище головної діагоналі
та суму елементів нижче неї.
```
вище = 11, нижче = 19
```

### Задача 9.6
Підрахувати кількість додатних, від'ємних і нульових елементів
матриці.
```
[[1,-2],[0,5]] → додатних 2, від'ємних 1, нулів 1
```

### Задача 9.7
Поміняти місцями два вказані рядки матриці, потім — два стовпці.
```
рядки 0 і 2, стовпці 0 і 1
```

### Задача 9.8
Відсортувати рядки матриці за зростанням суми їхніх елементів.
```
[[7,8,9],[1,2,3],[4,5,6]] → [[1,2,3],[4,5,6],[7,8,9]]
```

### Задача 9.9
Повернути квадратну матрицю на 90° за годинниковою стрілкою.
```
1 2 3        7 4 1
4 5 6   →    8 5 2
7 8 9        9 6 3
```

### Задача 9.10
Перемножити дві матриці розмірів m×k і k×n.
Якщо розміри несумісні — повідомити про помилку.
```
[[1,2],[3,4]] · [[5,6],[7,8]] → [[19,22],[43,50]]
```
