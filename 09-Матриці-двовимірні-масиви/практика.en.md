# Practice Tasks for Chapter 9

**Task type:** processing a two-dimensional array (matrix) of integers.

Input format:
```
3 3            ← number of rows and columns
1 2 3
4 5 6
7 8 9
```

For tasks involving diagonals the matrix is square (m = n).
Print the result matrix in even columns (`f"{x:4d}"`).

---

### Task 9.1
Print the sum of all elements, the maximum and the minimum with their positions.
```
max=9 (2,2), min=1 (0,0), sum=45
```

### Task 9.2
Print the sum of the elements of each row and of each column.
```
rows: 6 15 24
columns: 12 15 18
```

### Task 9.3
Print the transposed matrix.
```
1 4 7
2 5 8
3 6 9
```

### Task 9.4
Compute the sum of the elements of the main and secondary diagonals
(for a square matrix).
```
main = 15, secondary = 15
```

### Task 9.5
Compute the sum of the elements above the main diagonal
and the sum of the elements below it.
```
above = 11, below = 19
```

### Task 9.6
Count the positive, negative, and zero elements
of the matrix.
```
[[1,-2],[0,5]] → positive 2, negative 1, zeros 1
```

### Task 9.7
Swap two specified rows of the matrix, then two columns.
```
rows 0 and 2, columns 0 and 1
```

### Task 9.8
Sort the rows of the matrix in ascending order of the sum of their elements.
```
[[7,8,9],[1,2,3],[4,5,6]] → [[1,2,3],[4,5,6],[7,8,9]]
```

### Task 9.9
Rotate a square matrix 90° clockwise.
```
1 2 3        7 4 1
4 5 6   →    8 5 2
7 8 9        9 6 3
```

### Task 9.10
Multiply two matrices of sizes m×k and k×n.
If the sizes are incompatible, report an error.
```
[[1,2],[3,4]] · [[5,6],[7,8]] → [[19,22],[43,50]]
```
