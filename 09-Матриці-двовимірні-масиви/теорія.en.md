# Chapter 9. Matrices (Two-Dimensional Arrays)

## 9.1 The Concept

A **two-dimensional array (matrix)** is a table with m rows and n columns.
An element is written `a[i][j]`, where `i` is the row number and `j` the column number
(numbering starts at 0).

```
        j=0  j=1  j=2
i=0  [   1    2    3  ]
i=1  [   4    5    6  ]
i=2  [   7    8    9  ]
```

In Python a matrix is a **list of lists**:
```python
a = [[1, 2, 3],
     [4, 5, 6],
     [7, 8, 9]]

a[1][2]        # 6
len(a)         # 3  — number of rows
len(a[0])      # 3  — number of columns
```

## 9.2 Creating a Matrix

### The right way
```python
m, n = 3, 4
a = [[0] * n for _ in range(m)]            # m distinct rows
a = [[0 for _ in range(n)] for _ in range(m)]
```

### A MISTAKE — do not do it this way
```python
a = [[0] * n] * m        # all m rows are ONE and the same list!
a[0][0] = 1
print(a)                 # [[1,0,0,0], [1,0,0,0], [1,0,0,0]]
```

### From input
```python
m, n = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(m)]
```

### Filling by a formula
```python
a = [[i * n + j + 1 for j in range(n)] for i in range(m)]
```

## 9.3 Printing a Matrix

```python
for row in a:
    print(" ".join(f"{x:4d}" for x in row))
```
or
```python
for row in a:
    print(*row)
```

## 9.4 Traversal

### All elements
```python
for i in range(m):
    for j in range(n):
        ...a[i][j]...
```

### By rows / columns
```python
for i in range(m):            # sum of the i-th row
    s = sum(a[i])

for j in range(n):            # sum of the j-th column
    s = sum(a[i][j] for i in range(m))
```

### Transposition
```python
t = [[a[i][j] for i in range(m)] for j in range(n)]
# or: t = [list(row) for row in zip(*a)]
```

## 9.5 Diagonals of a Square Matrix (m = n)

| Name | Condition | Example elements |
|------|-----------|------------------|
| **main** diagonal | `i == j` | a[0][0], a[1][1], … |
| **secondary** (anti-diagonal) | `i + j == n - 1` | a[0][n-1], a[1][n-2], … |
| **above** the main | `i < j` | |
| **below** the main | `i > j` | |
| above the secondary | `i + j < n - 1` | |
| below the secondary | `i + j > n - 1` | |

```python
main_diag = sum(a[i][i] for i in range(n))
anti_diag = sum(a[i][n - 1 - i] for i in range(n))
above = sum(a[i][j] for i in range(n) for j in range(n) if i < j)
```

## 9.6 Operations on Matrices

### Addition (same sizes)
```python
c = [[a[i][j] + b[i][j] for j in range(n)] for i in range(m)]
```

### Multiplication by a number
```python
c = [[k * a[i][j] for j in range(n)] for i in range(m)]
```

### Matrix multiplication (m×k) · (k×n) = (m×n)
```python
c = [[sum(a[i][t] * b[t][j] for t in range(k))
      for j in range(n)] for i in range(m)]
```

### Finding the maximum and its position
```python
best, pi, pj = a[0][0], 0, 0
for i in range(m):
    for j in range(n):
        if a[i][j] > best:
            best, pi, pj = a[i][j], i, j
```

### Swapping two rows / columns
```python
a[i], a[k] = a[k], a[i]                       # rows
for i in range(m):                            # columns
    a[i][j], a[i][k] = a[i][k], a[i][j]
```

### Sorting the rows of a matrix by sum
```python
a.sort(key=sum)
```

## 9.7 Special Kinds of Matrices

| Kind | Condition |
|------|-----------|
| square | m = n |
| identity | `a[i][j] == (1 if i == j else 0)` |
| symmetric | `a[i][j] == a[j][i]` for all i, j |
| upper triangular | `a[i][j] == 0` when i > j |
| zero | all elements are 0 |

## 9.8 Rotating a Square Matrix 90° Clockwise

```python
b = [[a[n - 1 - j][i] for j in range(n)] for i in range(n)]
# shorter: b = [list(row) for row in zip(*a[::-1])]
```
