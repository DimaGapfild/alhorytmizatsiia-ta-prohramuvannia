# Розділ 14. Основи об'єктно-орієнтованого програмування

## 14.1 Від процедурного до об'єктного

Процедурний підхід: **дані окремо, функції окремо**.

**Python**

```python
student = {"name": "Коваль", "grades": [74, 82]}

def average(s):
    return sum(s["grades"]) / len(s["grades"])
```

**C++**

```cpp
struct Student {                        // поля структури перевіряє компілятор
    string name;
    vector<int> grades;
};

double average(const Student &s) {      // функція окремо від даних
    return accumulate(s.grades.begin(), s.grades.end(), 0.0) / s.grades.size();
}

Student student = {"Коваль", {74, 82}};
```

**JavaScript**

```javascript
const student = { name: "Коваль", grades: [74, 82] };

function average(s) {
  return s.grades.reduce((p, q) => p + q, 0) / s.grades.length;
}
```

У C++ відсутність поля в `struct` — це помилка компіляції; у Python і JavaScript відсутній ключ виявиться лише під час виконання.

Проблема: нічого не гарантує, що в словнику є потрібні ключі,
і функція `average` ніяк не «прив'язана» до даних.

ООП **об'єднує дані й поведінку** в одну сутність — об'єкт.

## 14.2 Клас і об'єкт

- **Клас** — опис (шаблон, тип) сутності: які в неї дані та дії.
- **Об'єкт (екземпляр)** — конкретне втілення класу.

Аналогія: клас «креслення автомобіля», об'єкт — конкретна машина.

**Python**

```python
class Student:
    """Студент із набором оцінок."""

    def __init__(self, name: str, group: str):
        self.name = name            # атрибут екземпляра
        self.group = group
        self.grades: list[int] = []

    def add_grade(self, score: int) -> None:
        """Додає оцінку з перевіркою діапазону."""
        if not 0 <= score <= 100:
            raise ValueError(f"бал {score} поза межами 0..100")
        self.grades.append(score)

    def average(self) -> float:
        """Середній бал; 0, якщо оцінок немає."""
        return sum(self.grades) / len(self.grades) if self.grades else 0.0


s = Student("Коваль", "КН-21")      # створення об'єкта
s.add_grade(74)
s.add_grade(82)
print(s.average())                  # 78.0
```

**C++**

```cpp
// Студент із набором оцінок.
class Student {
public:
    Student(string name, string group)        // конструктор
        : name(move(name)), group(move(group)) {}

    void add_grade(int score) {               // Додає оцінку з перевіркою діапазону.
        if (!(0 <= score && score <= 100)) {
            throw invalid_argument("бал " + to_string(score) + " поза межами 0..100");
        }
        grades.push_back(score);
    }

    double average() const {                  // Середній бал; 0, якщо оцінок немає.
        if (grades.empty()) return 0.0;
        return accumulate(grades.begin(), grades.end(), 0.0) / grades.size();
    }

    string name;                              // атрибути (поля) екземпляра
    string group;
    vector<int> grades;
};

int main() {
    Student s("Коваль", "КН-21");             // створення об'єкта
    s.add_grade(74);
    s.add_grade(82);
    cout << s.average() << endl;              // 78
}
```

**JavaScript**

```javascript
// Студент із набором оцінок.
class Student {
  constructor(name, group) {                  // конструктор
    this.name = name;                         // властивість екземпляра
    this.group = group;
    this.grades = [];
  }

  addGrade(score) {                           // Додає оцінку з перевіркою діапазону.
    if (!(0 <= score && score <= 100)) {
      throw new RangeError(`бал ${score} поза межами 0..100`);
    }
    this.grades.push(score);
  }

  average() {                                 // Середній бал; 0, якщо оцінок немає.
    if (this.grades.length === 0) return 0;
    return this.grades.reduce((p, q) => p + q, 0) / this.grades.length;
  }
}

const s = new Student("Коваль", "КН-21");     // створення об'єкта: слово new
s.addGrade(74);
s.addGrade(82);
console.log(s.average());                     // 78
```

У C++ поля класу потрібно **оголосити** в тілі класу (з типами), а `public`/`private` задають доступ. У JavaScript створення об'єкта вимагає слова `new`, а властивості з'являються під час присвоєння `this.x = ...`.

## 14.3 self, __init__ і атрибути

- `__init__` — **конструктор**: викликається автоматично при створенні.
- `self` — посилання на **поточний об'єкт**; перший параметр
  кожного методу екземпляра. Пишеться в оголошенні, але не в виклику.

**Python**

```python
s.add_grade(74)        # Python передає: Student.add_grade(s, 74)
```

**C++**

```cpp
s.add_grade(74);        // C++ неявно передає вказівник this: add_grade(&s, 74)
```

**JavaScript**

```javascript
s.addGrade(74);         // усередині методу this посилається на s
```

У C++ `this` — **вказівник** на поточний об'єкт (`this->name`, а часто й просто `name`); він не пишеться у списку параметрів. У JavaScript `this` визначається в момент виклику, тому, відокремивши метод (`const f = s.addGrade; f(74)`), його легко втратити.

### Атрибути класу vs екземпляра

**Python**

```python
class Student:
    university = "НУ «ЛП»"      # АТРИБУТ КЛАСУ — спільний для всіх
    count = 0

    def __init__(self, name):
        self.name = name        # АТРИБУТ ЕКЗЕМПЛЯРА — свій у кожного
        Student.count += 1
```

**C++**

```cpp
class Student {
public:
    inline static const string university = "НУ «ЛП»";   // АТРИБУТ КЛАСУ (static) — спільний для всіх
    inline static int count = 0;

    Student(string name) : name(move(name)) {
        count++;
    }

    string name;                                       // АТРИБУТ ЕКЗЕМПЛЯРА — свій у кожного
};
```

**JavaScript**

```javascript
class Student {
  static university = "НУ «ЛП»";   // СТАТИЧНЕ ПОЛЕ — спільне для всіх
  static count = 0;

  constructor(name) {
    this.name = name;                                  // ВЛАСТИВІСТЬ ЕКЗЕМПЛЯРА — своя у кожного
    Student.count += 1;
  }
}
```

## 14.4 Магічні (dunder) методи

| Метод | Викликається | Призначення |
|-------|--------------|-------------|
| `__init__` | `Student(...)` | конструктор |
| `__str__` | `print(obj)`, `str(obj)` | подання для користувача |
| `__repr__` | у REPL, `repr(obj)` | подання для розробника |
| `__len__` | `len(obj)` | довжина |
| `__eq__` | `a == b` | порівняння на рівність |
| `__lt__` | `a < b`, `sorted()` | «менше» |
| `__add__` | `a + b` | додавання |
| `__getitem__` | `obj[i]` | індексація |
| `__contains__` | `x in obj` | входження |
| `__call__` | `obj()` | виклик як функції |

Відповідники у C++ та JavaScript:

| Python | C++ | JavaScript |
|--------|-----|------------|
| `__init__` | конструктор `Student(...)` | `constructor` |
| `__str__` | `operator<<` (для `cout`) | `toString()` |
| `__repr__` | власна функція | `util.inspect`, `console.log` |
| `__len__` | метод `size()` | властивість `length` |
| `__eq__` | `operator==` | немає: метод `equals` |
| `__lt__` | `operator<` | немає: функція-компаратор |
| `__add__` | `operator+` | немає: метод `add` |
| `__getitem__` | `operator[]` | немає: метод `get` |
| `__call__` | `operator()` (функтор) | функція вже є викликуваним об'єктом |

У C++ можна перевантажити майже будь-який оператор; у JavaScript перевантаження операторів **немає**.

**Python**

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __str__(self):
        return f"({self.x}; {self.y})"

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

    def __eq__(self, other):
        return (self.x, self.y) == (other.x, other.y)

    def __add__(self, other):
        return Point(self.x + other.x, self.y + other.y)

    def __abs__(self):
        return (self.x ** 2 + self.y ** 2) ** 0.5


p = Point(1, 2) + Point(3, 4)
print(p)              # (4; 6)
print(abs(p))         # 7.211...
```

**C++**

```cpp
class Point {
public:
    Point(double x, double y) : x(x), y(y) {}

    bool operator==(const Point &o) const { return x == o.x && y == o.y; }       // __eq__
    Point operator+(const Point &o) const { return Point(x + o.x, y + o.y); }    // __add__
    double abs() const { return sqrt(x * x + y * y); }                           // __abs__ (звичайний метод)

    friend ostream &operator<<(ostream &os, const Point &p) {                    // __str__: вивід через cout
        return os << "(" << p.x << "; " << p.y << ")";
    }

    double x, y;
};

int main() {
    Point p = Point(1, 2) + Point(3, 4);
    cout << p << endl;                  // (4; 6)
    cout << p.abs() << endl;            // 7.2111
}
```

**JavaScript**

```javascript
class Point {
  constructor(x, y) {
    this.x = x;
    this.y = y;
  }

  toString() { return `(${this.x}; ${this.y})`; }            // __str__
  equals(o) { return this.x === o.x && this.y === o.y; }     // __eq__: оператор == не перевантажується
  add(o) { return new Point(this.x + o.x, this.y + o.y); }   // __add__: оператор + не перевантажується
  abs() { return Math.hypot(this.x, this.y); }
}

const p = new Point(1, 2).add(new Point(3, 4));
console.log(String(p));                 // (4; 6)
console.log(p.abs());                   // 7.211102550927978
```

## 14.5 Три принципи ООП

### Інкапсуляція
Приховування внутрішньої будови; доступ лише через методи.

Угоди Python (мова не забороняє доступ технічно):

**Python**

```python
self.name       # публічний
self._cache     # «захищений» — не трогати зовні (угода)
self.__secret   # name mangling → _ClassName__secret
```

**C++**

```cpp
class A {
public:
    string name;          // public: доступно всім
protected:
    string cache;         // protected: клас і його нащадки — це РЕАЛЬНА заборона
private:
    string secret;        // private: лише методи цього класу — РЕАЛЬНА заборона
};
```

**JavaScript**

```javascript
class A {
  #secret = 1;            // ПРИВАТНЕ поле (#): реальна заборона доступу ззовні

  constructor() {
    this.name = "x";      // публічна
    this._cache = [];     // «захищена» — лише угода, як у Python
  }
}
```

На відміну від Python, у C++ `private`/`protected` перевіряє компілятор. У сучасному JavaScript реальну приватність дають поля з `#`; підкреслення — лише домовленість.

Властивості (`property`) — доступ як до атрибута, з перевіркою:

**Python**

```python
class Temperature:
    def __init__(self, celsius=0):
        self._celsius = celsius

    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("нижче абсолютного нуля")
        self._celsius = value

    @property
    def fahrenheit(self):             # обчислювана, лише для читання
        return self._celsius * 9 / 5 + 32


t = Temperature()
t.celsius = 100          # викликається setter
print(t.fahrenheit)      # 212.0
```

**C++**

```cpp
class Temperature {
public:
    Temperature(double celsius = 0) : celsius_(celsius) {}

    double celsius() const { return celsius_; }                   // getter
    void set_celsius(double value) {                              // setter
        if (value < -273.15) {
            throw invalid_argument("нижче абсолютного нуля");
        }
        celsius_ = value;
    }

    double fahrenheit() const { return celsius_ * 9 / 5 + 32; }   // обчислюваний, лише для читання

private:
    double celsius_;
};

int main() {
    Temperature t;
    t.set_celsius(100);                  // setter викликаємо явно
    cout << t.fahrenheit() << endl;      // 212
}
```

**JavaScript**

```javascript
class Temperature {
  #celsius;

  constructor(celsius = 0) {
    this.#celsius = celsius;
  }

  get celsius() { return this.#celsius; }
  set celsius(value) {
    if (value < -273.15) {
      throw new RangeError("нижче абсолютного нуля");
    }
    this.#celsius = value;
  }

  get fahrenheit() { return this.#celsius * 9 / 5 + 32; }   // обчислювана, лише для читання
}

const t = new Temperature();
t.celsius = 100;                         // викликається setter
console.log(t.fahrenheit);               // 212
```

У C++ властивостей (`property`) немає — користуються парою методів `get`/`set`. JavaScript, як і Python, має синтаксис `get`/`set`, що виглядає як звичайний доступ до поля.

### Успадкування
Новий клас отримує дані й поведінку батьківського.

**Python**

```python
class Person:
    def __init__(self, name):
        self.name = name

    def info(self) -> str:
        return f"Особа: {self.name}"


class Student(Person):
    def __init__(self, name, group):
        super().__init__(name)        # виклик конструктора батька
        self.group = group

    def info(self) -> str:            # ПЕРЕВИЗНАЧЕННЯ (override)
        return f"Студент: {self.name}, група {self.group}"


class Teacher(Person):
    def __init__(self, name, subject):
        super().__init__(name)
        self.subject = subject

    def info(self) -> str:
        return f"Викладач: {self.name}, предмет {self.subject}"
```

**C++**

```cpp
class Person {
public:
    Person(string name) : name(move(name)) {}
    virtual ~Person() = default;
    virtual string info() const { return "Особа: " + name; }          // virtual дозволяє перевизначення

protected:
    string name;
};

class Student : public Person {
public:
    Student(string name, string group)
        : Person(move(name)), group(move(group)) {}                   // виклик конструктора батька

    string info() const override {                                    // ПЕРЕВИЗНАЧЕННЯ (override)
        return "Студент: " + name + ", група " + group;
    }

private:
    string group;
};

class Teacher : public Person {
public:
    Teacher(string name, string subject)
        : Person(move(name)), subject(move(subject)) {}

    string info() const override {
        return "Викладач: " + name + ", предмет " + subject;
    }

private:
    string subject;
};
```

**JavaScript**

```javascript
class Person {
  constructor(name) {
    this.name = name;
  }

  info() {
    return `Особа: ${this.name}`;
  }
}

class Student extends Person {
  constructor(name, group) {
    super(name);                        // виклик конструктора батька
    this.group = group;
  }

  info() {                              // ПЕРЕВИЗНАЧЕННЯ (override)
    return `Студент: ${this.name}, група ${this.group}`;
  }
}

class Teacher extends Person {
  constructor(name, subject) {
    super(name);
    this.subject = subject;
  }

  info() {
    return `Викладач: ${this.name}, предмет ${this.subject}`;
  }
}
```

У C++ динамічний вибір методу працює лише для `virtual`-функцій; `override` просить компілятор перевірити, що метод справді перевизначає віртуальний. Базовий клас має мати `virtual`-деструктор. У JavaScript усі методи «віртуальні» за замовчуванням. Перевірки типу: `dynamic_cast` у C++, `obj instanceof Person` у JavaScript.

Перевірки: `isinstance(obj, Person)`, `issubclass(Student, Person)`.

### Поліморфізм
Один інтерфейс — різна реалізація. Код працює з батьківським типом,
а викликається метод конкретного класу.

**Python**

```python
people = [Student("Коваль", "КН-21"), Teacher("Шевченко", "алгоритми")]
for p in people:
    print(p.info())        # викликається «свій» info для кожного
```

**C++**

```cpp
vector<unique_ptr<Person>> people;
people.push_back(make_unique<Student>("Коваль", "КН-21"));
people.push_back(make_unique<Teacher>("Шевченко", "алгоритми"));
for (const auto &p : people) {
    cout << p->info() << endl;          // викликається «свій» info для кожного
}
```

**JavaScript**

```javascript
const people = [new Student("Коваль", "КН-21"), new Teacher("Шевченко", "алгоритми")];
for (const p of people) {
  console.log(p.info());                // викликається «свій» info для кожного
}
```

У C++ поліморфізм працює через **вказівники або посилання** на базовий клас (тут — розумні вказівники `unique_ptr`). Якщо передати об'єкт нащадка в змінну типу `Person` за значенням, він «обріжеться» до `Person` (slicing).

## 14.6 Абстрактні класи

**Python**

```python
from abc import ABC, abstractmethod


class Shape(ABC):
    @abstractmethod
    def area(self) -> float:
        """Площа фігури."""

    @abstractmethod
    def perimeter(self) -> float:
        """Периметр фігури."""

    def describe(self) -> str:         # звичайний метод, спільний
        return f"{type(self).__name__}: S={self.area():.2f}"


class Rectangle(Shape):
    def __init__(self, a, b):
        self.a, self.b = a, b

    def area(self):
        return self.a * self.b

    def perimeter(self):
        return 2 * (self.a + self.b)


Shape()        # TypeError — абстрактний клас не створюється
```

**C++**

```cpp
class Shape {
public:
    virtual ~Shape() = default;
    virtual double area() const = 0;             // = 0 — чисто віртуальний (абстрактний) метод. Площа фігури.
    virtual double perimeter() const = 0;        // Периметр фігури.

    string describe() const {                    // звичайний метод, спільний
        ostringstream os;
        os << "S=" << fixed << setprecision(2) << area();
        return os.str();
    }
};

class Rectangle : public Shape {
public:
    Rectangle(double a, double b) : a(a), b(b) {}

    double area() const override { return a * b; }
    double perimeter() const override { return 2 * (a + b); }

private:
    double a, b;
};

// Shape s;   // помилка компіляції: абстрактний клас не створюється
```

**JavaScript**

```javascript
class Shape {
  constructor() {
    if (new.target === Shape) {
      throw new TypeError("абстрактний клас не створюється");
    }
  }

  area() { throw new Error("не реалізовано"); }
  perimeter() { throw new Error("не реалізовано"); }

  describe() {                          // звичайний метод, спільний
    return `${this.constructor.name}: S=${this.area().toFixed(2)}`;
  }
}

class Rectangle extends Shape {
  constructor(a, b) {
    super();
    this.a = a;
    this.b = b;
  }

  area() { return this.a * this.b; }
  perimeter() { return 2 * (this.a + this.b); }
}

// new Shape();   // TypeError
```

У C++ абстрактний клас — той, що має хоча б один чисто віртуальний метод (`= 0`); спроба створити його об'єкт — помилка **компіляції**. У JavaScript ключового слова `abstract` немає (воно є в TypeScript), тому перевірку імітують вручну.

## 14.7 Методи класу та статичні методи

**Python**

```python
class Student:
    count = 0

    def __init__(self, name):
        self.name = name
        Student.count += 1

    @classmethod
    def from_string(cls, s: str):       # альтернативний конструктор
        return cls(s.strip())

    @classmethod
    def total(cls) -> int:
        return cls.count

    @staticmethod
    def is_valid_grade(score: int) -> bool:   # не потребує ні self, ні cls
        return 0 <= score <= 100
```

**C++**

```cpp
class Student {
public:
    inline static int count = 0;

    Student(string name) : name(move(name)) {
        count++;
    }

    static Student from_string(const string &s) {         // альтернативний конструктор (статичний фабричний метод)
        size_t b = s.find_first_not_of(' '), e = s.find_last_not_of(' ');
        return Student(b == string::npos ? "" : s.substr(b, e - b + 1));   // аналог s.strip()
    }

    static int total() { return count; }

    static bool is_valid_grade(int score) {               // не потребує об'єкта
        return 0 <= score && score <= 100;
    }

    string name;
};
```

**JavaScript**

```javascript
class Student {
  static count = 0;

  constructor(name) {
    this.name = name;
    Student.count += 1;
  }

  static fromString(s) {                // альтернативний конструктор
    return new this(s.trim());          // this тут — сам клас (як cls)
  }

  static total() {
    return this.count;
  }

  static isValidGrade(score) {          // не потребує об'єкта
    return 0 <= score && score <= 100;
  }
}
```

| | Перший параметр | Доступ |
|---|---|---|
| метод екземпляра | `self` | атрибути об'єкта і класу |
| `@classmethod` | `cls` | лише атрибути класу |
| `@staticmethod` | немає | нічого — просто функція в класі |

У C++ і JavaScript розрізняють лише метод екземпляра та **статичний** метод (`static`): окремого `@classmethod` немає. У статичному методі JavaScript `this` посилається на сам клас (так само, як `cls`).

## 14.8 dataclass — менше шаблонного коду

**Python**

```python
from dataclasses import dataclass, field


@dataclass
class Student:
    name: str
    group: str
    grades: list[int] = field(default_factory=list)

    def average(self) -> float:
        return sum(self.grades) / len(self.grades) if self.grades else 0.0


s = Student("Коваль", "КН-21")
print(s)          # Student(name='Коваль', group='КН-21', grades=[])
```

**C++**

```cpp
struct Student {
    string name;
    string group;
    vector<int> grades;                 // за замовчуванням — порожній вектор: пастки Python немає

    double average() const {
        return grades.empty() ? 0.0
                              : accumulate(grades.begin(), grades.end(), 0.0) / grades.size();
    }

    bool operator==(const Student &) const = default;    // C++20: == генерується автоматично
};

Student s{"Коваль", "КН-21"};                            // агрегатна ініціалізація
```

**JavaScript**

```javascript
class Student {
  constructor(name, group, grades = []) {
    Object.assign(this, { name, group, grades });
  }

  average() {
    return this.grades.length === 0
      ? 0
      : this.grades.reduce((p, q) => p + q, 0) / this.grades.length;
  }
}

const s = new Student("Коваль", "КН-21");
console.log(s);   // Student { name: 'Коваль', group: 'КН-21', grades: [] }
```

У C++ аналог `dataclass` — звичайна `struct` (конструктор через фігурні дужки, порівняння `== default` з C++20). Виведення `print(s)` у Python відповідає виводу `console.log(s)` у JavaScript; у C++ оператор `<<` доведеться написати самому.

`@dataclass` автоматично створює `__init__`, `__repr__`, `__eq__`.

## 14.9 Типові помилки

| Помилка | Правильно |
|---------|-----------|
| забутий `self` у методі | `def m(self):` |
| `self.x` без присвоєння в `__init__` | ініціалізувати всі атрибути |
| змінний атрибут класу: `grades = []` | `field(default_factory=list)` |
| забутий `super().__init__()` | викликати в спадкованому конструкторі |
| `__str__` із `print` замість `return` | повертати рядок |
| C++: забутий `virtual` у базовому класі | `virtual` у базовому і `override` у нащадках |
| C++: невіртуальний деструктор у базовому класі | `virtual ~Base() = default;` |
| JS: виклик конструктора без `new` | `new Student(...)` |
| JS: втрата `this` (`const f = s.addGrade; f()`) | `s.addGrade.bind(s)` або стрілкова функція |
| JS: `this` до `super(...)` у нащадку | спершу викликати `super(...)` |
