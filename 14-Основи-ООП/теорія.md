# Розділ 14. Основи об'єктно-орієнтованого програмування

## 14.1 Від процедурного до об'єктного

Процедурний підхід: **дані окремо, функції окремо**.
```python
student = {"name": "Коваль", "grades": [74, 82]}

def average(s):
    return sum(s["grades"]) / len(s["grades"])
```
Проблема: нічого не гарантує, що в словнику є потрібні ключі,
і функція `average` ніяк не «прив'язана» до даних.

ООП **об'єднує дані й поведінку** в одну сутність — об'єкт.

## 14.2 Клас і об'єкт

- **Клас** — опис (шаблон, тип) сутності: які в неї дані та дії.
- **Об'єкт (екземпляр)** — конкретне втілення класу.

Аналогія: клас «креслення автомобіля», об'єкт — конкретна машина.

```python
class Student:
    """Студент із набором оцінок."""

    def __init__(self, name: str, group: str):
        self.name = name            # атрибут екземпляра
        self.group = group
        self.grades: list[int] = []

    def add_grade(self, score: int) -> None:
        """Додає оцінку з перевіркою діапазону."""
        if not 0 <= score <= 100:
            raise ValueError(f"бал {score} поза межами 0..100")
        self.grades.append(score)

    def average(self) -> float:
        """Середній бал; 0, якщо оцінок немає."""
        return sum(self.grades) / len(self.grades) if self.grades else 0.0


s = Student("Коваль", "КН-21")      # створення об'єкта
s.add_grade(74)
s.add_grade(82)
print(s.average())                  # 78.0
```

## 14.3 self, __init__ і атрибути

- `__init__` — **конструктор**: викликається автоматично при створенні.
- `self` — посилання на **поточний об'єкт**; перший параметр
  кожного методу екземпляра. Пишеться в оголошенні, але не в виклику.

```python
s.add_grade(74)        # Python передає: Student.add_grade(s, 74)
```

### Атрибути класу vs екземпляра
```python
class Student:
    university = "НУ «ЛП»"      # АТРИБУТ КЛАСУ — спільний для всіх
    count = 0

    def __init__(self, name):
        self.name = name        # АТРИБУТ ЕКЗЕМПЛЯРА — свій у кожного
        Student.count += 1
```

## 14.4 Магічні (dunder) методи

| Метод | Викликається | Призначення |
|-------|--------------|-------------|
| `__init__` | `Student(...)` | конструктор |
| `__str__` | `print(obj)`, `str(obj)` | подання для користувача |
| `__repr__` | у REPL, `repr(obj)` | подання для розробника |
| `__len__` | `len(obj)` | довжина |
| `__eq__` | `a == b` | порівняння на рівність |
| `__lt__` | `a < b`, `sorted()` | «менше» |
| `__add__` | `a + b` | додавання |
| `__getitem__` | `obj[i]` | індексація |
| `__contains__` | `x in obj` | входження |
| `__call__` | `obj()` | виклик як функції |

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __str__(self):
        return f"({self.x}; {self.y})"

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

    def __eq__(self, other):
        return (self.x, self.y) == (other.x, other.y)

    def __add__(self, other):
        return Point(self.x + other.x, self.y + other.y)

    def __abs__(self):
        return (self.x ** 2 + self.y ** 2) ** 0.5


p = Point(1, 2) + Point(3, 4)
print(p)              # (4; 6)
print(abs(p))         # 7.211...
```

## 14.5 Три принципи ООП

### Інкапсуляція
Приховування внутрішньої будови; доступ лише через методи.

Угоди Python (мова не забороняє доступ технічно):
```python
self.name       # публічний
self._cache     # «захищений» — не трогати зовні (угода)
self.__secret   # name mangling → _ClassName__secret
```

Властивості (`property`) — доступ як до атрибута, з перевіркою:
```python
class Temperature:
    def __init__(self, celsius=0):
        self._celsius = celsius

    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("нижче абсолютного нуля")
        self._celsius = value

    @property
    def fahrenheit(self):             # обчислювана, лише для читання
        return self._celsius * 9 / 5 + 32


t = Temperature()
t.celsius = 100          # викликається setter
print(t.fahrenheit)      # 212.0
```

### Успадкування
Новий клас отримує дані й поведінку батьківського.

```python
class Person:
    def __init__(self, name):
        self.name = name

    def info(self) -> str:
        return f"Особа: {self.name}"


class Student(Person):
    def __init__(self, name, group):
        super().__init__(name)        # виклик конструктора батька
        self.group = group

    def info(self) -> str:            # ПЕРЕВИЗНАЧЕННЯ (override)
        return f"Студент: {self.name}, група {self.group}"


class Teacher(Person):
    def __init__(self, name, subject):
        super().__init__(name)
        self.subject = subject

    def info(self) -> str:
        return f"Викладач: {self.name}, предмет {self.subject}"
```

Перевірки: `isinstance(obj, Person)`, `issubclass(Student, Person)`.

### Поліморфізм
Один інтерфейс — різна реалізація. Код працює з батьківським типом,
а викликається метод конкретного класу.

```python
people = [Student("Коваль", "КН-21"), Teacher("Шевченко", "алгоритми")]
for p in people:
    print(p.info())        # викликається «свій» info для кожного
```

## 14.6 Абстрактні класи

```python
from abc import ABC, abstractmethod


class Shape(ABC):
    @abstractmethod
    def area(self) -> float:
        """Площа фігури."""

    @abstractmethod
    def perimeter(self) -> float:
        """Периметр фігури."""

    def describe(self) -> str:         # звичайний метод, спільний
        return f"{type(self).__name__}: S={self.area():.2f}"


class Rectangle(Shape):
    def __init__(self, a, b):
        self.a, self.b = a, b

    def area(self):
        return self.a * self.b

    def perimeter(self):
        return 2 * (self.a + self.b)


Shape()        # TypeError — абстрактний клас не створюється
```

## 14.7 Методи класу та статичні методи

```python
class Student:
    count = 0

    def __init__(self, name):
        self.name = name
        Student.count += 1

    @classmethod
    def from_string(cls, s: str):       # альтернативний конструктор
        return cls(s.strip())

    @classmethod
    def total(cls) -> int:
        return cls.count

    @staticmethod
    def is_valid_grade(score: int) -> bool:   # не потребує ні self, ні cls
        return 0 <= score <= 100
```

| | Перший параметр | Доступ |
|---|---|---|
| метод екземпляра | `self` | атрибути об'єкта і класу |
| `@classmethod` | `cls` | лише атрибути класу |
| `@staticmethod` | немає | нічого — просто функція в класі |

## 14.8 dataclass — менше шаблонного коду

```python
from dataclasses import dataclass, field


@dataclass
class Student:
    name: str
    group: str
    grades: list[int] = field(default_factory=list)

    def average(self) -> float:
        return sum(self.grades) / len(self.grades) if self.grades else 0.0


s = Student("Коваль", "КН-21")
print(s)          # Student(name='Коваль', group='КН-21', grades=[])
```
`@dataclass` автоматично створює `__init__`, `__repr__`, `__eq__`.

## 14.9 Типові помилки

| Помилка | Правильно |
|---------|-----------|
| забутий `self` у методі | `def m(self):` |
| `self.x` без присвоєння в `__init__` | ініціалізувати всі атрибути |
| змінний атрибут класу: `grades = []` | `field(default_factory=list)` |
| забутий `super().__init__()` | викликати в спадкованому конструкторі |
| `__str__` із `print` замість `return` | повертати рядок |
