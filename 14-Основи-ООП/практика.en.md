# Practice Tasks for Chapter 14

**Task type:** design a class (or a small class hierarchy)
from a description of a subject area.

Requirements for **every** task:
1. `__init__` with validation of the input data (`raise ValueError`
   for invalid values);
2. at least 2 meaningful methods;
3. `__str__` for readable output and `__repr__` for debugging;
4. a docstring in the class and in every method;
5. a demonstration in an `if __name__ == "__main__":` block
   and 3 checks via `assert`.

---

### Task 14.1
The class `Rectangle` — a rectangle with sides a, b.
Methods: `area()`, `perimeter()`, `is_square()`.
A property `diagonal`. The sides must be positive.

### Task 14.2
The class `Circle` — a circle with radius r.
Methods: `area()`, `circumference()`, `scale(k)`.
Magic methods: `__eq__` (equal radii), `__lt__` (by radius),
so that a list of circles can be sorted.

### Task 14.3
The class `Student` — surname, group, a list of grades.
Methods: `add_grade(score)` with validation 0..100,
`average()`, `best()`, `ects()` (the scale from Chapter 5).
`__len__` — the number of grades.

### Task 14.4
The class `BankAccount` — an owner and a balance.
Methods: `deposit(amount)`, `withdraw(amount)` (do not allow
a negative balance), `history()` — a list of operations.
Make the balance read-only (`@property`).

### Task 14.5
The class `Vector` — a two-dimensional vector.
Magic methods: `__add__`, `__sub__`, `__mul__` (dot product
and multiplication by a number), `__abs__` (length), `__eq__`, `__neg__`.

### Task 14.6
The class `Fraction` — a common fraction.
In the constructor reduce the fraction using the GCD, and forbid a zero
denominator. Methods: `__add__`, `__mul__`, `__eq__`, `__lt__`,
`to_float()`.

### Task 14.7
The class `Time` — a time (hours, minutes, seconds).
Methods: `to_seconds()`, `__add__` (the sum of two moments with carry),
`__sub__`, `__lt__`. Validation: 0≤hours, 0≤minutes<60, 0≤seconds<60.

### Task 14.8
The class `Matrix` — a matrix based on a list of lists.
Methods: `__add__`, `__mul__` (by a number and by a matrix),
`transpose()`, `__getitem__`, `__str__`.
Check that the sizes are compatible.

### Task 14.9
A hierarchy: an abstract class `Shape` with `area()` and `perimeter()`;
descendants `Rectangle`, `Circle`, `Triangle`.
Create a list of different shapes and print them
sorted by area (polymorphism).

### Task 14.10
A hierarchy: `Person` (surname, age) → `Student` (group, grades)
and `Teacher` (subject, years of experience).
Override the method `info()` in each class.
A class `University` with a list of people:
methods `add(person)`, `students()`, `teachers()`, `__len__`.
Demonstrate `isinstance` and polymorphism.
