# Розділ 5. Розгалуження (умовні оператори)

## 5.1 Логічний тип і умови

**Умова** — вираз, що дає `True` або `False`.

### Операції порівняння

| Оператор | Значення | Приклад |
|----------|----------|---------|
| `==` | дорівнює | `a == b` |
| `!=` | не дорівнює | `a != b` |
| `<` `>` | менше / більше | `a < b` |
| `<=` `>=` | не більше / не менше | `a <= b` |

Python допускає **ланцюжки**: `0 <= x <= 100` замість `x >= 0 and x <= 100`.

У C++ і JavaScript ланцюжки порівнянь **не працюють**: `0 <= x <= 100` компілюється, але обчислюється як `(0 <= x) <= 100`, тобто `true`/`false` (1 або 0) порівнюється зі `100`, і результат завжди істинний. Пишіть `x >= 0 && x <= 100`.

У JavaScript є два види рівності: `==` (з приведенням типів: `"5" == 5` дає `true`) і `===` (сувора: `"5" === 5` дає `false`). Завжди використовуйте `===` та `!==`.

### Логічні операції

| Оператор | Назва | `True`, коли |
|----------|-------|--------------|
| `and` | кон'юнкція (І) | обидва операнди `True` |
| `or` | дизюнкція (АБО) | хоча б один `True` |
| `not` | заперечення (НЕ) | операнд `False` |

**Пріоритет:** `not` → `and` → `or`. Порівняння виконуються раніше за них.

Запис логічних операцій у трьох мовах:

| Python | C++ | JavaScript |
|--------|-----|------------|
| `and` | `&&` | `&&` |
| `or` | `\|\|` | `\|\|` |
| `not` | `!` | `!` |

У C++ також існують еквівалентні ключові слова `and`, `or`, `not`. Пріоритет у C++ і JavaScript той самий: `!` → `&&` → `||`.

### Таблиця істинності

| a | b | `a and b` | `a or b` | `not a` |
|---|---|-----------|----------|---------|
| F | F | F | F | T |
| F | T | F | T | T |
| T | F | F | T | F |
| T | T | T | T | F |

### Закони де Моргана
```
not (a and b)  ==  (not a) or (not b)
not (a or b)   ==  (not a) and (not b)
```

### Скорочене обчислення (short-circuit)
`and` / `or` не обчислюють другий операнд, якщо результат уже відомий.
Це дозволяє безпечні перевірки:

**Python**

```python
if b != 0 and a / b > 1:     # ділення не станеться при b == 0
    ...
```

**C++**

```cpp
if (b != 0 && a / b > 1) {      // ділення не станеться при b == 0
    // ...
}
```

**JavaScript**

```javascript
if (b !== 0 && a / b > 1) {     // ділення не станеться при b === 0
  // ...
}
```

## 5.2 Оператор if

### Неповне розгалуження

**Python**

```python
if умова:
    блок
```

**C++**

```cpp
if (умова) {
    // блок
}
```

**JavaScript**

```javascript
if (умова) {
  // блок
}
```

У C++ і JavaScript умова обов'язково береться в **круглі дужки**, а блок — у **фігурні** `{ }` (без них `if` керує лише одним оператором).

### Повне розгалуження

**Python**

```python
if умова:
    блок_1
else:
    блок_2
```

**C++**

```cpp
if (умова) {
    // блок_1
} else {
    // блок_2
}
```

**JavaScript**

```javascript
if (умова) {
  // блок_1
} else {
  // блок_2
}
```

### Багатогіллясте розгалуження

**Python**

```python
if умова_1:
    блок_1
elif умова_2:
    блок_2
elif умова_3:
    блок_3
else:
    блок_за_замовчуванням
```

**C++**

```cpp
if (умова_1) {
    // блок_1
} else if (умова_2) {
    // блок_2
} else if (умова_3) {
    // блок_3
} else {
    // блок_за_замовчуванням
}
```

**JavaScript**

```javascript
if (умова_1) {
  // блок_1
} else if (умова_2) {
  // блок_2
} else if (умова_3) {
  // блок_3
} else {
  // блок_за_замовчуванням
}
```

У C++ і JavaScript немає ключового слова `elif`: пишуть `else if`.

Перевірки виконуються **по порядку**; після першої істинної решта
не перевіряються.

### Вкладені умови

**Python**

```python
if a > 0:
    if b > 0:
        print("обидва додатні")
    else:
        print("лише a додатне")
```

**C++**

```cpp
if (a > 0) {
    if (b > 0) {
        cout << "обидва додатні" << endl;
    } else {
        cout << "лише a додатне" << endl;
    }
}
```

**JavaScript**

```javascript
if (a > 0) {
  if (b > 0) {
    console.log("обидва додатні");
  } else {
    console.log("лише a додатне");
  }
}
```

Часто можна замінити на `&&`: `if (a > 0 && b > 0)`.

Часто можна замінити на `and`: `if a > 0 and b > 0:`.

## 5.3 Умовний вираз (тернарний оператор)

**Python**

```python
m = a if a > b else b           # максимум
parity = "парне" if n % 2 == 0 else "непарне"
```

**C++**

```cpp
int m = a > b ? a : b;                                   // максимум
string parity = n % 2 == 0 ? "парне" : "непарне";
```

**JavaScript**

```javascript
const m = a > b ? a : b;                                 // максимум
const parity = n % 2 === 0 ? "парне" : "непарне";
```

Порядок у C++ і JavaScript інший, ніж у Python: `умова ? якщо_істина : якщо_хибна`.

Використовувати лише для коротких, однозначних випадків.

## 5.4 Оператор match (Python 3.10+)

**Python**

```python
match day:
    case 1 | 2 | 3 | 4 | 5:
        print("робочий")
    case 6 | 7:
        print("вихідний")
    case _:
        print("немає такого дня")
```

**C++**

```cpp
switch (day) {
    case 1: case 2: case 3: case 4: case 5:
        cout << "робочий" << endl;
        break;
    case 6: case 7:
        cout << "вихідний" << endl;
        break;
    default:
        cout << "немає такого дня" << endl;
}
```

**JavaScript**

```javascript
switch (day) {
  case 1: case 2: case 3: case 4: case 5:
    console.log("робочий");
    break;
  case 6: case 7:
    console.log("вихідний");
    break;
  default:
    console.log("немає такого дня");
}
```

Оператор `switch` — аналог `match`, але **без `break` виконання «провалюється»** в наступний `case`. У C++ `switch` працює лише з цілими типами та `enum` (не з рядками); у JavaScript порівняння суворе (`===`), тож працює й з рядками.

## 5.5 Хибність значень (truthiness)

Хибними вважаються: `False`, `None`, `0`, `0.0`, `""`, `[]`, `{}`, `()`, `set()`.
Усе інше — істинне.

У C++ до `bool` перетворюються числа (0 — хибне, решта — істинне) і вказівники; рядки та контейнери — ні, для них є `.empty()`. У JavaScript хибні: `false`, `0`, `-0`, `0n`, `NaN`, `""`, `null`, `undefined`; **порожні масив `[]` й об'єкт `{}` — істинні** (на відміну від Python).

**Python**

```python
if n:            # те саме, що if n != 0
if not s:        # те саме, що if s == ""
```

**C++**

```cpp
if (n) { /* ... */ }             // те саме, що if (n != 0)
if (s.empty()) { /* ... */ }     // те саме, що if not s
```

**JavaScript**

```javascript
if (n) { /* ... */ }             // те саме, що if (n !== 0) (і не NaN)
if (!s) { /* ... */ }            // те саме, що if (s === "") (і null/undefined)
```

## 5.6 Типові схеми

### Максимум із трьох

**Python**

```python
m = a
if b > m: m = b
if c > m: m = c
```

**C++**

```cpp
int m = a;
if (b > m) m = b;
if (c > m) m = c;
```

**JavaScript**

```javascript
let m = a;
if (b > m) m = b;
if (c > m) m = c;
```

У C++ є готові `max(a, max(b, c))` і `max({a, b, c})` (`<algorithm>`), у JavaScript — `Math.max(a, b, c)`.

### Належність інтервалу

**Python**

```python
if 0 <= x <= 10:
    print("у межах")
```

**C++**

```cpp
if (x >= 0 && x <= 10) {
    cout << "у межах" << endl;
}
```

**JavaScript**

```javascript
if (x >= 0 && x <= 10) {
  console.log("у межах");
}
```

### Чверть координатної площини

**Python**

```python
if x == 0 or y == 0:
    print("на осі")
elif x > 0 and y > 0: print("I")
elif x < 0 and y > 0: print("II")
elif x < 0 and y < 0: print("III")
else:                 print("IV")
```

**C++**

```cpp
if (x == 0 || y == 0) cout << "на осі" << endl;
else if (x > 0 && y > 0) cout << "I" << endl;
else if (x < 0 && y > 0) cout << "II" << endl;
else if (x < 0 && y < 0) cout << "III" << endl;
else cout << "IV" << endl;
```

**JavaScript**

```javascript
if (x === 0 || y === 0) console.log("на осі");
else if (x > 0 && y > 0) console.log("I");
else if (x < 0 && y > 0) console.log("II");
else if (x < 0 && y < 0) console.log("III");
else console.log("IV");
```

### Сортування трьох чисел

**Python**

```python
if a > b: a, b = b, a
if b > c: b, c = c, b
if a > b: a, b = b, a
```

**C++**

```cpp
if (a > b) swap(a, b);
if (b > c) swap(b, c);
if (a > b) swap(a, b);
```

**JavaScript**

```javascript
if (a > b) [a, b] = [b, a];
if (b > c) [b, c] = [c, b];
if (a > b) [a, b] = [b, a];
```

## 5.7 Порівняння дійсних чисел

Через похибку представлення `0.1 + 0.2 != 0.3`. Правильно:

**Python**

```python
EPS = 1e-9
if abs(x - y) < EPS:
    print("рівні")
```

**C++**

```cpp
const double EPS = 1e-9;
if (fabs(x - y) < EPS) {
    cout << "рівні" << endl;
}
```

**JavaScript**

```javascript
const EPS = 1e-9;
if (Math.abs(x - y) < EPS) {
  console.log("рівні");
}
```

Аналога `math.isclose` у C++ і JavaScript стандартна бібліотека не має — використовують власну функцію з абсолютною та/або відносною похибкою.

або `math.isclose(x, y)`.

## 5.8 Типові помилки

| Помилка | Приклад | Правильно |
|---------|---------|-----------|
| `=` замість `==` | `if a = 5:` | `if a == 5:` |
| забута двокрапка | `if a > 0` | `if a > 0:` |
| `elif` замість окремих `if` | послідовні незалежні перевірки | використати `if` |
| порівняння `float` на `==` | `if x == 0.3:` | `abs(x-0.3) < EPS` |
| перекриття умов | `if x > 10: … elif x > 5:` при x = 20 | упорядкувати межі |
| C++: `=` замість `==` | `if (a = 5)` компілюється, але присвоює | `if (a == 5)` |
| C++/JS: гілка без `{ }` | `if (x) a(); b();` — `b()` не належить до `if` | завжди ставити `{ }` |
| JS: `==` замість `===` | `"5" == 5` дає `true` | `"5" === 5` |
| C++/JS: ланцюжок `0 <= x <= 10` | завжди істинний | `x >= 0 && x <= 10` |
| C++/JS: `switch` без `break` | виконуються і наступні `case` | `break;` після кожної гілки |
