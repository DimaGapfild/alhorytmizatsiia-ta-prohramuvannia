# Практичні завдання до розділу 5

**Тип завдань:** розгалуження (`if` / `elif` / `else`), логічні операції.
Циклів у цьому розділі немає.

Вимоги: врахувати **усі** випадки, зокрема рівність і нуль.
Для кожної задачі навести не менше 4 тестів, включно з межовими.

---

### Задача 5.1
Дано три числа. Вивести найбільше з них.
```
5 9 2  → 9        7 7 7 → 7        -1 -5 -3 → -1
```

### Задача 5.2
Дано ціле число. Визначити, чи воно додатне, від'ємне або нуль.
```
-7 → від'ємне     0 → нуль         12 → додатне
```

### Задача 5.3
Дано рік. Визначити, чи він є високосним
(кратний 4, але не кратний 100, або кратний 400).
```
2024 → так        1900 → ні        2000 → так       2023 → ні
```

### Задача 5.4
Дано координати точки (x, y). Визначити номер чверті
або повідомити, що точка лежить на осі / у початку координат.
```
3 4 → I           -2 5 → II        0 7 → на осі OY   0 0 → початок
```

### Задача 5.5
Дано три довжини відрізків. Визначити, чи можна скласти з них
трикутник, і якщо так — чи він рівносторонній, рівнобедрений
або різносторонній.
```
3 4 5 → різносторонній    2 2 2 → рівносторонній
1 2 10 → не трикутник     5 5 8 → рівнобедрений
```

### Задача 5.6
Дано бал за 100-бальною шкалою. Вивести оцінку ECTS
(A: 90–100, B: 82–89, C: 74–81, D: 64–73, E: 60–63, FX: 35–59, F: 0–34).
```
95 → A            60 → E           40 → FX          12 → F
```

### Задача 5.7
Дано номер місяця. Вивести пору року.
Якщо номер поза межами 1–12 — повідомити про помилку.
```
1 → зима         4 → весна        13 → помилка
```

### Задача 5.8
Розв'язати квадратне рівняння ax² + bx + c = 0.
Врахувати випадки a = 0, D > 0, D = 0, D < 0.
```
1 -3 2  → x1=2, x2=1        1 2 1 → x=-1
1 0 1   → коренів немає     0 2 4 → лінійне: x=-2
```

### Задача 5.9
Дано вагу багажу (кг) і клас квитка (`econom` / `business`).
Безкоштовна норма: econom — 20 кг, business — 30 кг.
Кожен кілограм перевищення — 15 грн. Вивести суму доплати.
```
18 econom → 0          25 econom → 75
35 business → 75       30 business → 0
```

### Задача 5.10
Дано вік і стать (`ч` / `ж`). Визначити, чи має людина право
на пільговий проїзд: до 18 років — усі; жінки від 60, чоловіки від 65.
```
12 ч → так       30 ж → ні        62 ж → так       62 ч → ні
```
