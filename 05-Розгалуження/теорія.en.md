# Chapter 5. Branching (Conditional Statements)

## 5.1 The Boolean Type and Conditions

A **condition** is an expression that evaluates to `True` or `False`.

### Comparison Operators

| Operator | Meaning | Example |
|----------|---------|---------|
| `==` | equal to | `a == b` |
| `!=` | not equal to | `a != b` |
| `<` `>` | less than / greater than | `a < b` |
| `<=` `>=` | not greater than / not less than | `a <= b` |

Python allows **chaining**: `0 <= x <= 100` instead of `x >= 0 and x <= 100`.

In C++ and JavaScript, chained comparisons **do not work**: `0 <= x <= 100` compiles, but is evaluated as `(0 <= x) <= 100`, i.e. `true`/`false` (1 or 0) is compared with `100`, and the result is always true. Write `x >= 0 && x <= 100`.

JavaScript has two kinds of equality: `==` (with type coercion: `"5" == 5` gives `true`) and `===` (strict: `"5" === 5` gives `false`). Always use `===` and `!==`.

### Logical Operators

| Operator | Name | `True` when |
|----------|------|-------------|
| `and` | conjunction (AND) | both operands are `True` |
| `or` | disjunction (OR) | at least one is `True` |
| `not` | negation (NOT) | the operand is `False` |

**Precedence:** `not` → `and` → `or`. Comparisons are evaluated before them.

Logical operations in the three languages:

| Python | C++ | JavaScript |
|--------|-----|------------|
| `and` | `&&` | `&&` |
| `or` | `\|\|` | `\|\|` |
| `not` | `!` | `!` |

C++ also has the equivalent keywords `and`, `or`, `not`. The precedence in C++ and JavaScript is the same: `!` → `&&` → `||`.

### Truth Table

| a | b | `a and b` | `a or b` | `not a` |
|---|---|-----------|----------|---------|
| F | F | F | F | T |
| F | T | F | T | T |
| T | F | F | T | F |
| T | T | T | T | F |

### De Morgan's Laws
```
not (a and b)  ==  (not a) or (not b)
not (a or b)   ==  (not a) and (not b)
```

### Short-Circuit Evaluation
`and` / `or` do not evaluate the second operand if the result is already known.
This allows safe checks:

**Python**

```python
if b != 0 and a / b > 1:     # the division does not happen when b == 0
    ...
```

**C++**

```cpp
// the division does not happen when b == 0
    // ...
}
```

**JavaScript**

```javascript
// the division does not happen when b === 0
  // ...
}
```

## 5.2 The if Statement

### Incomplete Branching

**Python**

```python
if condition:
    block
```

**C++**

```cpp
if (condition) {
    // block
}
```

**JavaScript**

```javascript
if (condition) {
  // block
}
```

In C++ and JavaScript the condition must be in **parentheses** and the block in **curly braces** `{ }` (without them `if` controls only one statement).

### Complete Branching

**Python**

```python
if condition:
    block_1
else:
    block_2
```

**C++**

```cpp
if (condition) {
    // block_1
} else {
    // block_2
}
```

**JavaScript**

```javascript
if (condition) {
  // block_1
} else {
  // block_2
}
```

### Multi-Way Branching

**Python**

```python
if condition_1:
    block_1
elif condition_2:
    block_2
elif condition_3:
    block_3
else:
    default_block
```

**C++**

```cpp
if (condition_1) {
    // block_1
} else if (condition_2) {
    // block_2
} else if (condition_3) {
    // block_3
} else {
    // default_block
}
```

**JavaScript**

```javascript
if (condition_1) {
  // block_1
} else if (condition_2) {
  // block_2
} else if (condition_3) {
  // block_3
} else {
  // default_block
}
```

C++ and JavaScript have no `elif` keyword: write `else if`.

The checks are performed **in order**; after the first true one, the rest
are not checked.

### Nested Conditions

**Python**

```python
if a > 0:
    if b > 0:
        print("both positive")
    else:
        print("only a is positive")
```

**C++**

```cpp
if (a > 0) {
    if (b > 0) {
        cout << "both positive" << endl;
    } else {
        cout << "only a is positive" << endl;
    }
}
```

**JavaScript**

```javascript
if (a > 0) {
  if (b > 0) {
    console.log("both positive");
  } else {
    console.log("only a is positive");
  }
}
```

This can often be replaced with `&&`: `if (a > 0 && b > 0)`.

This can often be replaced with `and`: `if a > 0 and b > 0:`.

## 5.3 The Conditional Expression (Ternary Operator)

**Python**

```python
m = a if a > b else b           # maximum
parity = "even" if n % 2 == 0 else "odd"
```

**C++**

```cpp
// maximum
string parity = n % 2 == 0 ? "even" : "odd";
```

**JavaScript**

```javascript
// maximum
const parity = n % 2 === 0 ? "even" : "odd";
```

The order in C++ and JavaScript differs from Python: `condition ? if_true : if_false`.

Use it only for short, unambiguous cases.

## 5.4 The match Statement (Python 3.10+)

**Python**

```python
match day:
    case 1 | 2 | 3 | 4 | 5:
        print("working day")
    case 6 | 7:
        print("weekend")
    case _:
        print("no such day")
```

**C++**

```cpp
switch (day) {
    case 1: case 2: case 3: case 4: case 5:
        cout << "working day" << endl;
        break;
    case 6: case 7:
        cout << "weekend" << endl;
        break;
    default:
        cout << "no such day" << endl;
}
```

**JavaScript**

```javascript
switch (day) {
  case 1: case 2: case 3: case 4: case 5:
    console.log("working day");
    break;
  case 6: case 7:
    console.log("weekend");
    break;
  default:
    console.log("no such day");
}
```

The `switch` statement is the counterpart of `match`, but **without `break` execution "falls through"** into the next `case`. In C++ `switch` works only with integer types and `enum` (not with strings); in JavaScript the comparison is strict (`===`), so strings work too.

## 5.5 Truthiness of Values

The following are considered false: `False`, `None`, `0`, `0.0`, `""`, `[]`, `{}`, `()`, `set()`.
Everything else is true.

In C++ numbers (0 is false, everything else is true) and pointers convert to `bool`; strings and containers do not — use `.empty()` for them. In JavaScript the falsy values are `false`, `0`, `-0`, `0n`, `NaN`, `""`, `null`, `undefined`; **the empty array `[]` and the empty object `{}` are truthy** (unlike Python).

**Python**

```python
if n:            # same as if n != 0
if not s:        # same as if s == ""
```

**C++**

```cpp
// the same as if (n != 0)
// the same as if not s
```

**JavaScript**

```javascript
// the same as if (n !== 0) (and not NaN)
// the same as if (s === "") (and null/undefined)
```

## 5.6 Typical Patterns

### Maximum of three

**Python**

```python
m = a
if b > m: m = b
if c > m: m = c
```

**C++**

```cpp
int m = a;
if (b > m) m = b;
if (c > m) m = c;
```

**JavaScript**

```javascript
let m = a;
if (b > m) m = b;
if (c > m) m = c;
```

C++ has ready-made `max(a, max(b, c))` and `max({a, b, c})` (`<algorithm>`), JavaScript has `Math.max(a, b, c)`.

### Membership in an interval

**Python**

```python
if 0 <= x <= 10:
    print("within range")
```

**C++**

```cpp
if (x >= 0 && x <= 10) {
    cout << "within range" << endl;
}
```

**JavaScript**

```javascript
if (x >= 0 && x <= 10) {
  console.log("within range");
}
```

### Quadrant of the coordinate plane

**Python**

```python
if x == 0 or y == 0:
    print("on an axis")
elif x > 0 and y > 0: print("I")
elif x < 0 and y > 0: print("II")
elif x < 0 and y < 0: print("III")
else:                 print("IV")
```

**C++**

```cpp
if (x == 0 || y == 0) cout << "on an axis" << endl;
else if (x > 0 && y > 0) cout << "I" << endl;
else if (x < 0 && y > 0) cout << "II" << endl;
else if (x < 0 && y < 0) cout << "III" << endl;
else cout << "IV" << endl;
```

**JavaScript**

```javascript
if (x === 0 || y === 0) console.log("on an axis");
else if (x > 0 && y > 0) console.log("I");
else if (x < 0 && y > 0) console.log("II");
else if (x < 0 && y < 0) console.log("III");
else console.log("IV");
```

### Sorting three numbers

**Python**

```python
if a > b: a, b = b, a
if b > c: b, c = c, b
if a > b: a, b = b, a
```

**C++**

```cpp
if (a > b) swap(a, b);
if (b > c) swap(b, c);
if (a > b) swap(a, b);
```

**JavaScript**

```javascript
if (a > b) [a, b] = [b, a];
if (b > c) [b, c] = [c, b];
if (a > b) [a, b] = [b, a];
```

## 5.7 Comparing Real Numbers

Because of representation error, `0.1 + 0.2 != 0.3`. The right way:

**Python**

```python
EPS = 1e-9
if abs(x - y) < EPS:
    print("equal")
```

**C++**

```cpp
const double EPS = 1e-9;
if (fabs(x - y) < EPS) {
    cout << "equal" << endl;
}
```

**JavaScript**

```javascript
const EPS = 1e-9;
if (Math.abs(x - y) < EPS) {
  console.log("equal");
}
```

The standard library of C++ and JavaScript has no counterpart of `math.isclose` — use your own function with an absolute and/or relative tolerance.

or `math.isclose(x, y)`.

## 5.8 Common Mistakes

| Mistake | Example | Correct |
|---------|---------|---------|
| `=` instead of `==` | `if a = 5:` | `if a == 5:` |
| forgotten colon | `if a > 0` | `if a > 0:` |
| `elif` instead of separate `if`s | consecutive independent checks | use `if` |
| comparing `float` with `==` | `if x == 0.3:` | `abs(x-0.3) < EPS` |
| overlapping conditions | `if x > 10: … elif x > 5:` when x = 20 | order the boundaries |
| C++: `=` instead of `==` | `if (a = 5)` compiles, but assigns | `if (a == 5)` |
| C++/JS: branch without `{ }` | `if (x) a(); b();` — `b()` is not part of the `if` | always use `{ }` |
| JS: `==` instead of `===` | `"5" == 5` gives `true` | `"5" === 5` |
| C++/JS: chain `0 <= x <= 10` | always true | `x >= 0 && x <= 10` |
| C++/JS: `switch` without `break` | the following `case`s run as well | `break;` after each branch |
