# Practice Tasks for Chapter 5

**Task type:** branching (`if` / `elif` / `else`), logical operators.
There are no loops in this chapter.

Requirements: handle **all** cases, including equality and zero.
For each task give at least 4 tests, including boundary ones.

---

### Task 5.1
Three numbers are given. Print the largest of them.
```
5 9 2  → 9        7 7 7 → 7        -1 -5 -3 → -1
```

### Task 5.2
An integer is given. Determine whether it is positive, negative, or zero.
```
-7 → negative     0 → zero         12 → positive
```

### Task 5.3
A year is given. Determine whether it is a leap year
(divisible by 4 but not by 100, or divisible by 400).
```
2024 → yes        1900 → no        2000 → yes       2023 → no
```

### Task 5.4
The coordinates of a point (x, y) are given. Determine the number of the quadrant
or report that the point lies on an axis / at the origin.
```
3 4 → I           -2 5 → II        0 7 → on the OY axis   0 0 → origin
```

### Task 5.5
Three segment lengths are given. Determine whether a triangle can be formed from them,
and if so, whether it is equilateral, isosceles, or scalene.
```
3 4 5 → scalene           2 2 2 → equilateral
1 2 10 → not a triangle   5 5 8 → isosceles
```

### Task 5.6
A score on a 100-point scale is given. Print the ECTS grade
(A: 90–100, B: 82–89, C: 74–81, D: 64–73, E: 60–63, FX: 35–59, F: 0–34).
```
95 → A            60 → E           40 → FX          12 → F
```

### Task 5.7
A month number is given. Print the season.
If the number is outside 1–12, report an error.
```
1 → winter       4 → spring       13 → error
```

### Task 5.8
Solve the quadratic equation ax² + bx + c = 0.
Handle the cases a = 0, D > 0, D = 0, D < 0.
```
1 -3 2  → x1=2, x2=1        1 2 1 → x=-1
1 0 1   → no roots          0 2 4 → linear: x=-2
```

### Task 5.9
The weight of luggage (kg) and the ticket class (`econom` / `business`) are given.
Free allowance: econom — 20 kg, business — 30 kg.
Each kilogram over the allowance costs 15 UAH. Print the surcharge.
```
18 econom → 0          25 econom → 75
35 business → 75       30 business → 0
```

### Task 5.10
An age and a sex (`m` / `f`) are given. Determine whether the person is entitled
to reduced-fare travel: everyone under 18; women from 60, men from 65.
```
12 m → yes       30 f → no        62 f → yes       62 m → no
```
