# Розділ 3. Основи мов програмування: Python, C++, JavaScript

## 3.1 Три мови курсу: Python, C++, JavaScript

- Інтерпретована, динамічно типізована мова.
- Мінімум синтаксичного «шуму» — зручно для вивчення алгоритмів.
- Блоки виділяються **відступами** (4 пробіли), а не дужками.

Усі приклади курсу подано трьома мовами. Python — основна (найкоротший запис), C++ показує, що відбувається «ближче до машини» (типи, пам'ять), JavaScript — найпоширеніша мова веб.

| | Python | C++ | JavaScript |
|---|--------|-----|------------|
| Виконання | інтерпретатор | компіляція в машинний код | рушій (Node.js, браузер) з JIT |
| Типізація | динамічна | статична, типи вказуються явно | динамічна |
| Блоки | відступи | `{ }` | `{ }` |
| Кінець інструкції | кінець рядка | `;` | `;` (бажано) |
| Ціле число | довільної довжини | `int`, `long long` (фіксована розрядність) | `number` (double), `BigInt` |

```bash
python3 program.py      # запуск файлу
python3                 # інтерактивний режим (REPL)
g++ -std=c++17 -o prog prog.cpp && ./prog   # C++: компіляція і запуск
node program.js         # JavaScript: запуск файлу
node                    # JavaScript: інтерактивний режим (REPL)
```

## 3.2 Структура програми

**Python**

```python
# коментар до кінця рядка
"""
багаторядковий
коментар (рядок-документація)
"""

x = 10          # інструкція
if x > 5:       # двокрапка відкриває блок
    print("more")   # відступ 4 пробіли
print("done")   # поза блоком
```

**C++**

```cpp
// коментар до кінця рядка
/* багаторядковий
   коментар */

int x = 10;                  // інструкція завершується ;
if (x > 5) {                 // блок — у фігурних дужках
    cout << "more" << endl;  // відступ — лише для читабельності
}
cout << "done" << endl;      // поза блоком
```

**JavaScript**

```javascript
// коментар до кінця рядка
/* багаторядковий
   коментар */

let x = 10;                  // інструкція завершується ;
if (x > 5) {                 // блок — у фігурних дужках
  console.log("more");       // відступ — лише для читабельності
}
console.log("done");         // поза блоком
```

У C++ програма завжди починається з функції `main`, а потрібні бібліотеки підключаються директивою `#include`:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello" << endl;
    return 0;
}
```

У JavaScript (Node.js) достатньо файлу з інструкціями: `console.log("Hello");`.

## 3.3 Змінні та імена

Змінна — **ім'я, пов'язане з об'єктом** (а не комірка пам'яті).

**Python**

```python
a = 5          # a посилається на об'єкт 5
b = a          # b посилається на той самий об'єкт
a = 7          # a тепер на 7, b досі на 5
```

**C++**

```cpp
int a = 5;      // змінна — іменована комірка пам'яті певного типу
int b = a;      // b — окрема копія значення
a = 7;          // a = 7, b досі 5
```

**JavaScript**

```javascript
let a = 5;      // let — змінну можна змінювати
let b = a;      // для чисел b — копія значення
a = 7;          // a = 7, b досі 5
const PI = 3.14159;   // const — перепризначити не можна
```

У C++ змінна — це саме **комірка пам'яті** певного типу, а `b = a` копіює значення. У JavaScript числа й рядки поводяться як значення (копіюються), а масиви та об'єкти передаються **за посиланням** — так само, як у Python.

**Правила імен:** літери, цифри, `_`; не починаються з цифри;
регістрозалежні; не збігаються з ключовими словами.

**Стиль (PEP 8):** `snake_case` для змінних і функцій,
`UPPER_CASE` для констант, `CamelCase` для класів.

У JavaScript прийнято `camelCase` для змінних і функцій, `UPPER_CASE` для констант, `PascalCase` для класів. У C++ єдиного стандарту немає: поширені і `snake_case` (як у стандартній бібліотеці), і `camelCase`; головне — один стиль у всьому проєкті.

## 3.4 Базові типи даних

| Тип | Приклад | Опис |
|-----|---------|------|
| `int` | `42`, `-7`, `10**100` | ціле, довільної довжини |
| `float` | `3.14`, `1e-3` | дійсне, 64 біти |
| `bool` | `True`, `False` | логічне (підтип `int`) |
| `str` | `"text"`, `'text'` | рядок (незмінний) |
| `NoneType` | `None` | відсутність значення |

Порівняння з C++ і JavaScript:

| Поняття | Python | C++ | JavaScript |
|---------|--------|-----|------------|
| ціле | `int` (необмежене) | `int` (≈ ±2,1·10⁹), `long long` (≈ ±9,2·10¹⁸) | `number` (double, точно до 2⁵³), `BigInt` (`10n`) |
| дійсне | `float` (64 біти) | `double` (64 біти), `float` (32) | `number` |
| логічне | `bool` | `bool` | `boolean` (`true`, `false`) |
| рядок | `str` (незмінний) | `std::string` (змінний) | `string` (незмінний) |
| відсутність значення | `None` | немає; `nullptr`, `std::optional` | `null`, `undefined` |

У C++ тип треба вказати явно (`int x = 5;`) або доручити компілятору (`auto x = 5;`). У Python і JavaScript тип належить значенню, а не змінній.

**Python**

```python
type(42)        # <class 'int'>
isinstance(42, int)   # True
```

**C++**

```cpp
auto y = 42;                                    // тип виводиться компілятором
static_assert(is_same_v<decltype(y), int>);     // перевірка типу на етапі компіляції
cout << typeid(42).name() << endl;              // "i" (рядок залежить від компілятора)
```

**JavaScript**

```javascript
typeof 42;                 // "number"
typeof "text";             // "string"
Number.isInteger(42);      // true
Array.isArray([1, 2]);     // true
```

Типи в C++ перевіряються під час **компіляції**, у Python і JavaScript — під час виконання.

## 3.5 Арифметичні операції

| Оператор | Дія | Приклад | Результат |
|----------|-----|---------|-----------|
| `+ - *` | додавання, віднімання, множення | `7 * 3` | `21` |
| `/` | ділення (завжди `float`) | `7 / 2` | `3.5` |
| `//` | цілочислове ділення (вниз) | `7 // 2`, `-7 // 2` | `3`, `-4` |
| `%` | залишок | `7 % 2`, `-7 % 2` | `1`, `1` |
| `**` | степінь | `2 ** 10` | `1024` |

**Пріоритет:** `**` → унарний `-` → `* / // %` → `+ -`.
Дужки змінюють порядок.

**Складені присвоєння:** `x += 1`, `x -= 2`, `x *= 3`, `x //= 2`, `x **= 2`.

Відмінності в C++ та JavaScript (найчастіше саме тут початківці помиляються):

| Дія | Python | C++ | JavaScript |
|-----|--------|-----|------------|
| ділення | `7 / 2` → `3.5` | `7 / 2` → `3` (обидва `int`), `7 / 2.0` → `3.5` | `7 / 2` → `3.5` |
| цілочислове ділення | `7 // 2` → `3`, `-7 // 2` → `-4` | `7 / 2` → `3`, `-7 / 2` → `-3` (до нуля) | `Math.floor(7 / 2)` → `3`, `Math.trunc(-7 / 2)` → `-3` |
| залишок | `-7 % 2` → `1` | `-7 % 2` → `-1` | `-7 % 2` → `-1` |
| степінь | `2 ** 10` | `pow(2, 10)` (повертає `double`) | `2 ** 10` або `Math.pow(2, 10)` |
| збільшення на 1 | `x += 1` (оператора `++` немає) | `x++`, `++x`, `x += 1` | `x++`, `++x`, `x += 1` |
| ділення з присвоєнням | `x //= 2` | `x /= 2` (для `int`) | `x = Math.floor(x / 2)` |

## 3.6 Ввід даних

`input()` **завжди повертає рядок** — потрібне перетворення.

**Python**

```python
name = input("Ім'я: ")              # str
n = int(input("Ціле: "))            # int
x = float(input("Дійсне: "))        # float

# кілька чисел в одному рядку
a, b = map(int, input().split())
nums = list(map(int, input().split()))
```

**C++**

```cpp
string name;
getline(cin, name);          // рядок до кінця (з пробілами)
int n;
cin >> n;                    // cin сам розбирає текст у потрібний тип
double x;
cin >> x;                    // дійсне число

// кілька чисел в одному рядку
int a, b;
cin >> a >> b;
vector<int> nums(k);         // k — кількість чисел
for (int &v : nums) cin >> v;
```

**JavaScript**

```javascript
const lines = require("fs").readFileSync(0, "utf8").split("\n");   // весь ввід одразу

const name = lines[0];                        // завжди рядок
const n = parseInt(lines[1], 10);             // ціле
const x = parseFloat(lines[2]);               // дійсне

// кілька чисел в одному рядку
const [a, b] = lines[3].trim().split(/\s+/).map(Number);
const nums = lines[4].trim().split(/\s+/).map(Number);
```

У C++ `cin >> n` одразу читає значення потрібного типу, окремого перетворення не потрібно. Якщо ввести текст замість числа, потік переходить у стан помилки. У Node.js ввід теж приходить рядками, тому потрібні `parseInt`/`parseFloat`/`Number`. `readFileSync(0)` читає весь стандартний ввід одразу; змінну `lines` у наступних розділах використовуємо саме в цьому сенсі. Для діалогу з підказками є модуль `readline`.

## 3.7 Вивід даних

**Python**

```python
print("a =", a)                  # a = 5
print(a, b, sep="; ")            # 5; 7
print("без переходу", end="")

# f-рядки (основний спосіб форматування)
print(f"{a} + {b} = {a + b}")
print(f"{3.14159:.2f}")          # 3.14
print(f"{255:5d}|")              # "  255|"
print(f"{0.1234:.1%}")           # 12.3%
```

**C++**

```cpp
cout << "a = " << a << endl;                  // a = 5
cout << a << "; " << b << endl;               // 5; 7
cout << "без переходу";                       // без endl рядок не завершується

cout << a << " + " << b << " = " << a + b << endl;
cout << fixed << setprecision(2) << 3.14159 << endl;                // 3.14
cout << setw(5) << 255 << "|" << endl;                              // "  255|"
cout << fixed << setprecision(1) << 0.1234 * 100 << "%" << endl;    // 12.3%
printf("%.2f\n", 3.14159);                    // стиль C: те саме
```

**JavaScript**

```javascript
console.log("a =", a);                        // a = 5
console.log([a, b].join("; "));               // 5; 7
process.stdout.write("без переходу");         // без \n рядок не завершується

// шаблонні рядки (template literals) — основний спосіб форматування
console.log(`${a} + ${b} = ${a + b}`);
console.log((3.14159).toFixed(2));            // "3.14"
console.log(String(255).padStart(5) + "|");   // "  255|"
console.log((0.1234 * 100).toFixed(1) + "%"); // 12.3%
```

Для `setw`, `setprecision` потрібен `#include <iomanip>`. Маніпулятор `fixed` та `setprecision` «залипають» (діють на всі наступні виводи), а `setw` — лише на одне значення. У C++20 є також `std::format("{:.2f}", 3.14159)`.

## 3.8 Перетворення типів

**Python**

```python
int("42")        # 42
int(3.9)         # 3   (відкидає дробову частину)
float("3.5")     # 3.5
str(42)          # "42"
bool(0), bool(""), bool([])    # False, False, False
round(3.567, 2)  # 3.57
```

**C++**

```cpp
stoi("42");                  // 42
(int)3.9;                    // 3 (відкидає дробову частину)
stod("3.5");                 // 3.5
to_string(42);               // "42"
bool(0);                     // false
bool(7);                     // true  (будь-яке ненульове)
round(3.567 * 100) / 100;    // 3.57  (round з двома аргументами немає)
```

**JavaScript**

```javascript
parseInt("42", 10);          // 42
Math.trunc(3.9);             // 3 (відкидає дробову частину)
parseFloat("3.5");           // 3.5
String(42);                  // "42"
Boolean(0);                  // false
Boolean("");                 // false
Boolean([]);                 // true (!) — на відміну від Python
Math.round(3.567 * 100) / 100;   // 3.57
Number("abc");               // NaN — помилка перетворення
```

`stoi("abc")` у C++ кидає виняток `invalid_argument`, а в JavaScript `parseInt("abc")` просто повертає `NaN`.

## 3.9 Математичні функції: math, <cmath>, Math

**Python**

```python
import math

math.sqrt(16)       # 4.0
math.pi             # 3.141592653589793
math.floor(3.7)     # 3
math.ceil(3.2)      # 4
math.fabs(-5)       # 5.0
math.log(8, 2)      # 3.0
math.sin(math.pi/2) # 1.0
math.hypot(3, 4)    # 5.0
math.gcd(48, 18)    # 6
math.factorial(5)   # 120
```

**C++**

```cpp
// потрібні #include <cmath> і <numeric>
sqrt(16);                    // 4.0
M_PI;                        // 3.141592653589793 (є в g++/clang)
floor(3.7);                  // 3.0 (повертає double!)
ceil(3.2);                   // 4.0
fabs(-5);                    // 5.0
log(8) / log(2);             // 3.0 (log — натуральний; log2(8) — двійковий)
sin(M_PI / 2);               // 1.0
hypot(3, 4);                 // 5.0
gcd(48, 18);                 // 6 (C++17, <numeric>)
// факторіала в стандартній бібліотеці немає — пишемо цикл
```

**JavaScript**

```javascript
Math.sqrt(16);               // 4
Math.PI;                     // 3.141592653589793
Math.floor(3.7);             // 3
Math.ceil(3.2);              // 4
Math.abs(-5);                // 5
Math.log(8) / Math.log(2);   // 3 (або Math.log2(8))
Math.sin(Math.PI / 2);       // 1
Math.hypot(3, 4);            // 5
// gcd і factorial в Math немає — пишемо самостійно
```

`Math` у JavaScript — вбудований об'єкт, імпортувати його не потрібно.

Альтернативний імпорт: `from math import sqrt, pi`.

## 3.10 Типові помилки початківця

| Помилка | Причина |
|---------|---------|
| `TypeError: can only concatenate str` | `input()` не перетворено в число |
| `IndentationError` | змішані табуляція і пробіли |
| `NameError` | змінна використана до присвоєння |
| `ZeroDivisionError` | ділення на нуль |
| `ValueError: invalid literal for int()` | `int("abc")` |
| C++: `'x' was not declared in this scope` | змінну не оголошено (немає `int x;`) |
| C++: `3 / 2` дає `1`, а не `1.5` | обидва операнди цілі — ділення цілочислове |
| C++: `Floating point exception` | ділення цілого на нуль (винятку немає, програма аварійно завершується) |
| C++: різне значення між запусками | змінну не ініціалізовано (`int x;` містить сміття) |
| JS: `NaN` | `Number("abc")`, `parseInt("abc")` |
| JS: `"5" + 3` дає `"53"` | `+` з рядком — це конкатенація; потрібне `Number("5")` |
| JS: `1 / 0` дає `Infinity` | JS не кидає виняток при діленні на нуль |
| JS: `ReferenceError` | змінну використано до оголошення (`let`/`const`) |
