# Practice Tasks for Chapter 3

**Task type:** input, type conversion, arithmetic, formatted output.

General requirements:
- read data from the keyboard with `input()`;
- print the result with an f-string, real numbers with 2 digits after the decimal point;
- no loops or conditions (they come in later chapters).

---

### Task 3.1
Read two integers and print their sum, difference, product,
quotient, integer quotient, and remainder.
```
Input:  17 5
Output: 17 + 5 = 22
        17 - 5 = 12
        17 * 5 = 85
        17 / 5 = 3.40
        17 // 5 = 3
        17 % 5 = 2
```

### Task 3.2
Read an integer (a number of seconds) and print it in the format
`hours:minutes:seconds`.
```
Input:  3725
Output: 1:02:05
```

### Task 3.3
Read a three-digit number and print its digits separately,
as well as the sum of the digits (use `//` and `%`).
```
Input:  473
Output: 4 7 3, sum = 14
```

### Task 3.4
Read the radius of a circle and print the circumference and the area of the disk.
```
Input:  2.5
Output: C = 15.71, S = 19.63
```

### Task 3.5
Read the coordinates of two points and print the distance between them
(use `math.hypot`).
```
Input:  0 0 3 4
Output: d = 5.00
```

### Task 3.6
Read the two legs of a right triangle and print the hypotenuse,
the perimeter, and the area.
```
Input:  3 4
Output: c = 5.00, P = 12.00, S = 6.00
```

### Task 3.7
Read a deposit amount and the annual rate (%) and print the amount
after 3 years with compound interest.
```
Input:  1000 10
Output: 1331.00
```

### Task 3.8
Read a person's mass (kg) and height (m) and print the body mass
index BMI = m / h².
```
Input:  70 1.75
Output: BMI = 22.86
```

### Task 3.9
Read two integers and print their GCD and LCM
(use `math.gcd`; LCM = a*b // GCD).
```
Input:  12 18
Output: GCD = 6, LCM = 36
```

### Task 3.10
Read the number of minutes of a call, the price per minute, and the VAT (%),
and print the amount without VAT, the VAT amount, and the total due.
```
Input:  120 0.5 20
Output: without VAT: 60.00
        VAT:         12.00
        total:       72.00
```
