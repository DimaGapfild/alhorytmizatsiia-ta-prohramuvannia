# Практичні завдання до розділу 3

**Тип завдань:** ввід даних, перетворення типів, арифметика, форматований вивід.

Загальні вимоги:
- дані читати з клавіатури через `input()`;
- результат виводити f-рядком, дійсні числа — з 2 знаками після коми;
- жодних циклів і умов (вони будуть у наступних розділах).

---

### Задача 3.1
Прочитати два цілих числа і вивести їхню суму, різницю, добуток,
частку, цілу частку та залишок.
```
Ввід:  17 5
Вивід: 17 + 5 = 22
       17 - 5 = 12
       17 * 5 = 85
       17 / 5 = 3.40
       17 // 5 = 3
       17 % 5 = 2
```

### Задача 3.2
Прочитати ціле число (кількість секунд) і вивести його у форматі
`год:хв:сек`.
```
Ввід:  3725
Вивід: 1:02:05
```

### Задача 3.3
Прочитати трицифрове число і вивести його цифри окремо,
а також суму цифр (використати `//` і `%`).
```
Ввід:  473
Вивід: 4 7 3, сума = 14
```

### Задача 3.4
Прочитати радіус кола і вивести довжину кола та площу круга.
```
Ввід:  2.5
Вивід: C = 15.71, S = 19.63
```

### Задача 3.5
Прочитати координати двох точок і вивести відстань між ними
(використати `math.hypot`).
```
Ввід:  0 0 3 4
Вивід: d = 5.00
```

### Задача 3.6
Прочитати два катети прямокутного трикутника і вивести гіпотенузу,
периметр та площу.
```
Ввід:  3 4
Вивід: c = 5.00, P = 12.00, S = 6.00
```

### Задача 3.7
Прочитати суму вкладу та річну ставку (%) і вивести суму
через 3 роки за складними відсотками.
```
Ввід:  1000 10
Вивід: 1331.00
```

### Задача 3.8
Прочитати масу (кг) і зріст (м) людини та вивести індекс
маси тіла ІМТ = m / h².
```
Ввід:  70 1.75
Вивід: IMT = 22.86
```

### Задача 3.9
Прочитати два цілих числа і вивести їхній НСД та НСК
(використати `math.gcd`, НСК = a*b // НСД).
```
Ввід:  12 18
Вивід: НСД = 6, НСК = 36
```

### Задача 3.10
Прочитати кількість хвилин розмови, ціну за хвилину і ПДВ (%),
вивести суму без ПДВ, суму ПДВ і разом до сплати.
```
Ввід:  120 0.5 20
Вивід: без ПДВ: 60.00
       ПДВ:     12.00
       разом:   72.00
```
