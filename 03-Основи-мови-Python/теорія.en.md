# Chapter 3. Programming Language Basics: Python, C++, JavaScript

## 3.1 The Three Languages of the Course: Python, C++, JavaScript

- An interpreted, dynamically typed language.
- Minimal syntactic "noise" — convenient for learning algorithms.
- Blocks are marked by **indentation** (4 spaces), not braces.

All examples in the course are given in three languages. Python is the main one (the shortest notation), C++ shows what happens "closer to the machine" (types, memory), JavaScript is the most widespread language of the web.

| | Python | C++ | JavaScript |
|---|--------|-----|------------|
| Execution | interpreter | compilation to machine code | engine (Node.js, browser) with JIT |
| Typing | dynamic | static, types are written explicitly | dynamic |
| Blocks | indentation | `{ }` | `{ }` |
| End of statement | end of line | `;` | `;` (recommended) |
| Integer | arbitrary length | `int`, `long long` (fixed width) | `number` (double), `BigInt` |

```bash
python3 program.py      # run a file
python3                 # interactive mode (REPL)
g++ -std=c++17 -o prog prog.cpp && ./prog   # C++: compile and run
node program.js         # JavaScript: run a file
node                    # JavaScript: interactive mode (REPL)
```

## 3.2 Program Structure

**Python**

```python
# comment to the end of the line
"""
multi-line
comment (docstring)
"""

x = 10          # a statement
if x > 5:       # the colon opens a block
    print("more")   # 4-space indentation
print("done")   # outside the block
```

**C++**

```cpp
// comment to the end of the line
/* multi-line
   comment */

// a statement ends with ;
// a block is in curly braces
    // indentation is only for readability
}
// outside the block
```

**JavaScript**

```javascript
// comment to the end of the line
/* multi-line
   comment */

// a statement ends with ;
// a block is in curly braces
  // indentation is only for readability
}
// outside the block
```

In C++ a program always starts from the `main` function, and the libraries needed are included with `#include`:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello" << endl;
    return 0;
}
```

In JavaScript (Node.js) a file with statements is enough: `console.log("Hello");`.

## 3.3 Variables and Names

A variable is a **name bound to an object** (not a memory cell).

**Python**

```python
a = 5          # a refers to the object 5
b = a          # b refers to the same object
a = 7          # a now refers to 7, b still refers to 5
```

**C++**

```cpp
// a variable is a named memory cell of a given type
// b is a separate copy of the value
// a = 7, b is still 5
```

**JavaScript**

```javascript
// let — the variable can be reassigned
// for numbers b is a copy of the value
// a = 7, b is still 5
// const — cannot be reassigned
```

In C++ a variable really is a **memory cell** of a given type, and `b = a` copies the value. In JavaScript numbers and strings behave as values (they are copied), while arrays and objects are passed **by reference** — just as in Python.

**Naming rules:** letters, digits, `_`; must not start with a digit;
case-sensitive; must not coincide with keywords.

**Style (PEP 8):** `snake_case` for variables and functions,
`UPPER_CASE` for constants, `CamelCase` for classes.

In JavaScript the convention is `camelCase` for variables and functions, `UPPER_CASE` for constants, `PascalCase` for classes. C++ has no single standard: both `snake_case` (as in the standard library) and `camelCase` are common; the main thing is one style throughout a project.

## 3.4 Basic Data Types

| Type | Example | Description |
|------|---------|-------------|
| `int` | `42`, `-7`, `10**100` | integer, arbitrary length |
| `float` | `3.14`, `1e-3` | real number, 64 bits |
| `bool` | `True`, `False` | boolean (a subtype of `int`) |
| `str` | `"text"`, `'text'` | string (immutable) |
| `NoneType` | `None` | absence of a value |

Comparison with C++ and JavaScript:

| Concept | Python | C++ | JavaScript |
|---------|--------|-----|------------|
| integer | `int` (unlimited) | `int` (≈ ±2,1·10⁹), `long long` (≈ ±9,2·10¹⁸) | `number` (double, exact up to 2⁵³), `BigInt` (`10n`) |
| real | `float` (64 bits) | `double` (64 bits), `float` (32) | `number` |
| boolean | `bool` | `bool` | `boolean` (`true`, `false`) |
| string | `str` (immutable) | `std::string` (mutable) | `string` (immutable) |
| absence of a value | `None` | none; `nullptr`, `std::optional` | `null`, `undefined` |

In C++ the type must be written explicitly (`int x = 5;`) or left to the compiler (`auto x = 5;`). In Python and JavaScript the type belongs to the value, not to the variable.

**Python**

```python
type(42)        # <class 'int'>
isinstance(42, int)   # True
```

**C++**

```cpp
// the type is deduced by the compiler
// type check at compile time
// "i" (the string depends on the compiler)
```

**JavaScript**

```javascript
typeof 42;                 // "number"
typeof "text";             // "string"
Number.isInteger(42);      // true
Array.isArray([1, 2]);     // true
```

Types in C++ are checked at **compile time**, in Python and JavaScript at run time.

## 3.5 Arithmetic Operations

| Operator | Action | Example | Result |
|----------|--------|---------|--------|
| `+ - *` | addition, subtraction, multiplication | `7 * 3` | `21` |
| `/` | division (always `float`) | `7 / 2` | `3.5` |
| `//` | integer division (rounds down) | `7 // 2`, `-7 // 2` | `3`, `-4` |
| `%` | remainder | `7 % 2`, `-7 % 2` | `1`, `1` |
| `**` | exponentiation | `2 ** 10` | `1024` |

**Precedence:** `**` → unary `-` → `* / // %` → `+ -`.
Parentheses change the order.

**Augmented assignments:** `x += 1`, `x -= 2`, `x *= 3`, `x //= 2`, `x **= 2`.

Differences in C++ and JavaScript (this is where beginners most often make mistakes):

| Operation | Python | C++ | JavaScript |
|-----|--------|-----|------------|
| division | `7 / 2` → `3.5` | `7 / 2` → `3` (both `int`), `7 / 2.0` → `3.5` | `7 / 2` → `3.5` |
| integer division | `7 // 2` → `3`, `-7 // 2` → `-4` | `7 / 2` → `3`, `-7 / 2` → `-3` (toward zero) | `Math.floor(7 / 2)` → `3`, `Math.trunc(-7 / 2)` → `-3` |
| remainder | `-7 % 2` → `1` | `-7 % 2` → `-1` | `-7 % 2` → `-1` |
| power | `2 ** 10` | `pow(2, 10)` (returns `double`) | `2 ** 10` or `Math.pow(2, 10)` |
| increment by 1 | `x += 1` (there is no `++`) | `x++`, `++x`, `x += 1` | `x++`, `++x`, `x += 1` |
| division assignment | `x //= 2` | `x /= 2` (for `int`) | `x = Math.floor(x / 2)` |

## 3.6 Input

`input()` **always returns a string** — a conversion is needed.

**Python**

```python
name = input("Name: ")              # str
n = int(input("Integer: "))         # int
x = float(input("Real: "))          # float

# several numbers on one line
a, b = map(int, input().split())
nums = list(map(int, input().split()))
```

**C++**

```cpp
string name;
// a line up to its end (with spaces)
int n;
// cin parses the text into the needed type itself
double x;
// a real number

// several numbers on one line
int a, b;
cin >> a >> b;
// k is the count of numbers
for (int &v : nums) cin >> v;
```

**JavaScript**

```javascript
// the whole input at once

// always a string
// integer
// real

// several numbers on one line
const [a, b] = lines[3].trim().split(/\s+/).map(Number);
const nums = lines[4].trim().split(/\s+/).map(Number);
```

In C++ `cin >> n` reads a value of the required type directly, no separate conversion is needed. If text is entered instead of a number, the stream goes into a failed state. In Node.js the input also arrives as strings, so `parseInt`/`parseFloat`/`Number` are needed. `readFileSync(0)` reads the whole standard input at once; in the following chapters the variable `lines` is used in exactly this sense. For a dialogue with prompts there is the `readline` module.

## 3.7 Output

**Python**

```python
print("a =", a)                  # a = 5
print(a, b, sep="; ")            # 5; 7
print("no line break", end="")

# f-strings (the main way to format output)
print(f"{a} + {b} = {a + b}")
print(f"{3.14159:.2f}")          # 3.14
print(f"{255:5d}|")              # "  255|"
print(f"{0.1234:.1%}")           # 12.3%
```

**C++**

```cpp
cout << "a = " << a << endl;                  // a = 5
cout << a << "; " << b << endl;               // 5; 7
// without endl the line is not terminated

cout << a << " + " << b << " = " << a + b << endl;
cout << fixed << setprecision(2) << 3.14159 << endl;                // 3.14
cout << setw(5) << 255 << "|" << endl;                              // "  255|"
cout << fixed << setprecision(1) << 0.1234 * 100 << "%" << endl;    // 12.3%
// C style: the same
```

**JavaScript**

```javascript
console.log("a =", a);                        // a = 5
console.log([a, b].join("; "));               // 5; 7
// without \n the line is not terminated

// template literals are the main way to format
console.log(`${a} + ${b} = ${a + b}`);
console.log((3.14159).toFixed(2));            // "3.14"
console.log(String(255).padStart(5) + "|");   // "  255|"
console.log((0.1234 * 100).toFixed(1) + "%"); // 12.3%
```

`setw` and `setprecision` need `#include <iomanip>`. The `fixed` and `setprecision` manipulators are "sticky" (they affect all following output), while `setw` affects only one value. C++20 also has `std::format("{:.2f}", 3.14159)`.

## 3.8 Type Conversion

**Python**

```python
int("42")        # 42
int(3.9)         # 3   (drops the fractional part)
float("3.5")     # 3.5
str(42)          # "42"
bool(0), bool(""), bool([])    # False, False, False
round(3.567, 2)  # 3.57
```

**C++**

```cpp
stoi("42");                  // 42
// 3 (drops the fractional part)
stod("3.5");                 // 3.5
to_string(42);               // "42"
bool(0);                     // false
// true (any non-zero)
// 3.57 (there is no two-argument round)
```

**JavaScript**

```javascript
parseInt("42", 10);          // 42
// 3 (drops the fractional part)
parseFloat("3.5");           // 3.5
String(42);                  // "42"
Boolean(0);                  // false
Boolean("");                 // false
// true (!) — unlike Python
Math.round(3.567 * 100) / 100;   // 3.57
// NaN — conversion error
```

In C++ `stoi("abc")` throws an `invalid_argument` exception, while in JavaScript `parseInt("abc")` simply returns `NaN`.

## 3.9 Math Functions: math, <cmath>, Math

**Python**

```python
import math

math.sqrt(16)       # 4.0
math.pi             # 3.141592653589793
math.floor(3.7)     # 3
math.ceil(3.2)      # 4
math.fabs(-5)       # 5.0
math.log(8, 2)      # 3.0
math.sin(math.pi/2) # 1.0
math.hypot(3, 4)    # 5.0
math.gcd(48, 18)    # 6
math.factorial(5)   # 120
```

**C++**

```cpp
// needs #include <cmath> and <numeric>
sqrt(16);                    // 4.0
// 3.141592653589793 (available in g++/clang)
// 3.0 (returns double!)
ceil(3.2);                   // 4.0
fabs(-5);                    // 5.0
// 3.0 (log is natural; log2(8) is binary)
sin(M_PI / 2);               // 1.0
hypot(3, 4);                 // 5.0
gcd(48, 18);                 // 6 (C++17, <numeric>)
// there is no factorial in the standard library — write a loop
```

**JavaScript**

```javascript
Math.sqrt(16);               // 4
Math.PI;                     // 3.141592653589793
Math.floor(3.7);             // 3
Math.ceil(3.2);              // 4
Math.abs(-5);                // 5
// 3 (or Math.log2(8))
Math.sin(Math.PI / 2);       // 1
Math.hypot(3, 4);            // 5
// gcd and factorial are not in Math — write them yourself
```

`Math` in JavaScript is a built-in object, no import is needed.

Alternative import: `from math import sqrt, pi`.

## 3.10 Common Beginner Mistakes

| Error | Cause |
|-------|-------|
| `TypeError: can only concatenate str` | `input()` was not converted to a number |
| `IndentationError` | tabs and spaces mixed |
| `NameError` | a variable was used before assignment |
| `ZeroDivisionError` | division by zero |
| `ValueError: invalid literal for int()` | `int("abc")` |
| C++: `'x' was not declared in this scope` | the variable was not declared (no `int x;`) |
| C++: `3 / 2` дає `1`, а не `1.5` | both operands are integers — integer division |
| C++: `Floating point exception` | integer division by zero (there is no exception, the program crashes) |
| C++: різне значення між запусками | the variable was not initialised (`int x;` holds garbage) |
| JS: `NaN` | `Number("abc")`, `parseInt("abc")` |
| JS: `"5" + 3` дає `"53"` | `+` with a string is concatenation; use `Number("5")` |
| JS: `1 / 0` дає `Infinity` | JS does not throw an exception on division by zero |
| JS: `ReferenceError` | a variable was used before its declaration (`let`/`const`) |
