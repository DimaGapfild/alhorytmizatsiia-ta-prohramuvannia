# Алгоритмізація та програмування

Навчальний курс. Мова реалізації — **Python 3**.

## Структура

Кожен розділ — окрема папка з трьома файлами:

| Файл | Призначення |
|------|-------------|
| `теорія.md` | конспект лекції: поняття, синтаксис, приклади |
| `практика.md` | 10 однотипних задач одного рівня складності |
| `розв'язки.py` | еталонні розв'язки всіх 10 задач (запускаються і самоперевіряються) |

У розділах 1–2 задачі не передбачають коду, тому там замість
`розв'язки.py` лежить `розв'язки.md` — псевдокод і таблиці трасування.
Розділ 13 при запуску створює підпапку `demo/` з тестовими файлами.

## Як працювати з матеріалом

1. Прочитати `теорія.md`, розібрати приклади в інтерпретаторі.
2. Виконати всі 10 задач із `практика.md` самостійно.
3. Лише після цього порівняти з `розв'язки.py`.

## Запуск розв'язків`

```bash
python3 "01-Вступ-до-алгоритмізації/розв'язки.py"
```

Кожен файл розв'язків містить функції `task_01`…`task_10` і блок
`if __name__ == "__main__":` з демонстрацією роботи.

## Критерії оцінювання практичної роботи

| Бали | Вимоги |
|------|--------|
| 5 | усі 10 задач, код читабельний, крайні випадки враховані |
| 4 | 8–9 задач або дрібні недоліки в оформленні |
| 3 | 6–7 задач, базова правильність |
| 2 | 4–5 задач |
| 1 | менше 4 задач |
