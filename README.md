# Алгоритмізація та програмування

Навчальний курс. Мова реалізації — **Python 3**.

## Структура

Кожен розділ — окрема папка з файлами:

| Файл | Призначення |
|------|-------------|
| `теорія.md` | конспект лекції: поняття, синтаксис, приклади |
| `практика.md` | 10 однотипних задач одного рівня складності |

## Програма курсу

| № | Розділ |
|---|--------|
| 01 | Вступ до алгоритмізації |
| 02 | Блок-схеми та псевдокод |
| 03 | Основи мови Python |
| 04 | Лінійні алгоритми |
| 05 | Розгалуження |
| 06 | Цикли |
| 07 | Рядки |
| 08 | Списки (одновимірні масиви) |
| 09 | Матриці (двовимірні масиви) |
| 10 | Функції та рекурсія |
| 11 | Сортування та пошук |
| 12 | Словники, множини, кортежі |
| 13 | Файли та обробка помилок |
| 14 | Основи ООП |
| 15 | Складність алгоритмів |

## Як працювати з матеріалом

1. Прочитати `теорія.md`, розібрати приклади в інтерпретаторі.
2. Виконати всі 10 задач із `практика.md` самостійно.

## Критерії оцінювання практичної роботи

| Бали | Вимоги |
|------|--------|
| 5 | усі 10 задач, код читабельний, крайні випадки враховані |
| 4 | 8–9 задач або дрібні недоліки в оформленні |
| 3 | 6–7 задач, базова правильність |
| 2 | 4–5 задач |
| 1 | менше 4 задач |
