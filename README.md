## Структура

Кожен розділ — окрема папка з файлами:

| Файл | Призначення |

1. Прочитати `теорія.md`, розібрати приклади обраною мовою: `python3`, `node` або `g++ -std=c++20`.
2. Виконати всі 10 задач із `практика.md` самостійно.

## Бали та допуск до підсумкового контролю

Максимум за курс — **100 балів**: **60** поточний контроль + **40**
підсумковий (залік або екзамен — за рішенням викладача).

| Складова | Макс. | Як рахується |
|----------|-------|--------------|
| Практичні роботи (розділи 1–15) | 60 | середня оцінка за розділи (1–5, за таблицею вище) × 12; розділ, який не здано, — 0 |
| **Поточний контроль** | **60** | |
| Залік / екзамен | 40 | теоретична частина 20 + практичне завдання 20 |
| **Разом** | **100** | |

### Допуск до заліку або екзамену

Студент допускається до підсумкового контролю, якщо виконано **обидві**
умови:

1. поточний контроль — **не менше 35 балів із 60**;
2. здано практичні роботи **не менше ніж із 11 розділів із 15**
   (кожна — з оцінкою 3 або вище).

Не допущені студенти можуть доопрацювати практичні роботи й здати їх
повторно до початку сесії.

### Підсумкова оцінка

Залік/екзамен вважається складеним, якщо за нього отримано **не менше
24 із 40** балів. Підсумкова сума (поточний контроль + залік/екзамен):

| Сума балів | Оцінка (ECTS) | Національна шкала |
|------------|---------------|-------------------|
| 90–100 | A | відмінно |
| 82–89 | B | добре |
| 74–81 | C | добре |
| 64–73 | D | задовільно |
| 60–63 | E | задовільно |
| менше 60 | F | незадовільно (повторне складання) |

Для **заліку** результат — «зараховано» (від 60 балів і виконаних умов
вище) або «не зараховано».

> Конкретні пороги можуть уточнюватися викладачем на початку семестру.
