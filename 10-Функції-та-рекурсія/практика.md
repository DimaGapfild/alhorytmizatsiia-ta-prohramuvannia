# Практичні завдання до розділу 10

**Тип завдань:** для кожної задачі написати функцію
**у двох варіантах** — ітеративному (`*_iter`) і рекурсивному (`*_rec`),
та переконатися, що обидва дають однаковий результат.

Вимоги:
- функція має `return`, а не `print`;
- є docstring із описом параметрів і результату;
- наведено не менше 3 тестів через `assert`.

---

### Задача 10.1
`factorial(n)` — обчислити n! для цілого n ≥ 0.
```
0 → 1    1 → 1    5 → 120    10 → 3628800
```

### Задача 10.2
`digit_sum(n)` — сума цифр натурального числа.
```
0 → 0    7 → 7    12345 → 15
```

### Задача 10.3
`digit_count(n)` — кількість цифр натурального числа.
```
0 → 1    7 → 1    70500 → 5
```

### Задача 10.4
`power(a, n)` — a^n для цілого n ≥ 0, без оператора `**`.
Рекурсивний варіант реалізувати за O(log n).
```
(2, 10) → 1024    (5, 0) → 1    (3, 4) → 81
```

### Задача 10.5
`gcd(a, b)` — найбільший спільний дільник (алгоритм Евкліда).
```
(48, 18) → 6    (17, 5) → 1    (12, 0) → 12
```

### Задача 10.6
`fib(n)` — n-те число Фібоначчі (fib(0)=0, fib(1)=1).
Рекурсивний варіант — з мемоізацією; порівняти час роботи
наївного і мемоізованого для n = 35.
```
0 → 0    1 → 1    10 → 55    30 → 832040
```

### Задача 10.7
`reverse_number(n)` — число, записане цифрами у зворотному порядку.
```
12345 → 54321    7 → 7    1200 → 21
```

### Задача 10.8
`is_palindrome(s)` — чи є рядок паліндромом
(регістр і неалфавітні символи ігнорувати).
```
"ротатор" → True    "програма" → False    "" → True
```

### Задача 10.9
`list_sum(a)` — сума елементів списку (без `sum()`).
Рекурсивний варіант — через перший елемент і решту списку.
```
[] → 0    [5] → 5    [1,2,3,4] → 10
```

### Задача 10.10
`binary(n)` — двійкове подання натурального числа як рядок
(без `bin()`).
```
0 → "0"    1 → "1"    10 → "1010"    255 → "11111111"
```
