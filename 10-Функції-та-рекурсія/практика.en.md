# Practice Tasks for Chapter 10

**Task type:** for each task write a function
**in two versions** — iterative (`*_iter`) and recursive (`*_rec`),
and make sure both give the same result.

Requirements:
- the function uses `return`, not `print`;
- there is a docstring describing the parameters and the result;
- at least 3 tests are given via `assert`.

---

### Task 10.1
`factorial(n)` — compute n! for an integer n ≥ 0.
```
0 → 1    1 → 1    5 → 120    10 → 3628800
```

### Task 10.2
`digit_sum(n)` — the sum of the digits of a natural number.
```
0 → 0    7 → 7    12345 → 15
```

### Task 10.3
`digit_count(n)` — the number of digits of a natural number.
```
0 → 1    7 → 1    70500 → 5
```

### Task 10.4
`power(a, n)` — a^n for an integer n ≥ 0, without the `**` operator.
Implement the recursive version in O(log n).
```
(2, 10) → 1024    (5, 0) → 1    (3, 4) → 81
```

### Task 10.5
`gcd(a, b)` — the greatest common divisor (Euclid's algorithm).
```
(48, 18) → 6    (17, 5) → 1    (12, 0) → 12
```

### Task 10.6
`fib(n)` — the n-th Fibonacci number (fib(0)=0, fib(1)=1).
The recursive version uses memoization; compare the running time
of the naive and the memoized versions for n = 35.
```
0 → 0    1 → 1    10 → 55    30 → 832040
```

### Task 10.7
`reverse_number(n)` — the number written with its digits in reverse order.
```
12345 → 54321    7 → 7    1200 → 21
```

### Task 10.8
`is_palindrome(s)` — whether the string is a palindrome
(ignore case and non-alphabetic characters).
```
"rotator" → True    "program" → False    "" → True
```

### Task 10.9
`list_sum(a)` — the sum of the elements of a list (without `sum()`).
The recursive version works via the first element and the rest of the list.
```
[] → 0    [5] → 5    [1,2,3,4] → 10
```

### Task 10.10
`binary(n)` — the binary representation of a natural number as a string
(without `bin()`).
```
0 → "0"    1 → "1"    10 → "1010"    255 → "11111111"
```
