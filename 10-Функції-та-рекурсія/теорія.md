# Розділ 10. Функції та рекурсія

## 10.1 Призначення функцій

**Функція (підпрограма)** — іменований фрагмент коду, який можна
викликати багато разів із різними даними.

Що дають функції:
- **повторне використання** — код написано один раз;
- **декомпозиція** — велика задача розбивається на малі;
- **абстракція** — користувачу важливо *що* робить функція, а не *як*;
- **тестованість** — функцію легко перевірити окремо.

## 10.2 Оголошення та виклик

**Python**

```python
def area(a, b):            # def, ім'я, параметри, двокрапка
    """Площа прямокутника."""   # docstring
    return a * b           # повернення значення

s = area(3, 4)             # виклик, аргументи 3 і 4
```

**C++**

```cpp
// Площа прямокутника.
int area(int a, int b) {       // тип результату, ім'я, параметри з типами
    return a * b;              // повернення значення
}

int s = area(3, 4);            // виклик, аргументи 3 і 4
```

**JavaScript**

```javascript
/** Площа прямокутника. */
function area(a, b) {          // function, ім'я, параметри (без типів)
  return a * b;                // повернення значення
}

const s = area(3, 4);          // виклик, аргументи 3 і 4
```

Стрілкова форма в JavaScript: `const area = (a, b) => a * b;`.

**Параметр** — ім'я в оголошенні. **Аргумент** — значення при виклику.

Функція без `return` повертає `None`.
`return` негайно завершує функцію.

У C++ тип результату вказують перед іменем функції; якщо значення не повертається — `void`. Функцію потрібно оголосити (або визначити) **до** місця виклику; для цього пишуть прототип: `int area(int a, int b);`. У JavaScript функція без `return` повертає `undefined`; оголошення `function` «піднімаються» (hoisting), тому викликати таку функцію можна і до рядка з її оголошенням.

**Python**

```python
def sign(x):
    if x > 0:
        return 1
    if x < 0:
        return -1
    return 0
```

**C++**

```cpp
int sign(int x) {
    if (x > 0) {
        return 1;
    }
    if (x < 0) {
        return -1;
    }
    return 0;
}
```

**JavaScript**

```javascript
function sign(x) {
  if (x > 0) {
    return 1;
  }
  if (x < 0) {
    return -1;
  }
  return 0;
}
```

## 10.3 Види параметрів

**Python**

```python
def f(a, b=10, *args, **kwargs):
    ...
```

**C++**

```cpp
void f(int a, int b = 10) {                // значення за замовчуванням — у кінці списку
    // ...
}

int sum_all(initializer_list<int> nums) {  // аналог *args: sum_all({1, 2, 3})
    int s = 0;
    for (int x : nums) s += x;
    return s;
}
```

**JavaScript**

```javascript
function f(a, b = 10, ...args) {           // ...args — аналог *args (масив)
  // ...
}

function g({ x, y = 0 } = {}) {            // «іменовані» параметри — деструктуризація об'єкта
  // ...
}
g({ y: 5, x: 1 });                         // порядок не важливий
```

| Вид | Приклад | Опис |
|-----|---------|------|
| позиційні | `f(1, 2)` | за порядком |
| іменовані | `f(a=1, b=2)` | за іменем, порядок не важливий |
| зі значенням за замовчуванням | `def f(b=10)` | можна не передавати |
| `*args` | `def f(*nums)` | довільна кількість позиційних (кортеж) |
| `**kwargs` | `def f(**opts)` | довільна кількість іменованих (словник) |

У C++ немає іменованих аргументів — параметри передаються лише за порядком; зате є **перевантаження**: кілька функцій з однаковим іменем, але різними списками параметрів (`int area(int a)` і `int area(int a, int b)`). У JavaScript перевантаження немає: останнє оголошення з тим самим іменем перекриває попередні, а «іменовані» параметри імітують передачею об'єкта.

### Небезпека змінюваного значення за замовчуванням

**Python**

```python
def bad(x, acc=[]):      # ПОМИЛКА: список створюється ОДИН раз
    acc.append(x)
    return acc

bad(1)   # [1]
bad(2)   # [1, 2]  — не [2]!

def good(x, acc=None):   # правильно
    if acc is None:
        acc = []
    acc.append(x)
    return acc
```

**C++**

```cpp
vector<int> good(int x, vector<int> acc = {}) {   // значення за замовчуванням обчислюється при КОЖНОМУ виклику
    acc.push_back(x);
    return acc;
}
// good(1) -> {1}; good(2) -> {2}: пастки Python тут немає
```

**JavaScript**

```javascript
function f(x, acc = []) {                  // новий масив створюється при КОЖНОМУ виклику
  acc.push(x);
  return acc;
}
f(1);                                      // [1]
f(2);                                      // [2] — пастки Python тут немає
```

Значення за замовчуванням у C++ і JavaScript обчислюється при кожному виклику, тому спільного «накопичувача» не виникає.

## 10.4 Повернення кількох значень

**Python**

```python
def min_max(a):
    return min(a), max(a)      # кортеж

lo, hi = min_max([3, 1, 4])
```

**C++**

```cpp
pair<int, int> min_max(const vector<int> &a) {
    return {*min_element(a.begin(), a.end()), *max_element(a.begin(), a.end())};
}

auto [lo, hi] = min_max({3, 1, 4});        // структуровані прив'язки (C++17)
```

**JavaScript**

```javascript
function minMax(a) {
  return [Math.min(...a), Math.max(...a)];   // масив
}

const [lo, hi] = minMax([3, 1, 4]);
```

У C++ можна повертати `pair`, `tuple` або власну `struct`; у JavaScript — масив чи об'єкт.

## 10.5 Область видимості (scope)

Правило **LEGB**: Local → Enclosing → Global → Built-in.

**Python**

```python
x = 10              # глобальна

def f():
    x = 5           # ЛОКАЛЬНА, інша змінна
    print(x)        # 5

f()
print(x)            # 10
```

**C++**

```cpp
int x = 10;                    // глобальна

void f() {
    int x = 5;                 // ЛОКАЛЬНА, інша змінна
    cout << x << endl;         // 5
}

int main() {
    f();
    cout << x << endl;         // 10
}
```

**JavaScript**

```javascript
let x = 10;                    // глобальна

function f() {
  let x = 5;                   // ЛОКАЛЬНА, інша змінна
  console.log(x);              // 5
}

f();
console.log(x);                // 10
```

У C++ і JavaScript область видимості визначається блоком `{ }`: змінна, оголошена у блоці, існує лише в ньому.

**Python**

```python
def g():
    global x
    x = 99          # змінює глобальну
```

**C++**

```cpp
void g() {
    x = 99;                    // змінює глобальну (ключове слово global не потрібне)
    // ::x = 99;               // якщо є локальна x, глобальну вказують як ::x
}
```

**JavaScript**

```javascript
function g() {
  x = 99;                      // змінює зовнішню змінну (якщо немає локальної x)
}
```

Без локальної змінної з таким самим іменем C++ і JavaScript самі знаходять зовнішню; присвоєння їй змінює її. Тому випадково «зачепити» глобальну змінну тут легше, ніж у Python.

Використання `global` вважається поганим стилем — краще передавати
дані параметрами і повертати результат.

### Змінювані аргументи

**Python**

```python
def add_item(lst):
    lst.append(1)      # ЗМІНЮЄ список викликача!

a = []
add_item(a)
print(a)               # [1]
```

**C++**

```cpp
void add_item(vector<int> &lst) {      // & — передача за посиланням
    lst.push_back(1);                  // ЗМІНЮЄ вектор викликача!
}

void no_effect(vector<int> lst) {      // без & — працює з копією
    lst.push_back(1);                  // зовні нічого не змінюється
}

int main() {
    vector<int> a;
    add_item(a);
    cout << a.size() << endl;          // 1
}
```

**JavaScript**

```javascript
function addItem(lst) {
  lst.push(1);                         // ЗМІНЮЄ масив викликача!
}

const a = [];
addItem(a);
console.log(a);                        // [ 1 ]
```

У C++ за замовчуванням параметри **копіюються**; щоб функція змінювала оригінал, використовують посилання (`&`). Для великих об'єктів, які лише читають, пишуть `const vector<int> &v`, щоб не копіювати. У JavaScript числа й рядки передаються як значення, а масиви й об'єкти — як посилання (як у Python).

Числа і рядки незмінні — їх змінити зсередини функції неможливо.

## 10.6 Рекурсія

**Рекурсія** — виклик функцією самої себе.

Обов'язкові складові:
1. **база** (базовий випадок) — умова завершення без рекурсії;
2. **крок** — виклик себе з «меншими» даними, що наближають до бази.

**Python**

```python
def factorial(n):
    if n <= 1:          # база
        return 1
    return n * factorial(n - 1)    # крок
```

**C++**

```cpp
long long factorial(int n) {
    if (n <= 1) {                      // база
        return 1;
    }
    return n * factorial(n - 1);       // крок
}
```

**JavaScript**

```javascript
function factorial(n) {
  if (n <= 1) {                        // база
    return 1;
  }
  return n * factorial(n - 1);         // крок
}
```

`long long` вміщує факторіал лише до 20!; цілі числа типу `number` у JavaScript гарантовано точні лише до 2⁵³ (це приблизно 18!). Далі потрібен `BigInt`.

Дерево викликів для `factorial(4)`:
```
factorial(4) = 4 * factorial(3)
               3 * factorial(2)
                   2 * factorial(1)
                       1           ← база
= 4*3*2*1 = 24
```

**Фібоначчі (наївно — експоненційно повільно)**

**Python**


**C++**

```cpp
long long fib(int n) {
    return n < 2 ? n : fib(n - 1) + fib(n - 2);
```

**JavaScript**

```javascript
function fib(n) {
```

**Фібоначчі з мемоізацією (швидко)**

**Python**

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

**C++**

```cpp
long long fib(int n) {
    static unordered_map<int, long long> memo;     // кеш зберігається між викликами
    if (n < 2) return n;
    auto it = memo.find(n);
    if (it != memo.end()) return it->second;
    return memo[n] = fib(n - 1) + fib(n - 2);
}
```

**JavaScript**

```javascript
const memo = new Map();

function fib(n) {
  if (n < 2) return n;
  if (memo.has(n)) return memo.get(n);
  const r = fib(n - 1) + fib(n - 2);
  memo.set(n, r);
  return r;
}
```

Готового декоратора `lru_cache` у C++ і JavaScript немає — кеш (`unordered_map`, `Map`) пишуть вручну.

**Швидке піднесення до степеня — O(log n)**

**Python**

```python
def power(a, n):
    if n == 0:
        return 1
    if n % 2 == 0:
        half = power(a, n // 2)
        return half * half
    return a * power(a, n - 1)
```

**C++**

```cpp
long long power(long long a, int n) {
    if (n == 0) {
        return 1;
    }
    if (n % 2 == 0) {
        long long half = power(a, n / 2);
        return half * half;
    }
    return a * power(a, n - 1);
}
```

**JavaScript**

```javascript
function power(a, n) {
  if (n === 0) {
    return 1;
  }
  if (n % 2 === 0) {
    const half = power(a, n / 2);
    return half * half;
  }
  return a * power(a, n - 1);
}
```

**Ханойські башні**

**Python**

```python
def hanoi(n, src, dst, tmp):
    if n == 0:
        return
    hanoi(n - 1, src, tmp, dst)
    print(f"{src} -> {dst}")
    hanoi(n - 1, tmp, dst, src)
```

**C++**

```cpp
void hanoi(int n, const string &src, const string &dst, const string &tmp) {
    if (n == 0) {
        return;
    }
    hanoi(n - 1, src, tmp, dst);
    cout << src << " -> " << dst << endl;
    hanoi(n - 1, tmp, dst, src);
}
```

**JavaScript**

```javascript
function hanoi(n, src, dst, tmp) {
  if (n === 0) {
    return;
  }
  hanoi(n - 1, src, tmp, dst);
  console.log(`${src} -> ${dst}`);
  hanoi(n - 1, tmp, dst, src);
}
```

## 10.7 Рекурсія vs ітерація

| | Рекурсія | Цикл |
|---|---|---|
| читабельність для дерев/фракталів | краща | гірша |
| витрати пам'яті | O(глибини) — стек | O(1) |
| швидкість | нижча | вища |
| ризик | `RecursionError` | нескінченний цикл |

Ліміт глибини: `sys.getrecursionlimit()` — типово 1000.
`sys.setrecursionlimit(10000)` піднімає його (обережно!).

У C++ ліміт не фіксований: глибина залежить від розміру стека (зазвичай порядку десятків тисяч викликів), після чого програма аварійно завершується (*stack overflow*). У JavaScript занадто глибока рекурсія кидає `RangeError: Maximum call stack size exceeded` (порядку 10 000 викликів у Node.js).

**Будь-яку рекурсію можна переписати циклом**, але не завжди просто.

## 10.8 Lambda-функції

**Python**

```python
square = lambda x: x ** 2        # коротка анонімна функція
sorted(words, key=lambda w: len(w))
sorted(pairs, key=lambda p: (-p[1], p[0]))
```

**C++**

```cpp
auto square = [](int x) { return x * x; };          // лямбда-вираз (C++11)

sort(words.begin(), words.end(),
     [](const string &a, const string &b) { return a.size() < b.size(); });

sort(pairs.begin(), pairs.end(),
     [](const pair<string, int> &p, const pair<string, int> &q) {
         return p.second != q.second ? p.second > q.second : p.first < q.first;
     });
```

**JavaScript**

```javascript
const square = x => x ** 2;                         // стрілкова функція

words.sort((a, b) => a.length - b.length);

pairs.sort((p, q) => q[1] - p[1] || p[0].localeCompare(q[0]));
```

`sort` у C++ і JavaScript змінює контейнер на місці, а Python-ове `sorted` створює новий список.

Для чогось складнішого за один вираз — звичайний `def`.

## 10.9 Правила хорошої функції

1. Робить **одну** річ, і це видно з назви.
2. Назва — дієслово або `is_`/`get_`/`count_` + предмет.
3. Не більше 3–4 параметрів.
4. Має docstring: що робить, що приймає, що повертає.
5. Не друкує те, що має повертати (`return`, а не `print`).
6. Не змінює свої аргументи без явної потреби.
